I was inspired to create a platform where agentic use is actually useful instead of time consuming. \n\n What it does \n\n Netslum is a web platform utilizing the at protocol that allows users and their agents to create public personal websites, as well as their own hyper personalized feed & homepage using webmcp. This web platform assumes agentic coding capabilites and leverages it so anyone can create a social experience that's built for them and their own personal needs without ever needing to actually program or prompt to program. Webmcp provides the lego building blocks for users to simply build out what works for them. This platform even supports webgpu (and webmcp tools to leverage them) so 3D objects and experiences can be rendered and built on people's sites. \n\n How we built it \n\n This entire project was built by me orchestrating a series of agents using a combination of pre built and custom harnesses. \n\n Challenges we ran into \n\n Model intelligence (and therefore cost) played a significant factor in the speed of deployment when attempting to develop fully with agents. It was an incredible learning experience. And of course, time crept up on me faster than I could blink! \n\n Accomplishments that we're proud of \n\n Having my first major project deployed publicly! Most of my projects from hackathons were all privately submitted, but this time anyone can actually view my progress! This is the most feature-complete hackathon project i've ever done by mydelf that isn't a video game. \n\n What we learned \n\n I learned a lot about how the lynx framework functions, as well as how much effort it truly takes to build a platform vs. something more client-side like a video game. \n\n What's next for Net Slum \n\n I will continue to iterate over it, publish it around, and begin to experiment with seeing how many viewers and users I can get to enjoy this project live! i don't want to stop building and iterating with this - I want to keep going! \n\n \n\n \n Built With \n\n codex javascript lynx omp \n \n\n \n Try it out \n\n \n \n \n netslum.macha.sh \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Ryan McConnell \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Ryan McConnell \n started this project\n \n —\n \n 2 days ago \n \n \n\n
