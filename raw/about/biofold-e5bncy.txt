It's complemented by dedicated Web Workers for non-blocking calculations of van der Waals surfaces and sub-angstrom distances, along with a WebMCP adapter that links eight typed tools to a unified Command Bus for humans and agents. The backend relies on Supabase Edge Functions on Deno to orchestrate caching from RCSB PDB and UniProt, serving a wizard powered by OpenRouter. \n\n Challenges We Encountered \n\n Errors in the configuration of the free OpenRouter templates, UI errors, backend errors, WebMCP configuration errors, among others. \n\n Achievements We're Proud Of \n\n I'm proud to deliver a functional product with excellent scalability potential. \n\n What We Learned \n\n Besides the usual improvements in backend and database knowledge, I learned a lot about MCP configurations, as well as a great deal about web design. \n\n What's Next for BioFold? Biofold's objective is to expand the functionalities that, although mostly advanced, in several cases need improvement for university or professional work. That is why my next objective is to create the bioacademy section focused on learning molecular analysis, geared towards both high school and university students. \n\n \n\n \n Built With \n\n css javascript openrouter supabase typescript \n \n\n \n Try it out \n\n \n \n \n biofold-orpin.vercel.app \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Josuelpro Condori Choque \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Josuelpro Condori Choque \n posted an update\n \n —\n \n about 18 hours ago \n \n \n\n I just have Hi, I made a commit to the repo because I noticed a bug that was preventing MCP (which is now available with all 13 tools) from working correctly.
