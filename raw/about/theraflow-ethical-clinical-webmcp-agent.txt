However, browser AI agents typically rely on brittle DOM scraping or simulated mouse clicks. We built TheraFlow / MindBridge to explore how the new WebMCP client-side standard enables AI agents to dynamically generate, scaffold, and adapt interactive clinical interventions with zero DOM scraping, backed by deterministic crisis circuit breakers. \n\n What It Does \n\n TheraFlow turns a web workspace into an agent-executable clinical environment: \n\n \n Interactive Tool Registration: Registers structured tools ( generate_cbt_thought_record , build_pacing_grounding_exercise , trigger_crisis_containment ) directly via document.modelContext.registerTool . \n Dynamic DOM Scaffolding: Agents pass structured clinical parameters to render interactive tables and visual grounding animations. \n Deterministic Safety Overrides: If acute distress signals are evaluated, the agent triggers an immediate client-side containment sequence that locks the active workspace and presents verified support lifelines. \n Non-Repudiable Audit Telemetry: Every tool invocation and safety state transition writes to an on-screen runtime telemetry log. \n \n\n How We Built It \n\n \n Client-Side Architecture: Pure JavaScript, semantic HTML5, and CSS3 designed for zero-latency execution. \n WebMCP Standard: Implements document.modelContext tool declarations with input validation, schema descriptions, and client-side sanitization. \n Deployment: Hosted directly on GitHub Pages with MIT licensing. \n \n\n Challenges We Overcame \n\n Balancing open agent interaction with strict ethical boundaries required implementing deterministic safety containment. We ensured that clinical safety overrides always take precedence over generative outputs. \n\n Accomplishments That We're Proud Of \n\n \n Fully functional WebMCP registration working natively in Chrome. \n Smooth 4-7-8 visual pacing animation that adjusts pacing dynamically. \n A clear telemetry logging interface that makes agent tool calls visible in real time.\n*Assisting clinicians provide easier and safer assignments and instructions to clients. \n \n\n What We Learned \n\n WebMCP makes human-agent collaboration in web apps far more robust and predictable than traditional screen-reading and UI simulation. Dynamic AI helps clinicians like me use AI more ethically and safely. \n\n What's next for TheraFlow: Ethical Clinical WebMCP Agent \n\n The future is open, and hopefully we can provide more resources and support both for clients and management for the private practice clinician or organization. \n\n \n\n \n Built With \n\n css3 github html5 javascript webmcp \n \n\n \n Try it out \n\n \n \n \n GitHub Repo \n \n \n \n sultana717-debug.github.io \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Aunjuli Hicks \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n AI safety researcher & clinician.
