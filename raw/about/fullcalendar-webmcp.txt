This was the perfect opportunity and the perfect tool. \n\n What it does \n\n Exposes six tools for reading calendar context, finding events, and reading individual events, and interact with them to create, update, and delete. \n\n How we built it \n\n I used AI agents like Codex and Cursor. I did have experience with the FullCalendar implementation, what I did not have experience with was Chrome-specific or Chromium-specific developer tooling. \n\n Challenges we ran into \n\n The hardest challenge was to contain the boundary between the adapter and the host application because it could really easily outgrow and become opinionated about the implementation, which is contradictory to the ergonomics I'm looking for. \n\n Coding agents have this tendency that makes us overbuild, so I actually created three implementations before actually trimming about 60% of features I'd say, before freezing. \n\n Accomplishments that we're proud of \n\n I think is easy to understand, and it can be very developer-agent-friendly. \n\n What we learned \n\n I learned that less is more and clarity is the best way to communicate a tool description for agents. I mean, AI has come so far that it can pretty much understand intent even if you mess up your prompts. \n\n What's next for FullCalendar WebMCP \n\n I think this implementation can grow as an open-source project, especially since FullCalendar is used in production by many devs (9M+ monthly npm downloads). And not only FullCalendar, I actually bought a domain called protocoltooling.com that I probably would like to convert to a webmcp-focused tool creation organization for widely-used web-integrations like FC. \n\n \n\n \n Built With \n\n chatgpt chrome codex cursor fullcalendar next.js npm react typescript vercel vite webmcp \n \n\n \n Try it out \n\n \n \n \n protocoltooling.com \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n I worked on a whole project, mainly leaning on ChatGPT Codex, and Cursor. \n \n\n \n \n \n \n \n \n\n \n Roberto Nevarez \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Roberto Nevarez \n started this project\n \n —\n \n 2 days ago \n \n \n\n
