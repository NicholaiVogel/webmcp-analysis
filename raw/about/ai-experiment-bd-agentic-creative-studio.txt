These tools allow compatible AI agents to discover and operate the creative workspace without relying exclusively on fragile UI navigation. \n\n Example capabilities include: \n\n \n create_project \n enhance_prompt \n generate_image \n edit_image \n generate_story \n generate_storyboard \n generate_voice \n list_project_assets \n save_project_asset \n export_project \n \n\n Application Architecture \n\n Human → Creative UI → Project State → WebMCP Tool Layer → AI Agent → Creative Services \n\n The application maintains structured project context so an agent can understand the current task, inspect available assets, perform multi-step operations, and iterate based on human feedback. \n\n Backend & Data \n\n \n Server-side API routes for AI operations \n Secure environment-variable configuration for API credentials \n Structured project and asset state \n Modular service architecture for future AI providers \n Validation and error handling around agent tool execution \n \n\n Deployment \n\n The application is designed for production web deployment with: \n\n \n HTTPS \n Environment-based configuration \n Responsive desktop/mobile experience \n Public live demo \n Public open-source repository \n Reproducible development and deployment workflow \n \n\n Open-Source Architecture \n\n The project is intentionally modular so developers can extend the WebMCP tool registry with additional creative capabilities, connect new AI providers, and build their own agent-driven workflows. \n\n Core principle: AI Experiment BD is not simply an AI website with a chatbot. It is a tool-enabled creative environment where WebMCP gives AI agents a structured interface to the application's real capabilities. \n\n \n\n \n Built With \n\n agentic agents ai bengali css engineering generation generative image mcp multimodal next.js prompt react rest storytelling tailwind typescript voice webmcp workflows \n \n\n \n Try it out \n\n \n \n \n aiexperimentbd.netlify.app \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n I designed and developed **AI Experiment BD** as the primary creator, developer, and architect.
