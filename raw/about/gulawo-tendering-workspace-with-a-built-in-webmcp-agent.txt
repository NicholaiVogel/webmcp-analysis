An AI agent lives inside Gulawo: it finds open tenders, scores fit, checks your document vault, flags disqualifying deviations, and drafts proposals you approve before anything is saved. Like Comment Story Updates demo demo demo Inspiration East African SME contractors don't lose government tenders on price. They lose on a missing PPDA certificate. A deadline buried in a procurement portal. A compliance gap nobody caught until it was too late. That admin, the finding, the tracking, the checking, the paperwork, is exactly what beat the teams that could actually do the work. Gulawo exists to close that gap. What it does A contractor signs in, uploads a real certificate, hands a tender to the agent, and the agent works the whole pipeline inside the app. It searches open tenders, pulls the full brief, scores fit against the company's actual profile, checks the document vault against the compliance checklist, and scans the bid security against the stated guarantee so the fatal gap is caught before anyone submits. The agent proposes. The human approves. Nothing touches the bid until someone clicks Approve. How we built it Next.js and React for the workspace, and a WebMCP layer that declares six tools in the manifest and registers the same six on the page with document.modelContext.registerTool . Each tool dispatches to a typed function that runs real SQL against the live database, so the workflow is identical whether a human drives the cockpit in the browser or an agent calls the tools from ChatGPT's embedded browser with WebMCP enabled. It degrades gracefully if the API isn't there and is guarded by a session cookie. Challenges we ran into Making it watchable. The unbounded agent route we tried first was slow and unreliable, so we made the recorded path deterministic and database-backed, and bounded every step so one slow call could never blow the three-minute limit. A recording quirk taught us what the eye actually follows. A new tool's result is prepended above older ones, and an early cut scrolled the bottom card into view while the narration described the new one. Fixing the recorder to center the card it was talking about, and to actually reveal the proposal and the kanban, took more patience than the app itself. Accomplishments that we're proud of Credibility over confidence. Every WebMCP tool is deterministic. It returns structured JSON computed from real SQL against real tenders, the real compliance rule set, and the real uploaded documents. If the tool says a UGX 12 million bid security is short of the required two percent, that's arithmetic against an actual tender record, not a comforting guess. And human approval isn't a checkbox. Lookup tools run freely, but nothing persists until a person approves. What we learned For a contractor, credibility beats confidence. An agent that sounds sure about compliance is worthless if it's wrong and costs them a bid. That's why Gulawo doesn't guess. And we saw firsthand what people and agents can now do together that was hard before. Before, an assistant could only read whatever the page rendered. Now a small contractor gets a defensible answer in seconds. Is this tender worth it? Are we legally ready to bid? Is there a compliant draft held for sign-off? Instead of hours of paperwork or a disqualification. What's next for Gulawo Turn the six tools into a persistent compliance watchman. Let the agent monitor open tenders against the vault continuously, alert the contractor the moment a new tender matches, and keep draft proposals current as tenders change. Grow the readable tender pool beyond Uganda into Kenya, Tanzania, and Rwanda, and let the vault check itself against each market's rule set. And push deeper on the collaborative loop that WebMCP makes possible. The agent works the pipeline in the same session, with the human holding the final say, all the way to submission.
