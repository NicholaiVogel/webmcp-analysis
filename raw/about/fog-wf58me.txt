Asking chat made up recipes. I wanted a helper that only knows what I've unlocked. \n\n What it does \n\n Fog is a second-monitor companion for that kind of game. You mark bosses beaten and what you're carrying. An agent talks to the page through WebMCP — craft, housing, what's next. Later stages aren't registered as tools, so it can't pull them. \n\n How it's built \n\n Vite, React, TypeScript. Hosted static on Vercel. \n\n Eleven WebMCP tools via document.modelContext.registerTool . Eight always on. Three flip with your stage (craft list, recipe lookup, hints) using AbortController. \n\n Game data and gating live in the page. Demo scenarios so judges can poke it without owning the game. \n\n Challenges \n\n WebMCP only shows up in the right browser (ChatGPT in-app or Chrome with the flag). The model may still recall the game from training — we only control what the page tools expose.
