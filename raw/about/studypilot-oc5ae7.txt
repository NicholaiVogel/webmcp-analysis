Most study planners are designed primarily for humans to interact with through buttons and forms, but we wanted to explore a different approach: what if an AI agent could work with the same study planner alongside the student? \n\n This idea led us to build StudyPilot, a study planner designed from the beginning to support both human users and AI agents. \n\n The WebMCP Challenge gave us the opportunity to explore how websites can expose structured capabilities to AI agents instead of forcing agents to rely only on traditional UI interaction. \n\n What it does \n\n StudyPilot is an AI-agent-ready study planner that lets students organize and manage their academic tasks. \n\n Through the normal web interface, students can: \n\n Add study tasks with subjects, priorities, dates, and estimated time\nView their study tasks\nMark tasks as completed\nDelete tasks\nGenerate a prioritized study plan \n\n The same functionality is also exposed through WebMCP tools, allowing compatible AI agents to interact with the application programmatically. \n\n StudyPilot currently provides five WebMCP tools: \n\n add_study_task\nget_study_tasks\ncomplete_study_task\ndelete_study_task\ngenerate_study_plan \n\n This creates a simple human + AI collaboration model where the student can use the interface directly while an AI agent can use structured tools to help manage their study workflow. \n\n How we built it \n\n We built StudyPilot as a lightweight web application using: \n\n HTML — application structure\nCSS — responsive interface and visual design\nJavaScript — application logic and task management\nWebMCP — exposing StudyPilot functionality to AI agents\nLocalStorage — persistent task data in the browser \n\n The application uses WebMCP's document.modelContext.registerTool API to register the five tools. \n\n We designed each tool with clear inputs and outputs so that an AI agent can understand what the tool does and interact with StudyPilot without needing to manually navigate the UI. \n\n We also deployed the application publicly so the project can be tested as a live web application. \n\n Challenges we ran into \n\n One of our biggest challenges was understanding how to design a normal web application while also making its functionality accessible to AI agents. \n\n We had to think beyond traditional button-based interactions and define structured tools, parameters, and tool responses that an agent could reliably understand. \n\n Another challenge was making sure that actions performed through WebMCP stayed synchronized with the user interface and persisted correctly using LocalStorage. \n\n We also had to test each WebMCP tool individually and fix issues such as parameter naming and ensuring the tools were correctly registered and discoverable. \n\n Accomplishments that we're proud of \n\n We are proud that we turned a simple study planner into an application that can be used by both humans and AI agents. \n\n Some accomplishments we're particularly proud of: \n\n Built and deployed a complete working study planner\nImplemented five functional WebMCP tools\nMade the same underlying study data accessible through both the UI and WebMCP\nAdded persistent task storage using LocalStorage\nImplemented automatic prioritized study-plan generation\nTested all WebMCP tools successfully\nCreated a public live demo and open-source repository \n\n Most importantly, StudyPilot helped us move from simply building a website to thinking about how websites can become usable interfaces for AI agents. \n\n What we learned \n\n This project taught us that building for AI agents requires a different way of thinking about web applications. \n\n Instead of only asking "What buttons should the user click?", we also had to ask: \n\n "What capabilities should an AI agent be able to discover and use?" \n\n We learned how WebMCP tools can expose specific application capabilities in a structured way and how human interfaces and agent interfaces can coexist within the same application. \n\n We also gained practical experience with JavaScript, browser storage, tool registration, debugging, deployment, and testing an AI-agent-ready web application. \n\n What's next for StudyPilot \n\n StudyPilot is currently a lightweight prototype, but we see several possibilities for expanding it. \n\n Future versions could include: \n\n AI-powered personalized study recommendations\nAutomatic task creation from assignments or syllabi\nCalendar and reminder integration\nProgress tracking and analytics\nCloud synchronization across devices\nMore advanced AI-agent workflows\nCollaboration between students and AI agents for long-term study planning \n\n Our long-term goal is to make StudyPilot more than just a task manager — a study companion where students stay in control while AI helps them plan, organize, and execute their learning goals. \n\n \n\n \n Built With \n\n css3 github html5 javascript localstorage vercel webmcp \n \n\n \n Try it out \n\n \n \n \n studypilot-webmcp.vercel.app \n \n \n \n GitHub Repo \n
