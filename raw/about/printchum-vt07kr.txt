Problem Statement \n\n Creating standardized ID and document photo layouts is a daily necessity for photo studios, print shops, schools, and individuals. However, the existing workflow is plagued by significant friction: \n\n \n Tedious Manual Workflows: Arranging multiple photo sizes (such as 2 × 2 in, 1 × 1 in, Passport, and Wallet sizes) in desktop software like Photoshop or MS Word requires manual cropping, repetitive copy-pasting, and tedious alignment calculations. \n Physical Dimension Inaccuracies: Generic image editors often distort real-world physical dimensions during export or printing, leading to rejected government, passport, or school application photos due to incorrect millimeter specifications or DPI downsampling. \n Severe Privacy Risks: Most online photo tools require users to upload sensitive portraits and identity documents to remote cloud storage, where images may be stored indefinitely, indexed, or exposed to data breaches. \n Wasted Photo Paper: Without optimal 2D bin packing, manual sheet layouts result in low paper utilization and expensive photo paper waste. \n \n\n \n\n 2. Solution Overview \n\n PrintChum eliminates manual layout preparation by delivering an automated, privacy-first, browser-local photo layout engine. \n\n Users upload a photo once, adjust the crop framing, and select standard presets or custom packages. PrintChum’s deterministic layout algorithm instantly packs the required photo quantities onto the target paper sheet, overlays precision cutting guides and nameplates, and generates a print-ready PDF or triggers direct printing. \n\n Privacy-by-Design Architecture \n\n PrintChum processes images locally within browser memory : \n\n \n Image cropping, color composition, nameplate rendering, layout packing, and vector PDF compilation occur entirely on the client side. \n Customer photos are never stored in databases or permanent cloud storage . \n External server communication is strictly limited to optional AI background removal, where images are processed in-memory and immediately returned to the client without persistence. \n \n\n Mathematical Precision & Real-World Dimensions \n\n PrintChum maps screen pixels to true physical print dimensions using exact unit conversion constants:\n 1 in = 2.54 cm = 25.4 mm = 72 pt (PDF) = 300 px (at 300 DPI) \nThe 2D shelf-packing engine optimizes the printable area after subtracting horizontal and vertical margins ($M_x$ and $M_y$):\n W printable = W paper − 2 ⋅ M x , H printable = H paper − 2 ⋅ M y \nPaper utilization efficiency is computed deterministically:\n Utilization Efficiency  ( % ) = ( ∑ i = 1 n w i ⋅ h i W printable ⋅ H printable ) × 100 % \n\n \n\n 3. Key Features \n\n \n Single Crop, Multi-Size Distribution: Crop and position a portrait once; PrintChum automatically resizes, frames, and renders it across multiple target dimensions (2 × 2 in, 1 × 1 in, 1.5 × 1.5 in, Passport, 2R, Wallet, or Custom sizes). \n Deterministic Layout & Multi-Page Pagination: Automatically arranges mixed photo sizes with customizable margins, horizontal/vertical spacing, and auto-rotation (0° or 90°), cleanly overflowing onto subsequent pages when needed. \n Precision Cutting Guides & Annotations: Renders corner crop marks, dashed cutting lines, and dimensional labels for effortless trimming with rotary or guillotine paper cutters. \n Dynamic Nameplates for IDs: Add customizable nameplates (inside or outside the photo frame) supporting Full Name, ID/Student Number, Department, Role, and custom styling (fonts, background colors, and borders). \n Reusable Studio "Service Sets": Save and load recurring package presets (e.g., "Package A: 2 pcs 2x2 + 8 pcs 1x1 on 4R Paper" ). \n Direct Vector PDF Export & 300 DPI Printing: Export vector-coordinate PDFs via pdf-lib at 72 points/inch with embedded 300 DPI image assets for crisp, uncompressed physical prints. \n Agentic WebMCP Integration: Native browser-level Model Context Protocol (WebMCP via document.modelContext ) enabling browser AI assistants to configure layouts, apply presets, and control the editor programmatically. \n \n\n \n\n 4. Technologies Used \n\n Frontend & Application \n\n \n Framework: Next.js (App Router, React 19) \n Language: TypeScript \n Styling & UI Components: Tailwind CSS, shadcn/ui, Radix UI, Lucide React \n State Management: Zustand \n Form Handling & Validation: React Hook Form, Zod \n \n\n Graphics, Layout & Export \n\n \n Image Framing & Cropping: react-easy-crop , HTML5 Canvas API \n Layout Engine: Custom framework-independent 2D shelf-packing & pagination algorithm \n PDF Compilation: pdf-lib (point-accurate physical coordinate rendering) \n Printing Engine: Native Browser Print API & Print-Specific CSS ( @media print , @page ) \n \n\n \n\n 5. Target Users \n\n \n Photo Studios & Freelance Photographers: Rapidly prepare standard client packages without opening complex desktop editing suites. \n Print Shops & Internet / Computer Cafes: Serve walk-in customers seeking quick ID package prints with automated layout packing and zero paper waste. \n Schools, Universities & HR Departments: Standardize ID badge photo formatting and student/employee nameplates at scale. \n Individual Job Seekers & Travelers: Create exact-dimension passport, visa, resume, and government ID photos at home with guaranteed sizing compliance. \n \n\n \n\n \n Built With \n\n next.js react typescript webmcp zustand \n \n\n \n Try it out \n\n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n Hack The Limit \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Roswell James Vitaliz \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Roswell James Vitaliz \n started this project\n \n —\n \n 7 days ago \n \n \n\n
