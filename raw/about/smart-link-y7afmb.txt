We wanted to build one platform that replaces all of them, \nand takes it a step further by letting AI agents do the complex marketing setup work \non behalf of the user. \n\n What it does \n\n Smart Link is a link management and bio page platform with full WebMCP agent support. \n\n Users can create short links, build bio landing pages, track real-time analytics \nby country and device, run A/B tests to find the best-performing URL, and protect \ntheir links from bot traffic automatically. \n\n What makes Smart Link unique is its agent-native design. When opened in ChatGPT's \nin-app browser, the platform exposes three WebMCP tools that AI agents can use: \n\n \n create_marketing_link: Creates a fully-configured tracking link in one step — \nwith geo-targeting rules (route Saudi users to an Arabic page, French users to \na French page), device routing (mobile vs desktop), UTM tracking parameters, \nA/B testing between multiple URLs, and bot protection. A task that would normally \ntake a marketer 15 minutes across multiple tools now takes one sentence. \n get_link_analytics: Retrieves total clicks, human vs bot breakdown, top countries, \ndevice types, and A/B test results for any link by short code. \n shorten_url: Instantly shortens any URL without requiring an account. \n \n\n How we built it \n\n The platform is built with a full-stack architecture using React, Tailwind CSS, \nand Vite on the frontend, deployed on Vercel. The backend runs on Node.js with \nExpress.js, MongoDB Atlas for persistence, and Redis for caching and rate limiting, \ndeployed on Fly.io. We use Brevo for email campaigns and Lemon Squeezy for \nsubscription billing. \n\n For WebMCP, we registered the three agent tools directly in the HTML using \ndocument.modelContext.registerTool(). We built a dedicated public API endpoint \nthat AI agents call to create links with full marketing configuration. When a \nlogged-in user opens the site in ChatGPT's browser, their session token is read \nautomatically so created links appear in their personal dashboard. \n\n Challenges we ran into \n\n The biggest technical challenge was achieving sub-150ms redirect speeds while \nsimultaneously recording click analytics and running bot detection in real time. \nWe solved this by caching redirect targets in Redis and processing analytics \nasynchronously in the background. \n\n For WebMCP, the challenge was designing a public API that exposes advanced features \nlike geo-targeting and A/B testing to AI agents, while preventing abuse through \nstrict rate limiting and Google Safe Browsing URL safety checks on every request. \n\n Accomplishments that we are proud of \n\n Smart Link is a live production application with 41 registered users and over \n1,800 tracked clicks — built and running before this hackathon. We are proud of \nthe sub-150ms redirect performance and being one of the first link management \nplatforms to expose agent-native WebMCP tools, allowing marketers to set up \ncomplex geo-targeted, bot-protected campaigns through a single natural language \nconversation. \n\n What we learned \n\n We learned how to design APIs that serve both humans and AI agents — with clear \nparameter descriptions, meaningful error messages, and structured responses that \nagents can reason about. We also deepened our understanding of Redis caching \nstrategies for high-traffic systems. \n\n What's next for Smart Link \n\n We plan to add create_bio_page and run_ab_test as new WebMCP tools, letting agents \nbuild full landing pages and launch experiments without touching the UI. We also \nplan to add AI-powered UTM suggestions and integrate Facebook Pixel and Google Tag \nManager firing directly through the agent tools. \n\n \n\n \n Built With \n\n a/b-testing axios bot-detection brevo express.js fly.io geo-targeting github google-safe-browsing-api javascript jwt lemon-squeezy mongodb mongoose node.js qr-code rate-limiting react redis rest-api tailwind-css utm-tracking vercel vite webmcp \n \n\n \n Try it out \n\n \n \n \n www.by-smartlink.com \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n All Things Agentic Hackathon \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Smart Link \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Smart Link \n started this project\n \n —\n \n 9 days ago \n \n \n\n
