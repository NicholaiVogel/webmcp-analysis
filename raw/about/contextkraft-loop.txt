Reviewed context becomes agent-ready campaign work with exact handoffs, provenance, and human approval. Like Comment Story Updates ContextKraft Loop keeps reviewed decisions connected to the work built from them. WebMCP gives the live app a precise agent interface for reading reviewed context, preparing versioned handoffs, saving structured campaign/ad/scene outputs, returning results, comparing dependency changes, and applying only human-approved updates. The memorable proof changes a campaign CTA from GUIDE to START: dependent work is identified and updated while an independently edited camera instruction remains unchanged. The deployed standalone release includes three workspaces, strict contracts, IndexedDB persistence, explicit JSON envelopes, change comparison, and native WebMCP tools tested in Codex's in-app browser. The MIT-licensed public repository includes setup, automated tests, verification records, and synthetic evidence. Broader ContextKraft integration remains ongoing and is not claimed as deployed.
