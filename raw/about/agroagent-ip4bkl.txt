Farmers need to know when to plant, what crops are suitable, which inputs to use, what the weather may look like, and where they can get better market information.\nThe inspiration for AgroAgent came from my work developing Smart Agro Insight, an agricultural technology concept designed to help smallholder farmers access agricultural information and make better decisions using data and technology.\nI wanted to take that idea one step further.\nInstead of building another agricultural chatbot that simply gives farmers answers, I wanted to explore a future where an AI agent can actually interact with agricultural web services and tools on behalf of the farmer.\nThis led to AgroAgent: an AI-powered agricultural web agent designed around WebMCP. The goal is to make the web more useful to farmers by allowing an AI agent to discover and interact with agricultural capabilities rather than simply generating text.\nThe project was founded and developed by Yahaya Abubakar under YABTECH SMART AGRO INSIGHT ENTERPRISES.\nWhat It Does\nAgroAgent is an AI-powered agricultural decision-support platform for smallholder farmers, cooperatives and agribusiness users.\nA farmer can communicate with AgroAgent using natural language instead of navigating through many different agricultural services.\nFor example, a farmer can ask:\n"I want to plant maize on 2 hectares in Sokoto. Help me prepare."\nAgroAgent is designed to break this request into useful agricultural actions.\nThe platform includes WebMCP tools for:\nWeather information — checking weather conditions relevant to farming.\nCrop information — finding information about crops, growing conditions and risks.\nAgricultural inputs — searching for suitable seeds, fertilizer and crop-protection products.\nProduct comparison — comparing available agricultural inputs.\nFarm planning — creating a production plan based on crop and farm size.\nFarm-plan saving — saving the generated plan for later use.\nThe platform also includes:\nFarmer dashboard\nAI Agricultural Agent\nWeather dashboard\nCrop information\nAgricultural input marketplace\nMarket intelligence\nFarm plans\nFarmer profiles\nAdministrator dashboard\nWebMCP tool diagnostics\nThe important difference is that AgroAgent is designed around the interaction between the farmer, the AI agent and web tools.\nInstead of:\nFarmer → AI → Answer\nwe are building:\nFarmer → AI Agent → WebMCP Tools → Agricultural Information/Actions → Farmer\nHow We Built It\nWe started with the Smart Agro Insight agricultural concept and created a new WebMCP-focused application called AgroAgent.\nThe prototype was designed as a modular web application so that the agricultural services and AI interaction layer can evolve independently.\nThe application includes a responsive dashboard designed for both desktop and mobile users.\nWe created a dedicated WebMCP tool layer containing six core tools:\nget_weather\nsearch_crop_info\nsearch_products\ncompare_products\ncreate_farm_plan\nsave_farm_plan\nThe WebMCP implementation is structured around the browser's document.modelContext.registerTool() API so that the tools can be exposed to compatible AI agents.\nWe also created a data layer that currently provides a local-storage fallback for prototype testing and a Supabase-ready database architecture for production development.\nThe database structure includes entities for:\nFarmers\nCrops\nProducts\nMarket prices\nFarm plans\nAgent activity\nThe administrator dashboard is designed to provide a central place to manage farmers, farm plans and platform activity.\nFor the prototype, weather, market and agricultural product information is clearly identified as demo data. The architecture is designed so verified live APIs and Supabase can replace the demo layer as the project moves toward pilot implementation.\nChallenges We Ran Into\nOne of our biggest challenges was understanding how to move beyond a conventional AI chatbot and build an application where the website itself exposes useful capabilities to an AI agent.\nWebMCP introduced a different way of thinking about web applications. Instead of designing only screens and buttons for humans, we had to think about what capabilities an AI agent should be able to discover and use.\nAnother challenge was balancing ambition with the limited time available for the hackathon.\nAgriculture has a very large scope. We initially had many possible features including weather forecasting, market intelligence, farm records, crop recommendations, agricultural inputs, buyers, supply-chain information and administrative management.\nWe therefore narrowed the first version to a focused workflow: helping a farmer plan maize production.\nWe also faced the challenge of building a meaningful WebMCP implementation while keeping the application usable in environments where native WebMCP support may not yet be available. To solve this, the prototype includes a local testing fallback while keeping the actual WebMCP registration layer separate and ready for testing in a supported environment.\nAnother challenge was ensuring that we did not present demo agricultural information as real-world advice. Therefore, demo weather and market information is explicitly labelled as prototype data and is intended to be replaced with verified sources before production deployment.\nAccomplishments We Are Proud Of\nWe are proud that AgroAgent evolved from an agricultural idea into a working prototype with a clear agent + web tools architecture.\nOne of our biggest accomplishments is creating a dedicated set of agricultural tools that can be registered through WebMCP rather than building only a traditional chatbot.\nWe are particularly proud of the farm-planning workflow.\nA farmer can express a goal in natural language, and the application can identify the relevant agricultural operations required to produce a farm plan.\nWe also built:\nA complete agricultural dashboard\nAI agent interface\nSix WebMCP tool definitions\nAgricultural crop database structure\nAgricultural input catalogue\nMarket intelligence interface\nFarm-plan management\nFarmer profile\nAdministrator dashboard\nAgent activity logging\nSupabase-ready database schema\nMobile-responsive interface\nOpen-source project structure\nMost importantly, AgroAgent demonstrates a different vision for agricultural technology: AI should not only tell farmers what to do; AI should be able to interact with useful agricultural services and help complete tasks.\nWhat We Learned\nWe learned that building an AI application is not only about the AI model.\nThe real value comes from connecting AI to useful tools, structured information and actions.\nWebMCP helped us think about the web as something an AI agent can interact with rather than simply something a human browses.\nWe learned to design tools around clear actions and inputs. For example, instead of asking an AI to "know everything about agriculture," we can give it specific capabilities such as:\nGet weather.\nSearch crop information.\nSearch agricultural products.\nCompare products.\nCreate a farm plan.\nSave a farm plan.\nWe also learned the importance of building a focused MVP. A smaller workflow that works clearly is more valuable than a huge platform containing many unfinished features.\nFinally, we learned that agricultural technology must be built responsibly. Weather, market and agronomic information can affect real financial decisions, so production deployment must use reliable, verified data sources and clearly communicate uncertainty.\nWhat's Next for AgroAgent\nThe next stage is to move AgroAgent from a prototype toward a real pilot implementation with farmers.\nOur priorities are: \n\n \n Real WebMCP deployment\nWe will test the WebMCP tools in the supported environment and verify that AI agents can discover and execute them through the live application. \n Supabase integration\nWe will connect the production database so farmer profiles, farm plans, products, market information and agent activity can be securely stored. \n Verified agricultural data\nWe will replace demo weather and market information with reliable data sources and agricultural information appropriate for the target communities. \n Local agricultural intelligence\nWe want AgroAgent to become increasingly useful for farmers in northern Nigeria, starting with Sokoto and expanding to other agricultural communities. \n More agent actions\nFuture tools could allow the agent to:\nFind agricultural buyers\nCreate market listings\nTrack farm activities\nMonitor crop risks\nGenerate production budgets\nCompare input costs\nTrack market opportunities\nSupport cooperative management \n USSD, SMS and mobile access\nMany farmers may not have reliable smartphones or internet access. We therefore plan to explore USSD and SMS access alongside the web and mobile experience. \n Pilot with real farmers\nThe ultimate goal is to test AgroAgent with real smallholder farmers, agricultural cooperatives and agribusiness stakeholders, measure whether it improves decision-making, and continuously improve the system based on their feedback.\nOur long-term vision is to build an agricultural ecosystem where farmers do not have to search through many disconnected services themselves. They can simply tell an AI agent what they need, and the agent can interact with trusted agricultural web services to help them accomplish it.\nAgroAgent is our step toward an agricultural web where AI doesn't just answer — it acts.\nThis version is suitable for a Devpost project description and keeps the distinction between the current prototype and future production features clear. \n \n\n \n\n \n Built With \n\n agents agriculture ai apis css3 design github html5 javascript localstorage open responsive source supabase technology web webmcp \n \n\n \n Try it out \n\n \n \n \n youtu.be \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n yahaya yabo abubakar \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n yahaya yabo abubakar \n started this project\n \n —\n \n 2 days ago \n \n \n\n
