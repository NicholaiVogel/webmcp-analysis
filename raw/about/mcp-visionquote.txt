MCP VisionQuote was born from that friction — an AI estimator that combines Model Context Protocol (MCP/WebMCP) with domain \n knowledge from real-world low-current projects. Every surveillance or cabling quote starts with the same questions: how many cameras, how much cable, which conduits, how many man-hours? Experienced integrators can estimate a site in\n minutes, but clients still wait days for a polished proposal. I wanted to capture that expertise in a tool that reads project context through MCP tools, reasons about layouts and \n requirements, and returns a quote an installer can trust. \n\n What it does \n\n How we built it \n\n MCP VisionQuote exposes domain-specific tools through MCP/WebMCP: estimate_project , get_bom , generate_proposal , and suggest_camera_placement . The backend is Python 3.12 + \n FastAPI, with a lightweight SQLite store and a seed price catalog. A FastAPI web UI lets users enter site parameters and instantly see a BOM, labor estimate, and commercial proposal. I \n used YOLOv8-nano for optional photo-based placement suggestions, and Render + Cloudflare Tunnel for the public deployment. \n\n Challenges we ran into \n\n The hardest part was not the code — it was encoding field reality. Camera counts change when a hallway has no ceiling access. Cable lengths explode when plenum routes are blocked. I \n had to balance AI speed with installer-grade accuracy, so every recommendation includes assumptions that a human can review and override. Trust, not full automation, became the real \n goal. \n\n Accomplishments that we're proud of \n\n What we learned \n\n Domain experience is the differentiator. Generic LLMs can write a quote; only a system grounded in low-current installation practice knows why a quote is wrong. MCP proved to be the \n right glue: it keeps project data separate from reasoning, making the estimator easier to audit, extend, and connect to other tools. \n\n What's next for MCP VisionQuote \n\n MCP VisionQuote is a practical step toward AI-assisted field estimating — built by someone who has pulled the cable, mounted the cameras, and argued about the labor hours. \n\n \n\n \n Built With \n\n fastapi mcp python render sqlite tailwind-css webmcp yolov8 \n \n\n \n \n\n \n\n \n \n \n Created by\n \n\n \n \n \n \n I built MCP VisionQuote end-to-end as a solo developer, from the initial idea and architecture to the Python/FastAPI backend, WebMCP tools, user interface, testing, and deployment.
