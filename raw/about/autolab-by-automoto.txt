Agent-native WebMCP tools for configuring, understanding, and building the car you share with an AI. Like Comment Story Updates AutoLab unifies an AI-operable vehicle configurator, a synchronized Garage digital twin, a visual Owner's Guide, and the code-native 3D Creation Engine behind them. Across five page contexts it defines 49 WebMCP tool registrations: 3 landing tools, 17 configurator tools, 14 embedded Garage tools, 13 standalone Owner's Guide tools, and 2 Creation Engine tools. Agents can safely inspect and revise a build, calculate pricing and ownership outcomes, direct a shared 3D vehicle, reveal and measure 42 named components, and inspect the measurement-driven workflow used to build the model. Human input interrupts active agent transactions, mutations are revision-gated and undoable, and results state their source or measurement basis. Built with TypeScript, React 19, Three.js, React Three Fiber, Vite, Vitest, Playwright, Zod, Zustand, GLSL, Node.js, Python, GitHub Pages, Claude Code, and OpenAI Codex. The fictional Hudian RX2 is an independent reconstruction fitted to public dimensions and photographs, not manufacturer CAD.
