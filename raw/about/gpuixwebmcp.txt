While working with WebMCP, I felt there was a missing developer tool for seeing what tools a webpage exposes and what happens when those tools are called. \n\n So I built gpuiXwebmcp, a native debugger for WebMCP using Rust and GPUI. It connects to a WebMCP-enabled Chrome tab and lets you see the available tools, inspect their schemas, execute them, and view the execution results. \n\n The main idea is simple: instead of guessing what an agent is doing inside a browser, developers should be able to see the tools and their execution clearly. \n\n I built the project to learn more about WebMCP, GPUI, browser communication, and building native developer tools with Rust. One of the main challenges was connecting the browser environment with a native GPUI application and keeping the tool and execution state synchronized. \n\n This project is still an early experiment. The next things I want to explore are agent execution, tool-call replay, better debugging information, and connecting local AI models to the WebMCP tools. \n\n \n\n \n Built With \n\n chrome gpui javascript json rust webmcp websockets \n \n\n \n Try it out \n\n \n \n \n gpuixwebmcp.avikm744.workers.dev \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Avik Mukherjee \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n\n \n Arshdeep Singh \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n WINNER - AWS DATA EXCHANGE CHALLENGE, RallyToUS Hackathon, Innovative Projects Competition On Energy Conservation And Energy Efficiency \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Avik Mukherjee \n started this project\n \n —\n \n 3 days ago \n \n \n\n
