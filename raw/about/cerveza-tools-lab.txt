Over time, it became one of those side projects that mostly sat untouched. \n\n While exploring ideas for the WebMCP Challenge, I realized it was a good project to bring back to life. The calculators already represented useful, deterministic domain capabilities that could be exposed to agents without asking a language model to perform the calculations itself. \n\n That idea became Cerveza Tools Lab. \n\n What it does \n\n Cerveza Tools Lab is a shared brewing workspace where a brewer and an AI agent can work on the same batch. \n\n Through WebMCP, the agent can read the current brew, use tools for hydrometer correction, alcohol, dilution, IBU and carbonation, and update the brew when requested. Changes made manually in the UI are also immediately available to the agent. \n\n For example, if the measured gravity is higher than the target, the agent can read the values directly from the brew, calculate the required dilution and, after user approval, apply the adjustment. \n\n How I built it \n\n Cerveza Tools is my existing React and TypeScript library. During the challenge, I added optional WebMCP bindings to expose its calculation functions as agent-accessible tools. \n\n Cerveza Tools Lab is the new application built for the challenge. It adds shared Current Brew state and contextual WebMCP tools, allowing the UI and the agent to work with the same data and underlying brewing logic. \n\n Challenges and learnings \n\n The main challenge was deciding where agent capabilities should live and keeping human and agent state synchronized. \n\n Separating deterministic calculations from application context resulted in a simple architecture: Cerveza Tools knows how to calculate, while the Lab knows what the user is currently brewing. \n\n My primary takeaway was that WebMCP becomes particularly beneficial when an application reveals both its existing functionalities and its current context. Instead of merely adding a chatbot on top, it facilitates the seamless collaboration between humans and agents within the same application. \n\n \n\n \n Built With \n\n react typescript vite webmcp \n \n\n \n Try it out \n\n \n \n \n GitHub Repo \n \n \n \n three-fourteen.github.io \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Andy Pi \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Andy Pi \n started this project\n \n —\n \n 3 days ago \n \n \n\n
