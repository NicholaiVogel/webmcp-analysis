I wanted to treat AI agents as first-class citizens by implementing the official W3C WebMCP standard, Utilizing a passive display website into an interactive, zero-hallucination agent runtime. \n\n What it does \n\n \n Dual W3C WebMCP API : Implements both the Imperative JavaScript API ( document.modelContext.registerTool with 11 native capabilities) and the Declarative HTML Forms API ( <form toolname="send_inquiry" toolautosubmit="true"> with Resend email delivery). \n UI Event Bus : Synchronizes a visual interaction in real time. When an agent queries skills or projects, matching nodes in the Skill Graph visual feedback can be seen. \n Autonomous Recruiter Audit Workflow : AI recruiter agents can cross-reference declared skills against reviewed project evidence snapshots and generate a verified, printable Candidate Dossier. \n In-Page Simulator Drawer : Allows Users to test all 11 tools, presets, and direct JSON arguments without needing Chrome 149 experimental flags. \n \n\n How I built it \n\n \n Framework & UI : Next.js 16 (App Router & Turbopack), React 19, TypeScript 5.9. \n AI Standard : W3C WebMCP ( document.modelContext ) & Declarative HTML Attributes. \n Graphics & Motion : Three.js WebGL particle field, Anime.js telemetry, Framer Motion. \n Video Production : Programmatic motion graphics rendered using HyperFrames. \n \n\n Challenges I ran into \n\n \n Designing an architecture that works in Chrome 149 with experimental flags while building an in-page fallback simulator so users on any browser can test the exact same tool execution pipeline. \n Coordinating asynchronous tool execution events with React state across interactive 3D particle fields and physics decks without causing re-render lag. \n \n\n Accomplishments that I'm proud of \n\n \n 100% W3C WebMCP standard compliance across 11 registered tools and declarative forms. \n Creating a bi-directional visual event bus where background agent calls manipulate the frontend UI. \n Producing a verified, evidence-backed candidate audit workflow that eliminates LLM hallucinations. \n \n\n What I learned \n\n \n How standardized agent-to-browser protocols like WebMCP will web scraping on a person's portfolio can now be done easily with agents. \n \n\n What's next \n\n \n Adding multi-agent collaborative workspace
