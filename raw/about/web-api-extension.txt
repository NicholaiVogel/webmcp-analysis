While both the SaaS and API are not directly supported anymore, and new tech like WebMCP are unlikely to be added -- they are still used daily by hundreds of thousands of merchants across the world. \n\n What if that B2B SaaS could support WebMCP without the vendor needing to make any changes? A WebMCP browser extension could uplift it to the latest tech, until the next version - possibly years away - supports WebMCP natively. \n\n What it does \n\n The product is a browser framework that uplifts a legacy SaaS to support WebMCP, even if the SaaS itself does not expose tools to the agent. The browser extension jumps in. It provides full context to the agent: backend power plus browser tab content. \n\n How we built it \n\n An existing, battle proven MCP server was converted into a Chrome extension, features added (BYOK chat, telemetry/security chokepoint, sandboxed code execution, many others), and the concept was then used to architect an extension development framework for future browser extensions that will provide the same benefit to other SaaS that need uplifting. \n\n Challenges we ran into \n\n Basic model: a bit weak on the reasoning front, needs guidance. Advanced model: too much reasoning, needs guidance. Interesting problem to have! \n\n Accomplishments that we're proud of \n\n The showcase extension, covering one specific B2B SaaS, was presented to a future user. They confirmed that it would be useful. \n\n What's next for Web API Extension \n\n The showcase extension has been released for UAT usage (private link in the web store as it's tailored to one SaaS). The showcase extension has now been abstracted to become a browser extension framework. This framework needs development. Also: Extending the framework to involve other emerging tech such as MCP-B or in-browser models. \n\n \n\n \n Built With \n\n chrome.storage code-mode-sandbox eslint extension.js-v2.1.3-targeting-manifest-v3 javascript node.js npm postcss prettier react tailwind typescript utcp vitest webmcp zod \n \n\n \n Try it out \n\n \n \n \n GitHub Repo \n \n \n \n www.linkedin.com \n \n \n \n\n \n\n \n\n \n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Stefan Laetzer \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n 1 \n \n \n\n\n \n 1 person likes this:\n \n\n \n \n \n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Stefan Laetzer \n started this project\n \n —\n \n 10 days ago \n \n \n\n
