We built Pluno WebMCP for Anything to turn that repeated work into a shared tool registry. \n\n What it does \n\n A Chrome extension injects the existing tools for each website.\nCodex uses the available tools to complete the task. If the tools are not sufficient, codex builds a reusable tool while completing the task, then submits it to Pluno for review. Approved tools become available to everyone. \n\n Challenges we ran into \n\n \n Codex's built-in browser doesn't support extensions \n Codex via Chrome doesn't support WebMCP\n-> Made it work via workarounds (injecting as separate Pluno object in page context), but we're really looking forward to both of these being supported to make it work natively. \n \n\n Accomplishments that we're proud of \n\n Time reduction of >80% for several tasks we tested.\nExample task (finding getaways on Airbnb): \n\n \n Normal codex: 6m 22s \n Codex with Pluno WebMCP - first run: 7m 35s (completing the task + building the necessary tools) \n Codex with Pluno WebMCP - second run: 1m 3s (completing task via available tools) \n \n\n What we learned \n\n Security is crucial, but ChatGPT really helps for this:\nWe added a Sol-based review of tool suggestions in the backend, and with extensive penetration testing we weren't able get any tool definitions approved that had unintended side effects. \n\n What's next for Pluno - WebMCP for anything \n\n \n Submit plugin to marketplace \n Push for native support of WebMCP for external browser, and extension support for native Codex browser. \n Run agents on popular websites to warm up the tool registry. \n Improve the tool-building guidance, harden the security of the tool review. \n Add measures against tool explosion (too many tools for too specific things) \n \n\n \n\n \n Built With \n\n codex \n \n\n \n Try it out \n\n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Korbinian Abstreiter \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n Co-Founder pluno.ai \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Korbinian Abstreiter \n started this project\n \n —\n \n 2 days ago \n \n \n\n
