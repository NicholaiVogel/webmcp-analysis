This inspired us to build Agent Studio, where AI can perform editing tasks and suggest changes while humans approve important creative decisions. \n\n What it does \n\n Through WebMCP, the agent can interact with the video editor to:\n🔍 Inspect projects and understand the current editing state\n✏️ Modify captions and caption styling\n⏱️ Adjust scene durations\n🎬 Search real stock footage based on the video's content\n💡 Propose visual changes to improve the edit\nHuman-in-the-Loop\nThe key idea behind Agent Studio is controlled autonomy.\nAI agents can handle repetitive editing work, but consequential visual changes aren't applied blindly. Instead, the agent presents proposed changes for human approval.\nThis keeps the creator in control of the final creative decisions while allowing AI to handle tedious production task.\nThe agent operates the tools. The creator controls the outcome. \n\n ## How We Built It \n\n We built Agent Studio as a web-based video editor with WebMCP tools that let AI agents inspect projects and perform editing actions. The agent can modify captions, adjust scene durations, search Pexels for relevant stock footage, and propose visual changes. A human approval layer ensures important changes are reviewed before they are applied. \n\n Challenges we ran into \n\n The biggest challenge was making AI interactions with the video editor reliable while keeping humans in control. We also had to handle real-time WebMCP tool calls, stock footage search, and ensure consequential edits required approval instead of being applied automatically. \n\n Accomplishments that we're proud of \n\n We built a working environment where AI agents can interact with a real video editor through WebMCP while keeping humans in control. We're especially proud of combining agent-powered editing, real stock footage search, and human approval into one collaborative workflow. \n\n What we learned \n\n We learned that AI agents can be powerful creative collaborators when they have structured tools and clear boundaries. WebMCP showed us how agents can interact with real creative workflows, while human approval makes that automation safer and more useful. \n\n What's next for Agent Studio \n\n We plan to: \n\n Add more WebMCP editing tools for transitions, audio, effects, and layouts.\nSupport multiple specialized agents working together on a project.\nImprove the approval system with side-by-side previews and edit history.\nAdd smarter stock-footage recommendations based on each scene.\nEnable creators to save, reuse, and share agent workflows. \n\n \n\n \n Built With \n\n ai-agents and css pexels-api react tailwind typescript vite vs-code webmcp \n \n\n \n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Muhammad Abdulrehman \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Muhammad Abdulrehman \n started this project\n \n —\n \n 2 days ago \n \n \n\n
