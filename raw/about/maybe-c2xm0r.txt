Codex can discover the page’s Site Tools, read its live state, create or edit choices, configure the dice, trigger a roll, read the physical result, and save reusable decision cards—all inside the same shared interface. Maybe currently exposes nine page-local WebMCP tools, while human clicks and agent actions operate on the same application state. \n\n No grand theory of life.
