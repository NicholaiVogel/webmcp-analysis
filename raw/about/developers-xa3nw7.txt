I wanted to explore the future of the agent-native web by building a platform where AI agents and humans collaborate seamlessly. The WebMCP standard inspired me to expose structured tools directly to the agent, eliminating the friction of traditional UI scraping and guesswork. \n\n What it does \n\n This web application acts as a smart platform where users can interact via a standard visual interface, while AI agents can securely access the same underlying data catalog through WebMCP. Agents can search for items, filter by specific criteria, and process data requests instantly on behalf of the human user. \n\n How I built it \n\n I built the frontend using Next.js and React , creating a clean, minimalist user interface. The backend logic is powered by Node.js and TypeScript , managing data through a PostgreSQL database. \n\n To integrate the AI capabilities, I implemented the WebMCP standard by registering core tools directly in the client:\n document.modelContext.registerTool({ ... }) \nThis allows the ChatGPT in-app browser and Chrome WebMCP environments to read the exposed schema and execute data-fetching commands reliably. \n\n Challenges I ran into \n\n One of the main challenges was designing strict inputSchema definitions for the WebMCP tools to ensure the AI agent always passes the correct parameters without hallucinating fields. I also had to optimize the database queries to guarantee that the agent's rapid, automated requests wouldn't create bottlenecks on the server. \n\n Accomplishments that I'm proud of \n\n I successfully deployed a fully functional WebMCP-enabled application that dramatically reduces the time it takes to execute complex search and filter operations. Seeing the AI agent understand and execute commands directly through the provided tools rather than struggling with the UI was incredibly rewarding. \n\n What I learned \n\n I learned how to structure agent-facing APIs and bridge the gap between traditional human-first web development and new agent-native standards. Working with WebMCP completely changed my perspective on how web applications should be architected moving forward. \n\n What's next \n\n I plan to add more advanced tools, such as automated transaction handling and personalized recommendation algorithms, to further enhance the agent's ability to assist users autonomously. \n\n How we built it \n\n Challenges we ran into \n\n Accomplishments that we're proud of \n\n What we learned \n\n What's next for Developers \n\n \n\n \n Built With \n\n next.js node.js postgresql react sqlite typescript vercel webmcp \n \n\n \n Try it out \n\n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n CESAR DANIEL RODRIGUEZ HERRERA \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n CESAR DANIEL RODRIGUEZ HERRERA \n started this project\n \n —\n \n 8 days ago \n \n \n\n
