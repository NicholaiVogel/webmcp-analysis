Instead of treating safety as a hidden behavior, it exposes governance as something that can be observed, audited, and verified. \n\n Build Week additions \n\n \n WebMCP-ready governance interface. \n Developer-focused documentation and onboarding. \n Live governance observatory concept. \n Installation and testing guidance for judges. \n \n\n What it does \n\n \n Governs AI outputs through the PRAXIS pipeline. \n Tracks constitutional state (Continuity, Reciprocity, Sovereignty). \n Generates cryptographic audit receipts. \n Supports replayable governance history. \n Provides a production governance API. \n \n\n Why WebMCP \n\n WebMCP lets AI agents interact with websites through structured tools instead of guessing UI actions. Lex Aureon extends this by exposing governance capabilities as reusable tools such as govern_prompt, verify_receipt, constitutional_state, and replay_receipt. \n\n Technical architecture \n\n WebMCP Adapter → Existing Governance API → PRAXIS → Audit Receipt. \n\n The WebMCP layer wraps the existing governance pipeline rather than replacing it, preserving production behavior while enabling agent-native interactions. \n\n Installation and testing \n\n \n Live demo: https://lexaureon.com \n Public repository: https://github.com/omomehinemmanuel5-boop/LEX-Aureon \n Core endpoint: POST /api/lex/govern \n Public audit trail: /audit \n Benchmarks: /benchmarks \n \n\n Judges can test the live deployment directly without rebuilding the project. \n\n How Codex and GPT-5.6 were used \n\n During Build Week, Codex and GPT-5.6 accelerated documentation refinement, architecture planning, WebMCP integration planning, developer experience improvements, and submission preparation while preserving the existing production governance pipeline. \n\n \n\n \n Built With \n\n groq mcp next.js openai turso typescript vercel webmcp \n \n\n \n Try it out \n\n \n \n \n lexaureon.com \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Omomehin Emmanuel \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Omomehin Emmanuel \n started this project\n \n —\n \n 3 days ago \n \n \n\n
