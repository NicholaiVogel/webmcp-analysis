A browser-native mission control where agents inspect tasks, verify evidence, and propose actions while humans retain final authority. Like Comment Story Updates What I built Mission Center WebMCP is a browser-native mission control where agents can inspect tasks, trace dependencies, verify evidence, and propose safe next moves while humans remain the only authority who can approve lifecycle changes. Why WebMCP matters Mission Center already treats task state, evidence, handoffs, and verification as explicit, reviewable concepts. WebMCP makes those semantics available directly to browser agents instead of forcing them to infer meaning from pixels or DOM structure. The tools share the same live in-page state, evidence model, proposal queue, human approval UI, and audit trail as the person viewing the mission control. Human and agent collaboration The judge journey asks an agent to find the task in Review, inspect whether its evidence is current, and propose the safest next lifecycle move. The agent discovers WMC-103, checks its passing evidence, and proposes Review → Done. The task remains in Review and a pending proposal appears. A human then reviews the proposal and clicks Revalidate & approve. Mission Center rechecks the task revision and completion evidence before moving the task to Done. The agent has no approval tool and cannot silently change lifecycle truth. Agent calls, proposals, and human decisions remain separate and auditable. How it was implemented The app is a static HTML/CSS/ES module site with zero backend and zero API keys. It registers eight imperative tools through document.modelContext.registerTool, keeps validated state in browser storage, exposes proposal-only agent mutations, and enforces a human evidence/revision gate. The repository includes deterministic Node tests, verification scripts, and a GitHub Pages deployment workflow. Prior work disclosure This competition edition is derived from the existing MIT-licensed Codex Mission Center project. The frozen upstream baseline is documented in UPSTREAM_BASELINE.md. Browser WebMCP support, agent tools, proposal workflow, judge UX, and the static deployment are the challenge work.
