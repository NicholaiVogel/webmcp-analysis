Taking hands off of my instrument disrupts the practice flow when every beat counts. Despite many chrome extensions and tools trying to free musician’s hands, I believe AI’s computer use will be the interface to stitch all of these tools together so musicians can focus on their session. \n\n Built on top of Waveform Playlist and using patterns from using Logic Pro \n\n What it does \n\n \n Ask the agent to control the drum, metronome, and piano tracks \n Record with Browser Audio \n \n\n How we built it \n\n Use code mode to allow the agent to clone the current session data and edit the instruments, notation, and rhythm in one turn. \n\n Challenges we ran into \n\n \n Exploring use cases that justifies tool calls executed browser side when I am used to server propagating states over web sockets. \n ChatGPT voice dispatches subagent so its hard to stay within the same session of WebMCP \n \n\n Accomplishments that we're proud of \n\n \n Embracing a voice-first UX \n Heavy use of AudioContext API in the browser \n \n\n What we learned \n\n \n Voice mode would open in-app browser in the background that couldn’t be closed manually, leading to bad UX on session cleanup \n \n\n \n\n \n Built With \n\n dawcore typescript \n \n\n \n Try it out \n\n \n \n \n handsonthekeys.com \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Steven Tsao \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n 1 \n \n \n\n\n \n 1 person likes this:\n \n\n \n \n \n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Steven Tsao \n started this project\n \n —\n \n a day ago \n \n \n\n
