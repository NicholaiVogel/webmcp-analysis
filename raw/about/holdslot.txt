A person and an in-browser agent share the same screen. \n\n The agent can search open slots and place a hold . The hold is visible on the board with a timer. Confirm is a human-only button. There is no confirm tool. The agent cannot complete a booking. \n\n Live: https://holdslot-cyan.vercel.app \nRepo: https://github.com/devtechedge/holdslot \nDemo: https://www.youtube.com/watch?v=AnjYWBRFELY \n\n Why WebMCP \n\n Agents are bad at calendars. They click the wrong cell, double-book, or submit while the person looks away. \n\n WebMCP lets the page own the tools: \n\n \n search_slots — open slots by day and duration \n hold_slot — hold for 3 minutes (does not book) \n list_holds — current holds and time left \n release_hold — drop a hold \n get_board — full board snapshot \n request_confirm — ask the human to confirm ( does not confirm ) \n \n\n The UI updates when a tool runs. The person always sees the hold, the timer, and the confirm step. \n\n What people and agents do together \n\n \n Agent: search and hold while you watch \n You: reject a bad hold, or press Confirm booking \n Both: same URL, same state \n \n\n How it is built \n\n Static HTML / CSS / JS on Vercel. document.modelContext.registerTool(...) on load. In-memory slots. Works in ChatGPT’s in-app browser or Chrome with chrome://flags/#enable-webmcp-testing . \n\n What I learned \n\n Page-owned tools beat “agent, please click the button.” The useful part of WebMCP is a shared, visible contract: the agent can hold, the human still owns the commitment. \n\n \n\n \n Built With \n\n css html javascript vercel webmcp \n \n\n \n Try it out \n\n \n \n \n holdslot-cyan.vercel.app \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Dev M \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Dev M \n started this project\n \n —\n \n a day ago \n \n \n\n
