What it does WebMCP tools usually let agents use the app. EgoLens flips it: agents extend the app. Together, a person and an agent can now add a dataset format to a viewer in minutes, in the browser, without touching the source code. Drop a folder EgoLens does not recognize and the page becomes a WebMCP tool provider. The agent inspects files within strict byte limits, reads the recipe schema and operator vocabulary, and submits adapter recipes as declarative JSON, never code. Every validated revision renders in the production 3D viewer, docked next to the review panel : orbit, scrub the timeline, toggle boxes and segmentation, switch camera POVs. You accept or reject each capability with a named issue and the verdict flows back to the agent. Finalize seals the recipe with content hashes; it can be exported, imported, and shared. Every taught format stays: drop that layout again and it renders in one click. The app's capabilities keep growing, and files never leave the browser. How we built it Five tools registered on document.modelContext : inspect , get_contract , apply_revision , get_state , finalize . Self-describing descriptions, normalized inputs, string results, so ChatGPT's browser, Chrome's native WebMCP, and the Codex app drive them with zero agent-specific code. Recipes are data, executed in an isolated graph runtime with resource limits. The person confirms the sensor layout before teaching starts; a recipe that does not bind exactly those sensors is rejected. React 19, TypeScript, three.js, Web Workers, IndexedDB, GitHub Pages. 1,100 unit tests and Playwright probes that drive Chrome's real WebMCP end to end. Challenges we ran into Agents stopping at the timeline. Fixed without shipping any dataset example, which would leak the answer: a sensor contract, coverage diagnostics, and a next-step hint in every state read. Bugs only eyes can catch. PandaSet stores cuboid yaw along the width axis. Every automated check passed and the boxes were rotated 90° on screen. That is why the full renderer is the review surface. Host budgets. Codex caps descriptor size and call latency; in-app browsers hang on the File System Access API. Each constraint pushed the tool surface toward the plainest contract. Accomplishments that we're proud of Three unknown datasets taught end to end by agents in one week: A2D2 (3 revisions, 6 cameras + 6 LiDARs fused), KITTI Raw (7 revisions), PandaSet (world-frame poses, pandas pickles). No example recipe is ever shown to the agent. The same five tools work unchanged across three hosts, and each dataset taught left EgoLens able to read more than before. What we learned The interesting question is not "what can an agent do in my app" but "what can an agent make my app able to do". Expose the extension points as tools and the agent's output becomes an artifact a person can inspect, reject, seal, and share. The person's rejections were the most valuable signal in the loop.
