BakeryFlow was created to simplify these operations. \n\n For the WebMCP Challenge, I am extending BakeryFlow into an agent-native ERP where AI agents can interact directly with real business workflows using WebMCP. \n\n What it does \n\n BakeryFlow Agent allows an AI agent to understand and interact with bakery operations. \n\n Using WebMCP, an agent can: \n\n \n Check raw material inventory \n Retrieve product recipes \n Calculate ingredients required for production \n Detect inventory shortages \n Find suppliers \n Prepare or create purchase orders \n Create production runs \n \n\n For example, a manager can ask: \n\n "Can we produce 1,000 chocolate cookies?" \n\n The agent can inspect the recipe, calculate the required ingredients, compare them against current inventory, identify shortages, and help take the next required action. \n\n How I built it \n\n BakeryFlow uses a React frontend with a Django REST Framework backend and PostgreSQL database. \n\n For this challenge, WebMCP is being integrated into the frontend to expose selected ERP capabilities as structured tools that AI agents can discover and use. \n\n The WebMCP layer reuses BakeryFlow's existing business logic and APIs instead of creating a separate system specifically for AI agents. \n\n WebMCP Challenge Work \n\n BakeryFlow existed before the WebMCP Challenge. \n\n The core ERP functionality, including inventory, recipes, suppliers, purchases, and production management, was already part of BakeryFlow. \n\n For this challenge, I am adding the WebMCP integration and agent-native workflows that allow AI agents to securely interact with those existing capabilities. \n\n Challenges \n\n One of the main challenges is turning complex ERP workflows into clear and safe agent tools while preserving the existing validation, permissions, and business rules. \n\n Another challenge is designing tools that agents can combine into useful multi-step workflows rather than simply exposing individual CRUD operations. \n\n What's next \n\n The goal is to expand BakeryFlow Agent so an AI agent can assist with the complete production lifecycle — from demand planning and inventory analysis to purchasing, production, stock movement, and business insights. \n\n \n\n \n Built With \n\n django javascript postgresql python react rest vercel webmcp \n \n\n \n Try it out
