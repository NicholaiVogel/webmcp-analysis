I wanted the agent to do this directly inside the website. \n\n What it does \n\n RigSpec is a PC builder that both the user and a WebMCP agent can control. \n\n The agent can search parts, compare them, edit the build, and check compatibility. \n\n How we built it \n\n React, JavaScript, Vite, WebMCP, and a local PC parts dataset. \n\n The WebMCP tools use the same state and data as the UI. \n\n Challenges \n\n Product names are often ambiguous, and some catalog data is incomplete. \n\n I also had to make sure agent changes and manual user changes stayed synchronized. \n\n Accomplishments \n\n The agent and user actually work on the same interface instead of having a chatbot on the side. \n\n It also still works normally without WebMCP. \n\n What we learned \n\n WebMCP works well when an agent needs to interact with an existing website. \n\n Small tools also worked better than one big "build a PC" tool. \n\n What's next \n\n Better pricing data, more compatibility checks, saved builds, and testing with more WebMCP agents. \n\n \n\n \n Built With \n\n docker javascript nginx node.js react vite webmcp \n \n\n \n Try it out \n\n \n \n \n pcpartpicker.mob5.dev \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Julian Gunadi \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Julian Gunadi \n started this project\n \n —\n \n 3 days ago \n \n \n\n
