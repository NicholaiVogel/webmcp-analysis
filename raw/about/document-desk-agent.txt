The assistant can prepare actions, but the user reviews and approves them before anything is applied. \n\n WebMCP is used to expose these document actions directly to the agent as structured tools instead of forcing the agent to interact with the interface by clicking buttons visually. \n\n This creates a workflow where the agent understands the available document operations, prepares useful changes, and collaborates with the user through explicit approval steps. \n\n \n\n \n Built With \n\n css github html javascript openai pdf.js webmcp \n \n\n \n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n UM-PT Mueller \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n UM-PT Mueller \n started this project\n \n —\n \n 2 days ago \n \n \n\n
