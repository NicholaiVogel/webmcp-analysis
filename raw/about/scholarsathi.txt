Government portals can involve confusing eligibility rules, long document checklists, repeated data entry, and multiple application stages. Students pay for assistance 50 inr to 100 inr and still not understand why they qualify, what is missing, or what happens next. \n\n We wanted to create a safer alternative: a shared workspace where an AI agent can handle the complicated preparation work while the student remains informed and in control. \n\n ## What we built \n\n ScholarSathi helps students: \n\n \n discover representative scholarship programs; \n assess eligibility using deterministic rules; \n identify missing information and documents; \n prepare and validate an application draft; \n request explicit human approval; \n submit and track a simulated application. \n \n\n WebMCP is fundamental to the product. ScholarSathi exposes focused tools that an AI agent can discover and compose, rather than forcing the agent to guess how buttons and forms work. Tool calls update the same visible interface the student uses, creating shared state between the human and the agent. \n\n ## How we built it \n\n ScholarSathi is a static application built with semantic HTML, modern CSS, vanilla JavaScript ES modules, and local JSON-style data. It uses browser localStorage for privacy-safe demo persistence and requires no backend, account, external API, or LLM service. \n\n The application includes: \n\n \n a deterministic eligibility engine; \n shared profile, document, application, and civic-service state; \n validation and readiness checks; \n a two-phase human approval workflow; \n idempotent simulated submission; \n responsive and accessible UI; \n 26 imperative WebMCP tools with strict schemas and structured results. \n \n\n \n\n \n Built With \n\n and browser-localstorage deployment html5 json-seed-data modern-css netlify/vercel/github static vanilla-javascript-es-modules via webmcp-imperative-api \n \n\n \n Try it out \n\n \n \n \n openai-hackathon-scholar-sathi.vercel.app \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Umair khan \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Umair khan \n started this project\n \n —\n \n 3 days ago \n \n \n\n
