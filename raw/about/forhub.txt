I created forhub to simplify that process, keep privacy and control in focus, and explore how MCP and WebMCP can help AI agents support our daily lives. \n\n What it does \n\n forhub brings small apps into one browser workspace, with code editing, interactive previews, project management, and data storage. Compatible AI agents can help build and interact with these tools through scoped MCP and WebMCP interfaces. \n\n How we built it \n\n Built with TypeScript, React, and CodeMirror on Cloudflare Workers, using D1, R2, and Durable Objects for storage and application state. OpenSpec guided development, with automated browser, runtime, and security tests. \n\n Challenges we ran into \n\n Initial deployment still requires too much technical knowledge. Making infrastructure setup approachable for ordinary users—while keeping private data protected and agent permissions clear—is a key challenge. \n\n Accomplishments that we're proud of \n\n forhub makes personal ideas feel achievable, from agent-assisted recipe management to easier mind-map drafting. Spending less effort on setup gives me more freedom to experiment and make everyday life a little better. \n\n What we learned \n\n I estimate the foundation is about 90% complete, but turning it into an intuitive product takes substantial work. This competition taught me how much UI and UX matter: powerful capabilities need clear, comfortable interactions. \n\n What's next for forhub \n\n Simplify the interface and deployment process, develop reusable community guidance, evaluate how reliably models follow it, and make Demo development faster and easier. \n\n \n\n \n Built With \n\n cloudflare-agents-sdk cloudflare-d1 cloudflare-durable-objects cloudflare-r2 cloudflare-workers codemirror indexeddb javascript mcp playwright react sqlite typescript vite vitest webmcp wrangler zod \n \n\n \n Try it out \n\n \n \n \n space.forhub.cc \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Lany Rix \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Lany Rix \n started this project\n \n —\n \n a day ago \n \n \n\n
