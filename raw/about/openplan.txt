OpenPlan was inspired by the need to centralise renovation information and make everyday updates or queries quick and simple. \n\n What it does \n\n OpenPlan provides one shared place to manage renovation projects, floors, spaces, budgets, tasks, notes, and timelines. Its WebMCP integration lets homeowners use natural language in ChatGPT to read, create, update, and delete project information while the interface remains the central source of truth. \n\n How we built it \n\n We built OpenPlan with React, TypeScript, Vinext, Tailwind CSS, Zustand, and Cloudflare D1 for shared persistent data. Browser-native WebMCP and an unauthenticated Streamable HTTP MCP endpoint connect the same renovation data and tools to ChatGPT. \n\n Why WebMCP \n\n WebMCP fits OpenPlan because it lets homeowners manage complex renovation projects through simple natural-language requests while keeping the visual interface as the central source of truth. People and AI agents can now work together to create, review, update, and delete projects, floors, spaces, budgets, renovation items, notes, and timelines. \n\n \n\n \n Built With \n\n codex \n \n\n \n Try it out \n\n \n \n \n openplan-renovation.dominiconorton.chatgpt.site \n \n \n \n openplan-renovation.dominiconorton.chatgpt.site \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Dominic Norton \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Dominic Norton \n started this project\n \n —\n \n 3 days ago \n \n \n\n
