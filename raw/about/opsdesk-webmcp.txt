We wanted to build a web application designed specifically for the agent-native era—a unified workspace where human operators and AI agents collaborate seamlessly during system outages to diagnose latency spikes, inspect telemetry, and execute infrastructure remediation natively. \n\n What it does: \n\n OpsDesk WebMCP is an agent-native DevOps management workspace that exposes client-side operations directly to AI agents using the WebMCP standard ( document.modelContext ). Key functionalities include: \n\n \n Cluster Health Inspection ( get_cluster_metrics ): Enables agents to fetch live CPU usage, memory footprint, p99 latency, and error rates for targeted microservices. \n Dynamic Infrastructure Autoscaling ( scale_service_replicas ): Allows agents to scale pod replica counts up or down to mitigate degraded service performance, updating the visual dashboard UI in real-time. \n Synthetic Availability Testing ( run_synthetic_web_test ): Triggers browser automation benchmarks to check UI accessibility and endpoint response times. \n \n\n How we built it: \n\n \n Frontend & UI: Built using React and Tailwind CSS to render real-time service health, status indicators, and active pod replica counters. \n WebMCP Integration: Integrated @modelcontextprotocol/sdk on the client side, exposing native tool signatures directly via document.modelContext.registerTool . \n Agent Interoperability: Designed structured JSON input schemas and return payloads compatible with ChatGPT's in-app browser and WebMCP-enabled environments. \n \n\n Challenges we ran into: \n\n \n Client-Side Tool Synchronization: Ensuring state changes executed by an agent tool call (e.g., scaling replicas) triggered immediate visual UI updates in the React component hierarchy without requiring page refreshes. \n Schema Precision: Crafting clear, deterministic tool descriptions and JSON schemas so LLMs select the correct diagnostic or action tool under varied prompting scenarios. \n \n\n Accomplishments that we're proud of: \n\n \n Successfully implemented a functional browser-native WebMCP interface that allows an AI agent to execute end-to-end incident triage and infrastructure mitigation. \n Created a clean visual bridge where human engineers can monitor automated agent actions live on screen. \n \n\n What we learned: \n\n \n How WebMCP transforms static web applications into interactive, agentic workspaces by standardizing client-side tool discovery. \n Best practices for structuring agent inputs and fallback handling for robust client-side execution. \n \n\n What's next for OpsDesk WebMCP \n\n \n Adding multi-cluster support for cross-region failovers. \n Expanding tool execution security with human-in-the-loop confirmation prompts prior to executing high-impact scaling or rollback operations. \n \n\n \n\n \n Built With \n\n
