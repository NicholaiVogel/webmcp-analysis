\n \n \n \n \n\n \n \n WebMCP-selected service with AI-generated checklist for Driving License Renewal. \n \n 1 2 3 \n\n\n\n \n Inspiration \n\n Kuwait residents often know what they need to do, but not the exact government service or required documents. \n\n For example, someone may simply say: \n\n \n "I need to renew my driving license." \n \n\n or: \n\n \n "My residency was renewed and I need my Civil ID." \n \n\n I built Kuwait Life to make all users to use normal language to find the services they need. \n\n What it does \n\n Kuwait Life is a bilingual English/Arabic guide for Kuwait government services. \n\n Users can describe what they need in natural language and the application helps identify the most relevant service. \n\n The current MVP includes: \n\n \n Civil ID Renewal for Non-Kuwaitis \n Driving License Renewal \n Traffic Violation Inquiry and Payment \n Vehicle Registration Renewal \n \n\n For each service, Kuwait Life presents: \n\n \n responsible authority \n documents to prepare \n service requirements \n fee information \n available service channels \n official government source \n \n\n The interface supports both English and Arabic, including full RTL layout for Arabic. \n\n Why WebMCP \n\n The main feature of Kuwait Life is its WebMCP integration. \n\n Instead of an AI browser agent having to inspect the page visually, find controls, and simulate clicks, Kuwait Life exposes structured capabilities directly to WebMCP-compatible agents. \n\n The application currently exposes two WebMCP tools: \n\n find-kuwait-government-service \n\n This tool accepts a natural-language request such as: \n\n \n "I need to renew my driving license." \n \n\n It searches and ranks the available government services and returns structured service information. \n\n The same human-facing webpage also updates automatically, highlights the best matching service, and displays an AI selected state. \n\n create-kuwait-service-checklist \n\n After a service has been selected, an agent can call this tool to create a practical checklist containing the documents and requirements for that service. \n\n The checklist appears directly inside the webpage, where the human can continue interacting with it and mark items as completed. \n\n This creates a shared workflow between the AI agent and the person instead of replacing the website with a chatbot. \n\n Human + Agent Collaboration \n\n The experience is designed around both humans and AI agents using the same application: \n Human describes a situation\n ↓\nAI agent discovers WebMCP tools\n ↓\nAgent finds the relevant service\n ↓\nKuwait Life highlights the result\n ↓\nAgent creates a checklist\n ↓\nHuman works through the checklist\n ↓\nOfficial government source\n \n How I built it \n\n Kuwait Life was built with: \n\n \n Next.js \n React \n TypeScript \n Tailwind CSS \n WebMCP \n Vercel \n \n\n Government-service information is stored as structured application data. \n\n A search-ranking layer evaluates natural-language requests and ranks matching services. \n\n WebMCP tools are registered using document.modelContext.registerTool() and reuse the same search and service logic used by the human-facing application. \n\n Custom browser events connect WebMCP tool execution with the React interface so agent actions can visibly update the webpage. \n\n Challenges \n\n One of the main challenges was working with WebMCP in my first time and learning it concept. \n\n Another challenge how to design the AI experience so that it enhances website. \n\n What I learned \n\n This project helped me understand how WebMCP can make websites more agent-friendly. \n\n Instead of forcing AI agents to infer how a website works from its visual interface, websites can expose reliable structured actions directly to agents. \n\n Privacy and Safety \n\n Kuwait Life does not collect Civil ID numbers, passport information,or government login credentials. \n\n It does not submit government applications, process government payments, or access private government databases. \n\n The application provides informational guidance using public information and directs users to official government sources for the actual service. \n\n Kuwait Life is an independent informational project and is not affiliated with the Government of Kuwait. \n\n \n\n \n Built With \n\n css next.js react
