You open your figure, type what it\nshould do, and download the clip. The 20 tools sit inside the page where the figure\nruns, so the agent works on the same figure you are looking at. \n\n Better for the user \n\n No animation software, no rig setup. The page measures your figure itself — height,\nbone roles, sole points. The rest is one sentence in the chat, and you watch it happen. \n\n What is new \n\n Ask an agent for a backflip today and you get a figure that reaches through itself or\nbarely moves. Not because the AI is too dumb. It has too little to work with: it does\nnot know how tall the figure is, where its weight sits, how far a knee bends, or what\nits last move actually did. \n\n This page gives it all of that. You type a sentence, the agent builds the motion, and\nwhat comes out is usable. \n\n How it works \n\n 20 tools registered through document.modelContext.registerTool : describe the figure,\nset poses and joint angles, check the result, render an image. \n\n Everything the tools report is measured on the loaded model, not hardcoded. Answers\ncarry numbers with units, and when the solver misses what was asked, it says by how\nmuch. \n\n \n\n \n Built With \n\n javascript three.js webmcp \n \n\n \n Try it out \n\n \n \n \n urbanlama.github.io \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n urbanlama Blaschinz \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n 1 \n \n \n\n\n \n 1 person likes this:\n \n\n \n \n \n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n urbanlama Blaschinz \n started this project\n \n —\n \n 2 days ago \n \n \n\n
