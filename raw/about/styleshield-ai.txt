But programmers have individual habits in the way they name variables, structure functions, use loops, format code, write comments, and manage complexity. \n\n We wanted to turn these behavioral patterns into a unique Coding Fingerprint , similar to a digital identity for programming style. This idea led to StyleShield AI. \n\n What it does \n\n StyleShield AI analyzes a programmer's previous code samples and creates a Coding Fingerprint and Coding DNA based on their programming behavior. \n\n When a new code submission is provided, StyleShield: \n\n \n Extracts structural and behavioral coding features \n Compares the new code with established coding patterns \n Calculates a similarity score \n Uses machine learning for prediction \n Generates Coding DNA \n Provides programming-style/personality insights \n Produces an explainable verification result \n \n\n For the WebMCP Challenge, we extended StyleShield with WebMCP tools such as analyze_code , get_coding_fingerprint , and explain_verification . This allows AI agents to directly access StyleShield's analysis capabilities through structured tool calls while keeping the human involved in the final verification decision. \n\n How we built it \n\n We built StyleShield using Python, Flask, JavaScript, SQLite, and machine-learning techniques . \n\n The system extracts features such as variable naming, indentation, function structure, complexity, loops, comments, and AST-based characteristics. These features are combined to create a programmer's Coding Fingerprint and Coding DNA. \n\n We then developed a Flask API that connects the frontend to the analysis modules. \n\n For the WebMCP extension, we used document.modelContext.registerTool() to expose StyleShield functionality as structured WebMCP tools. These tools communicate with our Flask API and return structured JSON results that an AI agent can understand and use. \n\n Challenges we ran into \n\n One of our biggest challenges was connecting WebMCP with our existing Flask application while keeping the existing StyleShield functionality stable. \n\n We faced issues with asynchronous JavaScript requests, API responses, and exposing our local Flask application through a Cloudflare Quick Tunnel. At one point, the tunnel returned an HTTP 530 error, which initially looked like an application failure. \n\n After debugging, we identified the problem as tunnel connectivity rather than our StyleShield backend. We restarted the tunnel and successfully established communication between the WebMCP layer and our Flask API. \n\n Another challenge was representing programming style accurately. A programmer's identity cannot be determined from one feature, so we combined multiple coding characteristics to create a more meaningful fingerprint. \n\n Accomplishments that we're proud of \n\n We are proud that we transformed an existing programmer-code analysis concept into a WebMCP-enabled AI-assisted verification system . \n\n Our key accomplishments include: \n\n \n Building a working Coding Fingerprint system \n Generating unique Coding DNA \n Combining multiple programming-style features \n Integrating machine-learning-based prediction \n Building an explainable verification workflow \n Successfully registering multiple WebMCP tools \n Connecting WebMCP directly to our Flask analysis backend \n Successfully receiving structured analysis results through the WebMCP-connected application \n \n\n Most importantly, we learned how an existing application can be extended so that AI agents can directly use its capabilities instead of only interacting with its visual interface . \n\n What we learned \n\n We learned that programming style contains many subtle behavioral patterns that can be useful for identity verification. \n\n Technically, we learned how to build modular AI applications with Flask, connect frontend tools to backend APIs, handle asynchronous requests, work with structured JSON responses, and integrate WebMCP into an existing web application. \n\n We also learned that good human-agent interaction is not about replacing human decisions. Instead, an AI agent can gather evidence, perform analysis, and explain results while the human remains responsible for the final decision. \n\n What's next for StyleShield AI \n\n We plan to make StyleShield more robust and useful in real-world environments. \n\n Future improvements include: \n\n \n More advanced behavioral and semantic code analysis \n Larger and more diverse training datasets \n Cross-language programmer fingerprinting \n Stronger confidence and explainability mechanisms \n Continuous learning from new verified code samples \n Integration with coding assessment and educational platforms \n Advanced AI-agent workflows using additional WebMCP tools \n Programmer verification history and audit trails \n Better protection against intentional style imitation \n \n\n Our long-term goal is to make StyleShield a reliable programmer identity intelligence layer that can assist organizations, educators, and developers in understanding whether code is consistent with a programmer's established coding behavior. \n\n \n\n \n Built With \n\n analysis api artificial ast cloudflare coding css data fingerprinting flask html intelligence javascript jinja learning
