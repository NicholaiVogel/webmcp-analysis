It connects deterministic event discovery, privacy-safe social discovery, fictional places, shared planning, meetup preparation, and human approval in one visible workflow. \n\n The signature flow is search_events → find_nearby_friends → search_places → suggest_people_for_plan → human reviews and edits → create_group_meetup → human approves fictional invites . \n\n The application exposes nine strict native WebMCP tools. Read-only tools discover fictional events, profiles, coarse presence, friends, places, and recommendations. State-changing tools publish readOnlyHint: false and require a visible one-use human approval latch. Native tools and the React UI consume the same shared state, so human edits are observed by later agent calls. The agent cannot self-approve by passing confirmed: true . \n\n Hidden presence is never surfaced; city-only people reveal only their city; nearby people reveal only a coarse named neighborhood, never precise coordinates. No real messages, purchases, payments, authentication, backend, database, or external service are used. \n\n This standalone challenge prototype is inspired by the broader MySoci vision of social discovery, digital cities, personalized identity, and real-world experiences. It explores a future agent layer for MySoci; it is not the full MySoci product and contains no private/proprietary implementation. \n\n Built with React, TypeScript, Vite, native WebMCP document.modelContext, Vitest/JSDOM, deterministic local data, and static Vercel hosting. \n\n \n\n \n Built With \n\n openai-codex react typescript vercel vite vitest webmcp \n \n\n \n Try it out \n\n \n \n \n mysoci-agent-city-webmcp.vercel.app \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Elias Rafael \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Elias Rafael \n started this project\n \n —\n \n 7 days ago \n \n \n\n
