How much should I charge? How should I launch it? And how should I market it? \n\n We wanted to demonstrate how a human and an AI agent could work together, with the human making the important decisions while the AI handles structured tasks through WebMCP tools. \n\n What it does \n\n LaunchMate turns a business goal into a structured digital-product launch workflow: \n\n Goal → Product → Price → Launch → Marketing \n\n A user first enters a business goal, such as wanting to sell a digital product to students. \n\n LaunchMate then provides: \n\n \n Three digital product ideas \n A selected product \n A suggested price based on cost and margin \n A 7-day launch plan \n An AI-generated marketing kit \n \n\n The marketing kit includes: \n\n \n Target customer \n Value proposition \n Product description \n Marketing headline ideas \n Social media ideas \n Call to action \n \n\n The application also shows agent activity so users can see the actions performed during the workflow. \n\n How we built it \n\n LaunchMate was built as a lightweight web application using HTML, CSS and JavaScript. \n\n The application uses WebMCP tools as structured actions that an AI agent can discover and invoke. \n\n We created five WebMCP tools: \n\n \n set_business_goal \n suggest_product \n calculate_price \n build_launch_plan \n generate_marketing_kit \n \n\n The AI agent coordinates these tools in sequence. The application maintains the workflow state and renders the results back into the user interface. \n\n The project was also published as a public GitHub repository and configured for GitHub Pages deployment. \n\n Challenges we ran into \n\n One of the biggest challenges was making the AI-generated results reliably flow between the different stages of the workflow. \n\n In particular, the marketing stage required careful handling of structured WebMCP responses. The application needed to correctly map the returned data into the user interface while also providing fallback behavior when a tool response was incomplete. \n\n Another challenge was coordinating the human and agent actions. The user should be able to select a product while the agent can continue the workflow using the selected product. \n\n We also spent time testing the complete workflow from the initial business goal through product selection, pricing, launch planning and marketing generation. \n\n Accomplishments that we're proud of \n\n We are proud that LaunchMate demonstrates a complete human-and-AI workflow rather than simply generating text. \n\n The project connects multiple structured WebMCP tools into one workflow and makes the individual agent actions visible to the user. \n\n We are also proud of building a working end-to-end prototype that can take a simple business goal and turn it into a concrete launch plan. \n\n What we learned \n\n We learned that building an AI agent workflow requires more than generating good text. \n\n Reliable structured data, tool schemas, state management, error handling and UI rendering are all important parts of the experience. \n\n We also learned how WebMCP tools can provide a structured interface between an AI agent and a web application, allowing the agent to perform specific actions instead of relying only on unstructured responses. \n\n Most importantly, we learned that a good human-AI workflow should give the human control over important decisions while allowing the agent to handle repetitive and structured tasks. \n\n What's next for LaunchMate \n\n The current version focuses on the core web experience. \n\n Next, we would like to expand LaunchMate with: \n\n \n A more complete digital-product creation workflow \n Real payment and checkout integration \n Product landing-page generation \n More detailed marketing campaigns \n Analytics and sales tracking \n Additional AI-powered business tools \n A mobile application \n A fully deployed production version \n \n\n Our long-term goal is to turn LaunchMate into a practical AI business-launch assistant that helps people go from an initial idea to a real digital product and launch. \n\n \n\n \n Built With \n\n agents ai css github html javascript pages web webmcp \n \n\n \n Try it out \n\n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n
