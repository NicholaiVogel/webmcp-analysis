A bank export. A health record. Ten years of app history. The moment an AI is involved the implicit deal is "send us your data" — so most people just don't. That deal exists because of where the code runs, not anything fundamental. WebMCP changes where the code runs. \n\n What it does \n\n CSV and JSON exports load into DuckDB compiled to WebAssembly, running inside the tab. The agent writes the query, SiftIO runs it locally, and only the answer comes back, with an audit panel showing the number of rows held locally · and the number of rows seen by the agent. \n\n How we built it \n\n Angular 21 zoneless, DuckDB-wasm. Seven always-on tools plus two generated per dataset, whose input schema is built from that file's real columns. Registration is reactive; an effect watches the vault signal, so nothing calls registerTool from the UI. \n\n Challenges we ran into \n\n \n registerFileBuffer detaches the ArrayBuffer — nothing survived a reload. \n Numbers wrong three ways — BigInt throws, Number() corrupts above 2⁵³, sum() returns Decimal128 limbs as text. \n A chart that was never drawn — hidden canvas measured at zero. \n \n\n Accomplishments that we're proud of \n\n \n An agent really did use it and ChatGPT found the tools on the deployed site. \n A tool built for a file that didn't exist a moment ago. \n Trust you can check. \n Zero backend. \n \n\n What we learned \n\n I learned that WebMCP is a great tool, and it will change the way we interact with web apps. Learning such a tool is beneficial for building a futuristic AI Agent-friendly app without sacrificing security. \n\n What's next for SiftIO \n\n \n Real tool removal when Chrome ships unregisterTool. \n Shareable views without shareable data. \n An exportable audit. \n Importers for Apple Health XML, Google Takeout, bank dialects. \n \n\n \n\n \n Built With \n\n angular.js apache-arrow chart.js cloudflare-workers duckdb indexeddb javascript local-first sql typescript webassembly webmcp wrangler \n \n\n \n Try it out \n\n \n \n \n siftio.marouane-kouskous.workers.dev \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n marouane kouskous \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n marouane kouskous \n started this project\n \n —\n \n 3 days ago \n \n \n\n
