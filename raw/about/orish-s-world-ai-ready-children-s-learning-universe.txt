I wanted to create a safer, imaginative learning world where children do not simply watch content — stories can lead into real activities, learning and conversations with their families. \n\n As a mum building this independently, I have been learning the technology while developing the project. The Too-Fast Rocket became our first working story and teaches a simple lesson: STOP. LOOK. LISTEN. THINK. THEN TRY. \n\n What it does \n\n For the WebMCP Challenge, I created an AI-ready layer for Orish’s World. \n\n The demo uses WebMCP to expose structured learning actions directly from the webpage to compatible AI agents. Instead of an AI having to guess what a page offers, the website can describe useful actions as tools. \n\n The prototype includes tools for discovering an age-appropriate learning activity and accessing the Too-Fast Rocket lesson. \n\n How I built it \n\n The project is built for the web and deployed using Cloudflare Workers, with the source managed through GitHub. \n\n The WebMCP implementation uses document.modelContext.registerTool() to register Orish’s World learning actions with compatible AI environments. \n\n I deliberately connected the WebMCP experiment to a real project rather than creating a standalone technical demo. \n\n Challenges \n\n One of the biggest challenges was building and deploying this while learning the technology as I went. I also needed the normal website to remain usable even in browsers that do not currently expose WebMCP. \n\n The demo therefore detects WebMCP support and explains when the browser does not support it, while still containing the real registration code. \n\n What I learned \n\n I learned that websites can become more than pages designed only for people to click through. WebMCP creates the possibility of websites exposing meaningful, structured actions to AI agents. \n\n For education, that could eventually allow AI to help families navigate learning experiences while the website and parent remain in control. \n\n What's next \n\n Orish’s World is intended to grow into a wider learning universe with stories, reading, cooking, science and creative activities. \n\n My next step is to expand the WebMCP tools so AI can help families move between digital stories and useful real-world learning activities. \n\n \n\n \n Built With \n\n cloudflareworkers css github html javascript webmcp \n \n\n \n Try it out \n\n \n \n \n orishs-world-at-the-code.atthecode.workers.dev \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n This has been a crazy but really meaningful build for me.
