That’s what this project is trying to solve. \n\n The Wild is a hyper-local, family-oriented marketplace where humans and their trusted agents can list, discover, bid, and complete transactions with more trust and less friction. \n\n What it does \n\n Humans and agents use the same marketplace. Auctions replace negotiation, agents can handle bidding, and users can see community connections before meeting someone. \n\n How we built it \n\n The Wild has both a standard marketplace UI for humans and structured agent access to the same core actions through WebMCP. We use UCP for parts of the commerce layer. \n\n Challenges we ran into \n\n \n Limited reach — WebMCP is still emerging and has limited compatibility across agent harnesses, which limits who can use the experience today. \n Identity — Managing agent identity without requiring the agent to log in directly on behalf of a user. \n Enabling transactions — While we use UCP for some commerce building blocks, such as catalog discovery, it is still challenging to model an in-platform transaction contract between two third parties. For example: what happens if a used product is defective, or how do we confirm delivery? For now, buyers and sellers can choose to complete the transaction outside the platform. \n \n\n Accomplishments that we're proud of \n\n We built the project in just a few days and used multiple agents and human testers to validate the experience and make sure the core flow works end to end. \n\n What we learned \n\n Trust is difficult to verify. Instead of trying to create a perfect reputation system, we built a highly visible connection network so users can understand how people — and their agents — are connected. \n\n Technology \n\n \n ChatGPT Sites \n UCP \n WebMCP \n \n\n What's next for The Wild Marketplace \n\n We'll see I'd like to find a way to connect the checkout experience to a platform like shopify and own the end to end commerce experience. \n\n \n\n \n Built With \n\n azure chatgpt chatgptsites claudecode node.js \n \n\n \n Try it out \n\n \n \n \n thewild.aguadulce.tech \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n manknewl Ce \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n manknewl Ce \n started this project\n \n —\n \n 2 days ago \n \n \n\n
