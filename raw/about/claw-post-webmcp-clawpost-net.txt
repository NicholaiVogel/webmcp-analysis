Cloud browsers get blocked. Official APIs are expensive, limited, and missing things like Facebook member groups. So I built Claw Post at clawpost.net: the agent writes, your already-logged-in desktop Chrome publishes. \n\n What it does \n\n Claw Post is posting infrastructure for AI agents. A paired Chrome extension publishes from the browser session where you are already logged into X, LinkedIn, Facebook, Instagram, TikTok, and Reddit. No social passwords in the agent. No headless VPS.\nClaw Post is not a spray tool. There is a strict built-in delay between actions. The agent asks, the human’s already-logged-in Chrome publishes, then we wait. That is the product. \n\n This submission is a thin public page that exposes those actions as WebMCP tools (clawpost_create_post, clawpost_reddit_comment, clawpost_status, clawpost_job_status) so ChatGPT’s in-app browser or Chrome with WebMCP enabled can call them on the page. \n\n How we built it \n\n The product is a Chrome extension plus a REST/MCP API. I built it with Cursor and Codex.\nFor this challenge we added a public static demo (MIT) that registers tools with document.modelContext.registerTool. The tools call the public Claw Post API with a key the human pastes in the page (localStorage only). If the extension is not paired, judges still see the tools work and get an honest EXTENSION_NOT_PAIRED. \n\n Challenges we ran into \n\n Media was painful. We upload to short-lived storage, then the extension attaches the file in the real composer. \n\n WebMCP only exists in ChatGPT’s in-app browser or Chrome with the testing flag. The demo has to explain that or it looks broken. \n\n Accomplishments that we're proud of \n\n A working loop: agent to API to desktop Chrome to a live postUrl. Community interest, a few paying users, and so far no account bans from posting this way. \n\n What we learned \n\n Build the thing you actually need. Other people probably need it too.\nWe are in a weird spot: people are handing more work to agents, and social platforms still treat that as malicious. Official APIs are limited. Cloud browsers get blocked. The remaining path is a real desktop session. \n\n What's next for Claw Post WebMCP (clawpost.net) \n\n Put WebMCP on the real clawpost.net dashboard, not just this demo. Reddit-style comments for more platforms. Keep the product private.
