An agent shouldn't need to know about 12 specialized tools upfront - it should be able to ask one discovery layer and get routed to the right one. \n\n What it does \n\n The Decision Support Network (DSN) is a WebMCP-enabled discovery and routing hub for 12 specialized AI decision-support tools spanning healthcare, legal, housing, energy, education, and more. \n\n DSN demonstrates a two-hop agent workflow: \n\n \n An AI agent discovers DSN and uses its WebMCP tools to find the right decision-support capability \n DSN routes the agent to a second, specialized WebMCP-enabled Decision Support App (DSA) \n The agent calls the specialized tool directly for structured analysis \n \n\n WebMCP Tools: \n\n \n find_decision_tools - Natural-language intent matching \n search_tools - Keyword search across all registered tools \n list_categories - Browse tools by category \n \n\n Four Access Interfaces (one canonical routing engine): \n\n \n Browser WebMCP via document.modelContext.registerTool() \n Remote MCP (JSON-RPC 2.0) at /api/mcp \n REST API with full OpenAPI 3.1 spec \n Human UI at https://decisionsupportnetwork.com \n \n\n How we built it \n\n Built with Next.js, TypeScript, Prisma/PostgreSQL, and NextAuth v5. The routing engine uses LLM-backed intent matching with keyword fallback for deterministic parity across all four access surfaces. \n\n What's next \n\n Expanding the network with more decision-support tools and enabling agents to chain multiple tools for complex multi-step decision workflows. \n\n What's next for Decision Support Network \n\n \n\n \n Built With \n\n https://decisionsupportnetwork.com next.jstypescriptwebmcpmcpprismapostgresqltailwind \n \n\n \n Try it out \n\n \n \n \n decisionsupportnetwork.com \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Curtiss Witt \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Curtiss Witt \n started this project\n \n —\n \n 4 days ago \n \n \n\n
