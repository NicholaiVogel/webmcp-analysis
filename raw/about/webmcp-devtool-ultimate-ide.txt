Every site that registers tools via document.modelContext.registerTool() becomes a programmable surface — but today there is no developer tooling to discover those tools, inspect their schemas, invoke them locally, or stress-test edge cases before shipping integrations. This project fills that gap: it is a browser-native IDE for the agentic web. \n\n How it creates a better user experience \n\n Developers open the extension popup on any tab and instantly see every WebMCP tool exposed on that page — names, descriptions, and input schemas — without reading source code or wiring up an LLM. One click generates a mock payload from the schema; another invokes the tool in-page and surfaces the result or error inline. A formatted "Copy LLM Prompt" export lets teams hand off exact tool contracts to ChatGPT, Gemini, or other agents in seconds. \n\n What people and agents can do together that was difficult before \n\n Before WebMCP, integrating an agent with a web app meant reverse-engineering hidden APIs or building bespoke MCP servers. With WebMCP, the page itself advertises its capabilities. Our extension makes that contract visible and testable: a human developer can validate tool behavior, catch schema mismatches, and export orchestration context — while an agent on the same page can call the identical tools.
