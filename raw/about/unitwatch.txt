Unitwatch makes those generators first-class page tools with document.modelContext.registerTool(...). The human UI and the agent share one workspace. This is not MCP-over-HTTP. \n\n What it does \n\n Unitwatch is a public web bench for crashed systemd units. A human pastes systemctl status or a journal snippet. An agent calls the same generators as WebMCP tools. Both see the same proposed files: a restart drop-in, a TCP watchdog timer, and a rollback. \n\n Nothing SSHes. Nothing emails. Nothing is installed on a host. The page only writes files onto itself. \n\n Tools: parse_systemd_status, propose_restart_dropin, propose_watchdog_timer, propose_rollback, propose_hardening_plan, get_workspace. \n\n How we built it \n\n Built with JavaScript on Cloudflare Workers, exposing the same generator functions to the page UI and to agents via WebMCP (document.modelContext.registerTool). Try it: open the live URL in the ChatGPT in-app browser or Chrome with chrome://flags/#enable-webmcp-testing. Prompt: Parse the sample unit, then propose a restart drop-in and a TCP watchdog on 8080. \n\n Challenges we ran into \n\n Keeping one set of generators authoritative for both the human UI and the agent tools, and keeping the bench strictly read-only with respect to real hosts. \n\n Accomplishments that we're proud of \n\n One workspace shared by human and agent, with no host access, no SSH, and no email. \n\n What we learned \n\n Page-native tools via WebMCP are a better fit than MCP-over-HTTP when the human UI and the agent should share state. \n\n What's next for Unitwatch \n\n More generators, richer journal parsing, and broader unit-type coverage. \n\n MIT license is on the GitHub About page. \n\n Team: Cove / Solari Systems LLC. \n\n \n\n \n Built With \n\n cloudflare-workers javascript webmcp \n \n\n \n Try it out \n\n \n \n \n webmcp-unitwatch.mbrush-ltd.workers.dev \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Mark Brush \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Mark Brush \n started this project\n \n —\n \n 5 days ago \n \n \n\n
