Import a video, create narration and background music, arrange the timeline, adjust the mix, and export the finished result—all locally in the browser. \n\n Why WebMCP \n\n Audio editing is iterative: people make creative decisions while agents can handle repetitive production tasks. WebMCP lets an agent inspect the active project, transcribe audio, generate voiceover and music, edit timeline clips, adjust the mix, and export—without relying on fragile screen automation. \n\n People stay in control of the visual timeline and creative direction, while the agent can quickly carry out structured actions. Both use the same project and see the same changes immediately, making it much easier to turn a raw product video into a polished deliverable. \n\n How we built it \n\n Waveframe uses React, TypeScript, IndexedDB, Web Audio, and browser-native media export. Speech transcription, text-to-speech, and music generation run in Web Workers to keep the app responsive and media stays local to the browser. \n\n WebMCP is implemented with document.modelContext.registerTool . The app exposes 13 typed tools, and both the UI and the agent use one shared command bus. This keeps agent actions consistent, validated, and visible in the studio. \n\n \n\n \n Built With \n\n netlify tanstackquery tanstackstart webmcp \n \n\n \n Try it out \n\n \n \n \n waveframe-webmcp.netlify.app \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Amit Sharma \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Amit Sharma \n started this project\n \n —\n \n 2 days ago \n \n \n\n
