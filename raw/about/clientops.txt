This\n makes it easy to miss follow-ups, lose track of delivery\n work, or delay billing. \n\n I built ClientOps as an agent-native client-work command\n center. It brings projects, tasks, invoice drafts, and\n follow-ups into one workspace that both humans and AI\n agents can use. Through WebMCP, an agent can retrieve a\n workspace briefing, create work items, update task status,\n and prepare invoice or follow-up drafts. \n\n The app was built with a lightweight HTML, CSS, and\n JavaScript frontend, Supabase REST persistence, and Vercel\n deployment. WebMCP tools are registered with\n document.modelContext.registerTool() and include\n structured JSON schemas so agents can interact with the\n app reliably. \n\n A core design principle is human approval. Agents can\n prepare an invoice or message, but they cannot send it or\n charge a client automatically. This keeps automation\n useful without giving it unsafe control over financial or\n external actions. \n\n While building the project, I learned how to design AI-\n facing tool schemas, expose browser actions through\n WebMCP, persist frontend state to a hosted database, and\n create safe human-in-the-loop workflows. \n\n The main challenges were working with an evolving WebMCP\n API, supporting browsers where WebMCP is unavailable, and\n deciding which actions should be automated versus approved\n by a person. I addressed these with feature detection,\n fallback behavior, explicit read-only annotations,\n structured outputs, and draft-only financial workflows. \n\n ClientOps demonstrates how websites can become reliable\n working environments for both people and agents—not just\n interfaces that an AI has to interpret visually. \n\n \n\n \n Built With \n\n ai api automation chrome css design html human-in-the javascript json localstorage loop responsive rest schema static supabase vercel web webmcp \n \n\n \n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n AHcc408 Hait \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n AHcc408 Hait \n started this project\n \n —\n \n 9 days ago \n \n \n\n
