Alun Agent Desk explores a simple question: what if an agent could work directly with a trusted cultural evidence surface while human judgment remained visible and accountable? \n\n What it does \n\n Alun Agent Desk is a shared human-agent workspace for AI-and-music developments. A person can browse source-linked records and see their evidence status, geography, implications, and uncertainty. A WebMCP-capable agent can use four structured tools to search developments, inspect a record, compare jurisdictions, and prepare an audience-specific cultural brief. \n\n Every tool call changes the same visible interface. The person can see which evidence the agent selected, review the resulting brief, and verify the original sources. The app does not silently turn events, consultations, or platform policies into settled law. \n\n Why WebMCP \n\n Without WebMCP, an agent must infer meaning from page layout or conduct an unrelated web search. With WebMCP, Alun exposes a bounded, traceable evidence model directly to the agent. This makes the interaction faster and more reliable while preserving provenance and uncertainty for the human reviewer. \n\n The key collaboration is: the agent finds and structures evidence; people retain interpretation, legitimacy, and decision authority. \n\n How it was built \n\n The application is a responsive React and TypeScript site hosted on ChatGPT Sites. It registers four tools through document.modelContext.registerTool: search_developments, inspect_development, compare_developments, and prepare_cultural_brief. Tool results update React state so agent actions and the human review surface remain synchronized. \n\n The evidence set is deliberately small and source-linked. Search supports geography, status, and thematic filters, including explicit reporting when requested regional evidence is missing. \n\n Challenges and learning \n\n The main design challenge was preventing a polished brief from appearing more authoritative than its sources. The interface therefore keeps source URLs, evidence status, jurisdiction, and uncertainty visible. Testing also exposed a hidden audience filter that made tool results diverge from the visible list; it was removed so the agent and person now share the same result set. \n\n What is next \n\n The prototype can expand into the Alun Situation Room as a public cultural-technology evidence layer. Future work would add carefully reviewed records and institutional workflows without turning the tool into an automated policy authority. \n\n \n\n \n Built With \n\n chatgpt-sites \n \n\n \n Try it out \n\n \n \n \n alun-agent-desk.imanfattah.chatgpt.site \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Iman Fattah \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Iman Fattah \n started this project\n \n —\n \n 2 days ago \n \n \n\n
