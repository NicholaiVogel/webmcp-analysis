Turn an exact wall-art request into an inspected, printer-packed fabrication package through four visible WebMCP tools. Four structured WebMCP tools create, constrain, inspect, and prepare the same visible project. Inspection returns exact measurements and confirms all 81 parts fit across 62 plates. The final tool prepares a 656,651-byte fabrication package while the reviewer controls the download. Inspiration Creative manufacturing software has powerful controls, but an agent usually has to imitate mouse clicks or stop at advice. Relief Forge explores a more useful interaction: structured tools that operate the same deterministic design engine and visible editor a person uses. The motivating request is concrete: Make me a four-foot-square Polar Bloom statement piece with a reproducible design and fixed palette. Fit every part to my printer, validate the exact plan, and prepare the fabrication files. That request combines units, aesthetic intent, fabrication constraints, inspection, and a deliverable. It is a stronger use of WebMCP than adding a chat panel to a design application. What it does Relief Forge registers four focused WebMCP tools: relief_forge_create_wall_art creates supported deterministic wall art at exact finished dimensions. relief_forge_set_printer_bed applies explicit bed dimensions, edge margins, spacing, rotation, and color-packing rules. relief_forge_inspect_fabrication_plan reports the current project identity, measurements, part and plate counts, and digital geometry and packing status. relief_forge_prepare_fabrication_package prepares an export only for the current validated project snapshot, while leaving the final download as a visible reviewer action. The agent and person share one visible, editable project. A first-run Judge Quick Start card shows tool readiness, explains the workflow, and copies the exact reproducible prompt. How to run the agent demo Relief Forge is the shared workspace, not the chat. On first visit, the Judge Quick Start card shows whether all four WebMCP tools are ready. After the card reports 4 AGENT TOOLS READY , select Copy prompt for AI chat , return to the Codex or ChatGPT conversation that opened Relief Forge, paste the prompt into that conversation's message box, press Send, and keep Relief Forge open. There is intentionally no prompt box inside Relief Forge. The agent's four tool calls update the same visible project the reviewer can inspect and edit. After dismissal, the instructions can be reopened with Run agent demo . If clipboard access is blocked, the complete prompt remains visible for manual copying. Why WebMCP improves the experience Before WebMCP, an agent could recommend settings or imitate fragile UI clicks. With WebMCP, it can translate the request into explicit units and constrained parameters, update the visible project, inspect the exact result the person sees, and prepare a snapshot-consistent package. The person remains in control and can inspect or edit the artifact after every step. These are software checks, not claims of physical print, strength, or installation certification. How we built it Relief Forge is a React and TypeScript browser application. Geometry and stable identifiers remain deterministic local code. Printer packing, mesh checks, project state, and exports also run locally and repeat within the audited Chromium runtime; cross-runtime ZIP byte identity is not claimed. The challenge extension adds a narrow imperative WebMCP adapter around established editor actions. Tools register through document.modelContext.registerTool , use explicit schemas and physical bounds, update visible state before returning serializable results, read the current computed plan, and guard export preparation against stale project or printer configurations. Existing project and challenge extension Relief Forge existed before the challenge with deterministic geometry, exact-size controls, printer-bed packing, model and assembly previews, and STL, 3MF, PDF, manifest, recipe, and ZIP exports. During the challenge period, I added the four imperative WebMCP tools, lifecycle and schema validation, deterministic named WebMCP recipes including Polar Bloom, the visible agent-action status surface, stale-export protection, automated WebMCP coverage, Judge Quick Start, challenge documentation, and a separate sign-in-gated deployment. Accomplishments Relief Forge lets a natural-language request drive a real creative-manufacturing workflow through structured tools rather than simulated clicks. Agent and manual interaction share one source of truth. Established geometry remains deterministic, and packing is repeatable within the audited Chromium runtime. What we learned Creative-software tools work best when designed like manufacturing commands: constrained inputs, explicit measurements, visible changes, reproducible results, revision-aware exports, and honest boundaries around digital validation.
