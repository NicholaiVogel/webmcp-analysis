We can offload the researchers by letting AI agents handle the repetitive tasks like conducting iterations experiments and drafting their results. We can take this a step further by making agents decide what experiments to do and how, essentially making them an active participant in research. \n\n What it does \n\n Circuit Bench is a virtual electronics labaratory which expose WebMCP tools that let agents build circuits, run experiments, draft results and learn from the results to iterate and reach a goal. \n\n How we built it \n\n I built it with a Next.js frontend, FastAPI backend, ngspice for real circuit simulation, and WebMCP so agents can directly operate the lab. \n\n Challenges we ran into \n\n The hardest part was making sure the agent and the human interface always shared the same circuit state. Also the UI/UX took time to as the circuit canvas needed a clean and optimized interface. \n\n Accomplishments that we're proud of \n\n AI agent can independently experiment, learn from simulation results, and verify/improve its design. This loop can lead to very interesting findings. \n\n What we learned \n\n WebMCP has huge potential and it deserves to be explored more. Such a simple solution that can huge huge impact. \n\n What's next for Circuit Bench \n\n I'd like to support more components, richer experiments, larger circuits, and more advanced agent-driven engineering workflows. We could take this into other scientific domains too, not just electronics. \n\n PS., I know the project name sounds AI-made but I named it myself, and I couldn't come up with something better (maybe we are starting to think like AI now) \n\n \n\n \n Built With \n\n docker fastapi next.js ngspice python react restapi spice sqlite typescript webmcp \n \n\n \n Try it out \n\n \n \n \n circuit-bench-production.up.railway.app \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n Sole developer, tester, and full-time AI prompter :) \n \n\n \n \n \n \n \n \n\n \n Ashish Padavala \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Ashish Padavala \n started this project\n \n —\n \n 3 days ago \n \n \n\n
