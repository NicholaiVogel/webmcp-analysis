Humans , we have evolved by learning faster by seeing rather than plain text, so Teresct connects AI explanations with visual learning through clean, structured diagrams. \n\n What it does \n\n Teresct lets make AI agents to use WebMCP to create and edit Excalidraw diagrams. It generates connected concepts, circular nodes, labeled arrows, semantic colors, and organized layouts that make complex ideas easier to understand. \n\n How we built it \n\n We built Teresct with Next.js, React, TypeScript, the official Excalidraw library, WebMCP, Zod validation, deterministic graph layouts, and Convex persistence. \n\n Challenges we ran into \n\n The biggest challenges were converting connecting the nodes to correct diagram and looks great and neat \n\n Accomplishments that we're proud of \n\n We created a WebMCP-first diagram workspace where AI agents can directly build and revise visual explanations. \n\n What we learned \n\n Using WebMCP \n\n What's next for Teresct \n\n Next, I want to add AI-generated animations that reveal each step of a diagram in sequence, highlight active connectors \n\n I want try to any animations lib's and connect to webMCP make it neat explaining animations on the web \n\n \n\n \n Built With \n\n nextjs openai react webmcp \n \n\n \n Try it out \n\n \n \n \n teresct.vercel.app \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Vicky ch \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n Not a typical Programmer \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n 1 \n \n \n\n\n \n 1 person likes this:\n \n\n \n \n \n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Vicky ch \n started this project\n \n —\n \n a day ago \n \n \n\n
