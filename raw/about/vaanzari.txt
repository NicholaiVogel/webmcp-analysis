Traditional web agents have to guess at buttons and page structure. We wanted the storefront to expose a clear, predictable interface for people and agents to use together. \n\n What we built \n\n Vaanzari adds browser-native WebMCP tools for public saree discovery and visible cart actions. A compatible agent can search products, retrieve a product, compare products, open a product page, add an available product to the cart, and open the cart. The person remains in control of product choice, checkout, payment, and order confirmation. \n\n How we built it \n\n We register six tools with document.modelContext.registerTool(...) : search-sarees , get-saree , compare-sarees , open-saree , add-saree-to-cart , and open-cart . The tools use a public-safe catalog adapter plus browser navigation and cart adapters. Results map back into the visible UI so the person and agent share the same state. We also added a diagnostics view, tests, and a standalone Apache-2.0 reference repository. \n\n Challenges and what we learned \n\n The hard part was choosing a useful boundary without exposing account, customer, checkout, payment, or order workflows to an agent. We learned that structured tools make actions more predictable than UI guessing, while explicit human control keeps consequential commerce decisions with the shopper. \n\n \n\n \n Built With \n\n mcp react typescript webmcp \n \n\n \n Try it out \n\n \n \n \n vaanzari.com \n \n \n \n GitHub Repo \n \n \n \n vaanzari.com \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Mridul Singh \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Mridul Singh \n started this project\n \n —\n \n a day ago \n \n \n\n
