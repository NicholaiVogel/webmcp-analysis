Buyers spend hours manually filtering locations, calculating physical distances for COD (Cash On Delivery) meetups, and checking whether sellers are willing to negotiate or urgently selling ("BU / Butuh Uang"). \n\n LocalMarket AI bridges this gap using WebMCP (Web Model Context Protocol) . By exposing structured tools directly to AI agents inside browser contexts (such as ChatGPT in-app browser or Chrome with WebMCP enabled), an AI agent can instantly assist users in finding nearby pre-owned items, filtering urgent deals, and negotiating prices. \n\n What It Does \n\n \n Distance Radius Filtering : Filters pre-owned items by physical COD distance (e.g. < 1 km , < 3 km , < 5 km ). \n ⚡ BU (Butuh Uang) Deals Discovery : Instantly isolates urgent secondhand sales sold below standard market value. \n WebMCP Price Bargaining : Exposes native make_offer tools allowing AI agents to negotiate prices and propose COD meetups automatically. \n Interactive WebMCP Inspector : Built-in visual overlay displaying real-time tool registrations and executions. \n \n\n WebMCP Implementation \n\n LocalMarket AI implements window.document.modelContext.registerTool({...}) for 5 core tools: \n\n \n search_nearby_deals : Filter listings by query, location radius (km), budget, and category. \n filter_urgent_bu : Extract top urgent "BU (Butuh Uang)" bargains. \n get_item_details : Retrieve seller verification score, item condition rating, and meetup locations. \n make_offer : Submit custom price bargain offers and COD requests to sellers. \n view_my_offers : Retrieve active user/agent offer shortlists. \n \n\n How We Built It \n\n \n Frontend : Clean, responsive dark-themed UI built with HTML5, Tailwind CSS, and Vanilla ES6 JavaScript. \n Protocol Integration : Pure client-side WebMCP implementation with graceful degradation for standard browsers. \n Dataset : Pre-owned item catalog enriched with geolocation metadata, seller verification ratings, and COD safety scores. \n Testing : Fully tested with a 17-point automated blackbox and functional test suite ( test_runner.js ). \n \n\n What's Next for LocalMarket AI \n\n We plan to expand LocalMarket AI by integrating real-time geolocation APIs, web push notifications for accepted bargain offers, and multi-agent automated price negotiations. \n\n \n\n \n Built With \n\n ai and css etc figma html html5 javascript libra node.js python riyo tailwind webmcp-protocol website \n \n\n \n Try it out \n\n
