WebMCP opens up a different possibility. An AI agent can understand the visitor, their context, and their intent, then shape the experience around them. For consulting companies, this could change how digital experiences are designed. \n\n What it does \n\n We WebMCP-enabled newtuple.ai and allowed ChatGPT to interact with the website through structured tools. In the demo, ChatGPT understands the profile of the person browsing the site and dynamically changes the website based on what is likely to be most relevant to them. \n\n Instead of every visitor seeing the same homepage, the agent can help create a more personal experience in real time. \n\n What we learned \n\n WebMCP could enable a broader shift toward a deeply personal internet. Websites can become adaptive experiences shaped around each visitor instead of static pages built for an average user. \n\n That is especially interesting for agencies, which already spend significant effort designing journeys, campaigns, landing pages, and personalization strategies for their clients. \n\n WebMCP gives them a new design surface to experiment with. \n\n Challenges \n\n The hardest questions were around how much control an agent should have, what parts of the experience should remain deterministic, and how to make dynamic personalization feel useful without becoming unpredictable. \n\n Because WebMCP is still experimental, many of these interaction patterns are still being discovered. \n\n For us, that was the point of the project: exploring what websites might look like when AI agents become part of the browsing experience. \n\n \n\n \n Built With \n\n cloudflare codex nextjs openai \n \n\n \n Try it out \n\n \n \n \n newtuple.ai \n \n \n \n GitHub Repo \n
