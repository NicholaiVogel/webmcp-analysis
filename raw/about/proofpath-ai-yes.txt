ProofPath turns that reasoning step into a small, transparent educational workflow. \n\n Solution \n\n Users enter a claim and a piece of evidence. ProofPath classifies the relationship as SUPPORTED , CONTRADICTED , or INSUFFICIENT and returns bounded probabilities. It is intentionally limited to educational evidence assessment and does not claim to be a truth detector or scientific validator. \n\n AI and technical design \n\n The application uses a lightweight evidence-classification model behind a single analysis path. The same bounded analyze(claim, evidence) function is used by the human-facing interface and the structured WebMCP tool. This avoids duplicated verdict logic and keeps the same safety limits across interfaces. \n\n Evaluation and testing \n\n The project includes automated regression tests for the model and UI plus a real-browser WebMCP runtime canary. The canary discovered the analyze_evidence tool in headed Chrome, successfully invoked a normal evidence case, and verified that blank evidence fails closed instead of producing a confident result. \n\n Responsible AI \n\n ProofPath uses an explicit claim ceiling: EDUCATIONAL_EVIDENCE_ASSESSMENT_ONLY . Missing required input returns a BLOCK state. The project is not presented as a medical, legal, scientific-validation, or general automated fact-checking system. \n\n User experience \n\n The app remains usable as an ordinary web form. Students can enter a claim and evidence directly, inspect the resulting classification, and see when the system refuses to classify because necessary evidence is missing. \n\n Track 1 submission package \n\n The submission includes a slide presentation describing the problem, architecture, evaluation, responsible-AI constraints, and impact; a video walkthrough/live demo; source code and a live deployment; and the required packaged deliverables. \n\n Built and verified with \n\n JavaScript, HTML, CSS, lightweight machine-learning classification, WebMCP, GitHub Actions, headed Chrome runtime verification, and ChatGPT-assisted implementation/test/documentation workflows. \n\n Source and live demo \n\n Public repository: https://github.com/lbkapcsolat-dotcom/ProofPath/tree/webmcp-challenge \n\n Live deployment: https://elastic-cloud-7bddb2h.shipstatic.com \n\n Video walkthrough: https://youtu.be/sN-UJNyZoL4 \n\n \n\n \n Built With \n\n chatgpt css github-actions html javascript machine-learning webmcp \n \n\n \n Try it out \n\n \n \n \n GitHub Repo \n \n \n \n elastic-cloud-7bddb2h.shipstatic.com \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n AI YES :International Youth AI Competition \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n I helped test the application, review the user experience, and prepare the project for the competition.
