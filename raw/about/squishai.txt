Two of the most capable AI tools in the world, completely blind to each other. The moment I heard about WebMCP — AI tools registering directly in the browser — I realised the browser was the missing coordination layer. Not another app. Not another API. The page itself becomes the dispatcher. \n\n What it does \n\n SquishAI is a shared task queue and working memory layer that connects AI agents across platforms. Open squishai.io in ChatGPT's in-app browser and five tools appear instantly via WebMCP — no plugin setup, no API keys, nothing to install. \n\n Tell ChatGPT what you need built. It calls submit_task , packages the work, and queues it with full context. Claude Code (or Manus, Cursor, Windsurf — any connected agent) sees the task, claims it, executes it, and posts the result back. The story: two competing AI platforms, cooperating through an open standard. \n\n The tools: \n\n \n brief — check the queue and working memory at session start \n submit_task — queue work for another agent, with optional platform targeting \n status — see what's pending, in progress, or done \n result — fetch what the worker built \n remember — save decisions and context that travel with every task \n \n\n How we built it \n\n The WebMCP layer lives entirely in index.html — five document.modelContext.registerTool() calls that fire when the page loads in a WebMCP-enabled browser. Each tool's execute function calls a REST API ( /api/v1/* ) on the SquishAI backend. \n\n The backend is Node.js + Express + SQLite. The same database powers both the browser-side REST API and a server-side MCP connector (StreamableHTTP + SSE transports) for AI coding tools. One queue, two transports — whichever side submits, the other side picks up. \n\n Working memory is append-only per user. Every submit_task call automatically packs the last five memory entries into the task context, so the worker arrives fully briefed without the submitter having to repeat themselves. \n\n A constitution delivered via the MCP instructions field means every connecting agent is briefed on the system the moment they connect — what the queue is, how memory works, what to do on a new session. \n\n Challenges \n\n The open web part is genuinely hard. Browser-side tools calling a backend from inside ChatGPT's in-app browser means strict CORS handling and no assumptions about the host environment. Every fetch had to be self-contained. \n\n Cross-platform coordination without a shared session was the core design problem. The solution: a shared token that acts as a namespace. Any agent with the token reads from the same queue and memory — it doesn't matter which platform submitted or which picks up. \n\n What we learned \n\n WebMCP is not a feature — it's a shift in what a webpage is. A page that registers tools is no longer just content. It's an interface for agents. The implications for how we think about the web are significant: any site can become a capability that AI models can reach for, without plugins, without OAuth flows, without anything except opening a URL. \n\n The cross-platform demo — ChatGPT submitting, Claude Code executing — was the accidental proof. Two competing AI ecosystems, cooperating through an open standard. That's what the open web looks like. \n\n \n\n \n Built With \n\n chatgpt cluade express.js javascript mcp node.js restapi sqlite webmcp \n \n\n \n Try it out \n\n \n \n \n squishai.io \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Bryan Horsfield \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Bryan Horsfield \n started this project\n \n —\n \n 2 days ago \n \n \n\n
