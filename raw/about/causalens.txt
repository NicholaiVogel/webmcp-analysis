Evidence may support a hypothesis, contradict it, or suggest alternative explanations. We built CausaLens to make that reasoning explicit, traceable, and human-controlled. \n\n What it does \n\n CausaLens is a clinical evidence investigation workspace where an AI agent can propose a causal claim, while every claim remains grounded in the exact sentences from the patient record. \n\n The agent can: \n\n \n search the clinical record \n retrieve a structured case summary \n create causal claims \n attach supporting and contradicting evidence \n challenge its own claims \n surface alternative explanations \n focus specific evidence \n update a claim's review status \n \n\n Instead of automatically deciding what caused an outcome, CausaLens keeps the final judgment with the human: accept, reject, or leave the claim unresolved. \n\n AI proposes. Evidence challenges. Human decides. \n\n Why WebMCP \n\n WebMCP turns CausaLens from a website an agent can simply view into a structured environment an agent can actually work with. \n\n CausaLens exposes its investigation capabilities as WebMCP site tools. ChatGPT can discover these tools directly in its in-app browser and use them to investigate a case without guessing how to navigate the interface. \n\n This enables the human and agent to share the same workspace: the agent performs evidence-intensive investigative work while the human remains responsible for consequential decisions. \n\n How we built it \n\n CausaLens is a web application deployed on Vercel with WebMCP integrated directly into the application. \n\n We registered eight WebMCP tools for: \n\n \n searching the clinical record \n retrieving the case summary \n creating claims \n attaching evidence \n challenging claims \n adding alternative explanations \n updating claim status \n focusing evidence \n \n\n The tools include both read and write operations. Before workspace-changing actions are executed, the agent can request human approval. \n\n The demo uses a synthetic clinical case to demonstrate the workflow safely. \n\n Challenges \n\n The main challenge was designing tools that were useful to an AI agent without allowing the agent to bypass the human decision-making process. \n\n We also had to make evidence references precise enough that claims could remain tied to specific record sentences rather than unsupported model-generated conclusions. \n\n What we learned \n\n WebMCP makes it possible to design interfaces for humans and agents together instead of treating the agent as a separate chatbot. \n\n The most important design decision was not giving the agent more autonomy, but giving it structured autonomy with evidence, challenge, and human oversight built into the workflow. \n\n What's next \n\n CausaLens could expand beyond the synthetic case into larger longitudinal records, richer evidence provenance, multiple competing causal hypotheses, and collaborative review workflows for research and other evidence-intensive domains. \n\n This project is a research demonstration using synthetic data and is not intended for clinical diagnosis or treatment decisions. \n\n \n\n \n Built With \n\n ai chatgpt clinical human-ai-collaboration javascript next.js react typescript vercel webmcp \n \n\n \n Try it out
