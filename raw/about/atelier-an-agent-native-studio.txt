Every capability it has — perceiving the canvas, changing palettes, composing scenes, adding textures, critiquing, proposing variations, exporting the artwork — is declared as a structured WebMCP tool via document.modelContext.registerTool(), with JSON schemas and natural-language descriptions. The browser agent (ChatGPT in-app browser, or any WebMCP client) is not an assistant bolted onto the app: it IS the interface. \n\n The human keeps the most natural human interface — direct manipulation (drag, resize, click, scroll) — and delegates everything linguistic or generative to the agent: "make it warmer", "give me three alternatives", "export". Both actors share one canvas and one history, so a human adjustment and an agent transformation compose naturally, including undo. \n\n Ten tools are registered: get_canvas_state, set_palette, add_shape, remove_shape, move_shape, apply_composition, add_texture, semantic_query, suggest_variations, export_artwork. Each tool mutates one serializable scene object (seeded, deterministic procedural generation) and redraws a 2D canvas. An in-page fallback registry (clearly labeled in the UI) mirrors the same tool surface for browsers without the WebMCP flag, so the studio stays fully agent-drivable anywhere. \n\n Built with: vanilla JavaScript, HTML5 Canvas 2D, WebMCP (document.modelContext), zero external dependencies. \n\n \n\n \n Built With \n\n ai-agents html5 javascript vanilla-js webmcp \n \n\n \n Try it out \n\n \n \n \n GitHub Repo \n \n \n \n shamanov39-dev.github.io \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Alexey Alexey Shamanov \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n 1 \n \n \n\n\n \n 1 person likes this:\n \n\n \n \n \n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Alexey Alexey Shamanov \n started this project\n \n —\n \n 4 days ago \n \n \n\n
