I wanted to build a personal card that gave users more freedom to design and express themselves. However, after seeing similar ideas like Linktree, I put the project aside because I wasn't sure if it would solve a real problem. \n\n When I discovered WebMCP and saw how AI agents could directly interact with tools provided by a website, I became interested in the idea again. I decided to bring Nambut back and explore how AI could help users create and customize their cards. \n\n The name Nambut is a play on the Thai word "นามบัตร" (Nam-bat), which means a business card or a card containing your personal information. \n\n What it does \n\n Nambut is a flexible personal card builder where users can create, customize, and share their own cards. \n\n Users can freely arrange elements, customize colors, rotate elements, apply effects such as glass blur and shadows, and choose from templates. \n\n With WebMCP, AI agents can also interact directly with the editor using tools such as add_element , move_element , and delete_element . \n\n How we built it \n\n Nambut is a web-based visual editor with WebMCP integrated into its core functionality. \n\n We exposed the editor's main actions as structured tools so that AI agents can understand and interact with the application directly, while keeping the normal UI available for human users. \n\n Challenges we ran into \n\n I had never built an application like this before, and this was also my first time seriously working with AI agents. \n\n I had to learn how AI agents work and how to expose the tools I built in a way that an AI could understand and use correctly. \n\n Learning about WebMCP and this new way of connecting AI with web applications was challenging, but it also gave me a lot more motivation to learn and build. \n\n Accomplishments that we're proud of \n\n I'm proud that I was able to bring an idea I had been thinking about for a long time back to life. \n\n More importantly, I managed to finish it within the hackathon deadline and turn it into something that actually works. \n\n What we learned \n\n This project gave me my first real experience with AI agents and taught me that websites can provide AI with structured capabilities instead of simply being interfaces that AI has to navigate. \n\n It also showed me how new technologies like WebMCP can change the way we think about building web applications. \n\n What's next for Nambut \n\n If Nambut proves that there is real potential, I want to add more tools and significantly improve the UX/UI. \n\n I also want to make Nambut a way for more people to discover WebMCP and experience how AI can be used more effectively when it can directly interact with the tools of an application. \n\n \n\n \n Built With \n\n
