I exposed web tools directly via the new WebMCP (Web Model Context Protocol) standard enabling browser AI agents to autonomously look up tariff rules, compute duty savings, and prepopulate customs manifests for traders in seconds. \n\n What it does \n\n SwiftClear is an agent-native AfCFTA trade compliance and customs declaration workspace. Key features include: \n\n AI Trade Analysis : Instant HS tariff classification, rule-of-origin verification, and duty breakdown powered by Google Gemini 3.1 Flash Lite. \n\n WebMCP Tool Suite : Exposes structured client-side tools directly onto navigator.modelContext so external AI web agents (or in-page agents) can query trade rules and drive the application UI. \n\n AfCFTA Preferential Tariff Calculator : Calculates baseline MFN duty vs. AfCFTA preferential rates, VAT, security fees, escort fees, and net USD savings across key African transport corridors (e.g., Kano to Accra, Mombasa to Kampala). \n\n Live WebMCP Inspector & Terminal : Provides a real-time event stream of WebMCP tool registration, execution requests, parameters, and dynamic DOM updates. \n\n How I built it/WebMCP Architecture \n\n SwiftClear is built using a modern, resilient tech stack: \n\n WebMCP Standard : Implemented client-side tool registration on navigator.modelContext with a robust fallback polyfill (src/utils/webmcpPolyfill.ts) supporting event dispatching for tool execution. \n\n Registered WebMCP Tools :\n1) lookup_hs_code : Resolves product descriptions to 6-digit HS codes, duty rates, and AfCFTA eligibility using Gemini 3.1 Flash.\n2) calculate_duties : Calculates exact duty fees, VAT, port handling, escort fees, and total clearance costs based on declared consignment value and quantity.\n3) populate_customs_manifest : Injects parsed manifest state directly into the frontend reactive DOM. \n\n AI Backend : Express server (server.ts) and Vercel serverless endpoint (api/gemini/analyze-trade.ts) using @google/genai with gemini-3.1-flash-lite, structured JSON schema enforcement (responseMimeType: "application/json"), and offline trade fallback models. \n\n Frontend : React 19, Vite, Tailwind CSS v4, Framer Motion, and Lucide Icons. \n\n Challenges and Accomplishments \n\n WebMCP Browser Compatibility : Chrome's native WebMCP flag (chrome://flags/#enable-webmcp-testing) exposes a native navigator.modelContext object. I designed a dual-layer registration architecture that seamlessly interfaces with both native browser environments and standalone WebMCP bridges without breaking page state. \n\n Structured AI Responses : Enforcing strict JSON schema validation with Gemini 3.1 Flash Lite to guarantee reliable numeric duty rates and standardized HS codes for seamless tool execution. \n\n Trade Fallback Engine : Built a robust offline AfCFTA tariff matrix ensuring the application remains 100% operational even during network or credential unavailability. \n\n What's next for Swiftclear \n\n Expanded Corridor Coverage : Expand tariff data across all 54 AfCFTA signatory nations. \n\n Real-time Customs API Sync : Integrate direct webhooks with national customs systems (e.g., Ghana Single Window, Nigeria Trade Portal). \n\n Multi-Lingual Agent Support : Enable French, Swahili, Arabic, and Portuguese agent interactions for cross-regional trade facilitation. \n\n \n\n \n Built With \n\n express.js framer-motion gemini-api google-gemini json-schema lucide-react node.js react tailwindcss typescript vercel vite webmcp \n \n\n \n Try it out \n\n \n \n \n swiftclearapp.vercel.app \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Akpan Victor D. \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n 1 \n \n \n\n\n \n 1 person likes this:\n \n\n \n \n \n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Akpan Victor D. \n started this project\n \n —\n \n a day ago \n \n \n\n
