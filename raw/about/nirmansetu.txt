Keeping track of the progress of these projects can be difficult when many projects are running in different locations. It can also take time to find out which projects are progressing normally and which ones are delayed. \n\n I wanted to build a system where project information could be viewed in one place instead of depending mainly on manual reports and checking projects individually. \n\n NirmanSetu provides a dashboard for monitoring infrastructure projects and their current status. It includes project progress, location, contractor information, completion dates, verification information, reports, and project risk information. Projects are grouped into On Track, At Risk, and Delayed so that projects requiring attention can be identified more easily. \n\n Why I Built NirmanSetu \n\n The main idea behind NirmanSetu came from a problem I have seen around government and public infrastructure work in Nepal. \n\n Whether it is a road, health post, school, municipal building, or a larger government project, it is not always easy for people to know what is actually happening with a project. At the local and municipal level, and even with larger government projects, information can be scattered across different offices, reports, and processes. This makes it harder to understand whether a project is progressing as planned, why it is delayed, or how public money is being used. \n\n Seeing this lack of transparency and accountability is what motivated me to build NirmanSetu. \n\n I wanted to create a digital system where government infrastructure projects could be monitored in one place, with information such as project progress, location, contractor, deadlines, verification, and risk status. \n\n The goal is not to claim that software alone can solve corruption. Instead, I wanted to build a system that makes project information easier to access and makes it harder for important information to remain hidden or difficult to track. \n\n Why WebMCP \n\n WebMCP added another important part to this idea. Normally, a person using NirmanSetu would open the project list, search or filter projects, and then check individual project details. I wanted to see what would happen if an AI agent could directly use some of these project functions. \n\n For example, instead of manually looking through the project list, a user can ask: \n\n \n Find all delayed infrastructure projects in NirmanSetu and show me their names, locations, and completion percentages. \n \n\n The AI agent can identify the appropriate WebMCP tool, call it, receive the project information, and present the result in a natural-language response. \n\n This is different from simply putting a chatbot on the website. The agent can actually interact with functions provided by the application. \n\n WebMCP Implementation \n\n I implemented four read-only WebMCP tools: \n\n \n search_projects \n get_project_details \n find_delayed_projects \n get_project_risk \n \n\n The tools are registered using the browser's document.modelContext API. They return structured project data that an AI agent can use. \n\n For the hackathon demo, I used a controlled project dataset so that the demonstration is stable and easy to test. The project is structured so these tools can later be connected to a real backend and actual project data. \n\n How I Built It \n\n The frontend was built with React and Vite. I used Tailwind CSS for the interface, along with React Router, Leaflet, and Lucide React. The application is deployed using Vercel. \n\n I first worked on the normal infrastructure monitoring interface and then added the WebMCP integration. After registering the tools, I tested them in Chrome and used the WebMCP Tool Inspector to check the available tools and their responses. \n\n One of the main things I had to figure out was how to expose useful project functions to an AI agent rather than just exposing information on a webpage. I also tested the complete flow from a natural-language request to the tool call and finally to the response generated by the AI agent. \n\n What I Learned \n\n This project helped me understand how a normal web application can be made easier for AI agents to use. \n\n Before working on this project, I mainly thought about a website from the perspective of a person clicking buttons and navigating pages. WebMCP made me think about another user of the application: an AI agent that needs clear tools and structured information. \n\n I also learned more about registering browser tools, defining their inputs and outputs, testing tool calls, and making the interaction reliable for a live demonstration. \n\n Challenges \n\n One challenge was deciding which parts of the application would actually be useful for an AI agent. I did not want to expose every UI action as a tool, so I focused on project search, project details, delayed projects, and risk information. \n\n Another challenge was testing the complete interaction between the browser, WebMCP tools, and the AI agent. I had to make sure the tools were registered correctly and returned information in a format that the agent could understand. \n\n Future Plans \n\n The current version is a hackathon prototype. For a real deployment in Nepal, I would connect NirmanSetu to actual government or municipal project data instead of the current demo dataset. \n\n I would also like to add GPS and timestamp-based evidence for construction progress, better verification of submitted photos and documents, financial and milestone tracking, notifications for delayed projects, and AI-based analysis that can help identify projects that may require closer monitoring. \n\n \n\n \n Built With \n\n css javascript leaflet.js react router tailwind vite webmcp \n \n\n \n Try it out \n\n \n \n \n GitHub Repo \n \n \n \n nirman-setu-webmcp.vercel.app \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Yuv Raj Dhakal \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Yuv Raj Dhakal \n started this project\n \n —\n \n 2 days ago \n \n \n\n
