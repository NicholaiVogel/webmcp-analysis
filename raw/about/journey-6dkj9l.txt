Right now, most AI assistants feel isolated from the apps we actually use—they sit in a side panel, completely blind to what's happening on your screen unless you copy-paste text back and forth. \n\n When the WebMCP open standard was announced, we realized web apps could finally give AI agents structured "hands" to help users directly inside the UI. We set out to build Ecrit —a cozy, distraction-free notes workspace where you and your agent can read, organize, and edit your board together without getting in each other's way. \n\n \n\n What it does \n\n Ecrit is a soft, paper-themed Kanban board and note app designed for both humans and AI agents. \n\n \n Works with your AI agent: Instead of copy-pasting notes, your AI assistant can directly create cards, organize columns, search your notes, or edit markdown text using clean background commands. \n Keeps you in control: The app includes human-in-the-loop protection. For sensitive actions—like deleting a note—the AI cannot bypass your permission; it triggers a friendly prompt asking for your confirmation first. \n \n\n * Clean, distraction-free workspace: Uses a calming "Cactus & Paper" design system with readable typography so writing always feels natural. \n\n How we built it \n\n We built Ecrit using modern, fast web standards designed for agent-native interactions: \n\n \n Frontend: Built with Next.js (App Router) and Tailwind CSS to keep the UI fluid and responsive. \n WebMCP Integration: We used @mcp-b/global to register 7 custom browser tools directly to navigator.modelContext . This allows browser agents (like ChatGPT's in-app browser) to instantly detect what Ecrit can do. \n Markdown Rendering: Integrated marked so your notes support rich text, checklists, and code snippets smoothly. \n \n\n * Security & Guardrails: Built strict input sanitization and length limits into every tool handler to stop prompt injection attacks from messing up your board. \n\n Challenges we ran into \n\n \n Teaching DevTools to detect WebMCP: Early on, browser flags and polyfills didn't always play nicely together during Next.js client hydration. We had to carefully structure our client component mounts inside a clean useEffect lifecycle to ensure navigator.modelContext was exposed reliably to Chrome DevTools. \n Balancing cute design with structure: Finding the right balance between a soft, friendly "cactus and paper" aesthetic without making the Kanban board feel cluttery or misaligned took several UI iterations. \n Preventing rogue actions: Ensuring AI agents couldn't accidentally wipe out user data required setting up a clear split between "read-only" search tools and "write" operations that require explicit user consent. \n \n\n \n\n Accomplishments that we're proud of \n\n \n 7 fully functional WebMCP tools: We successfully exposed a complete set of CRUD and search actions (create, move, edit, rename, delete, search, summarize) without relying on fragile web scraping. \n A polished, human-centered UI: Created an aesthetic that feels warm, calm, and approachable—completely avoiding cold, overly complex dark-mode terminal tropes. \n Built-in security: Successfully defended tool handlers against prompt injections and stored XSS attacks right out of the box. \n \n\n \n\n What we learned \n\n \n The future of web apps is agent-native: Building with WebMCP showed us how much smoother web apps become when AI agents have explicit APIs instead of guessing their way through raw HTML elements. \n Safety needs to be built into the UI: Human-in-the-loop confirmations are essential for building trust between users and automated agents. \n \n\n \n\n What's next for Ecrit \n\n \n Real-time multiplayer editing: Allowing multiple human users and AI agents to edit the exact same markdown card simultaneously. \n Custom tags & board filtering: Exposing tag-based tool filtering so agents can organize complex projects automatically based on priority. \n Offline local storage sync: Saving all your paper notes and board history locally so Ecrit works seamlessly offline without needing a constant network connection. \n \n\n \n\n \n Built With \n\n ai-agents developer-tools kanban markdown next.js notes openai opensource productivity security tailwindcss typescript ux/ui webmcp \n \n\n \n Try it out
