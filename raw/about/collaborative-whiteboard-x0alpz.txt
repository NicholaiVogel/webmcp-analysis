Some topics are hard to understand from text alone, so I thought it would be useful if an AI could explain them directly on a whiteboard with drawings, arrows and notes. \n\n What it does \n\n Collaborative Whiteboard is a shared whiteboard for a human and an AI. You can draw something, write a question, select an area or point at something with the AI Pen. The AI can then explain it, improve it or continue working on the same canvas. Everything the AI creates stays editable, so you can change it and keep working from there. \n\n How we built it \n\n I built the project mainly with Codex and Claude . I also used WebMCP, MCP tools and different Claude skills while working on it. The app itself is a web-based whiteboard with tools for drawing, writing, selecting things and working together with an AI agent. \n\n Challenges we ran into \n\n One of the biggest challenges was definitely usage limits while building the project. Getting the WebMCP connection and the Human-to-AI workflow working correctly was also not easy. There were many small bugs with turns, waiting and editing the canvas that had to be fixed. \n\n Accomplishments that we're proud of \n\n I am really proud that the main idea actually works. The AI can understand the board and add real, editable drawings and objects to it. I am also happy with how fast the app runs now. Building and testing the project was a lot of fun. \n\n What we learned \n\n I learned a lot about WebMCP, AI agents and how to connect an AI with an interactive website. I also learned that making an AI understand when it should wait, edit or react to the user is harder than it first sounds. \n\n What's next for Collaborative Whiteboard \n\n Next, I would like to improve how well the AI designs and organizes things on the whiteboard, so its diagrams and layouts look even better. I also want to add more things the AI and the user can insert into the canvas. I would still like to improve the performance a bit more, even though the app is already running pretty fast now. \n\n \n\n \n Built With \n\n claude codex css3 html5 javascript typescript \n \n\n \n Try it out \n\n \n \n \n bertus37987.github.io \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n willy Willy Ebert \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n willy Willy Ebert \n started this project\n \n —\n \n a day ago \n \n \n\n
