Studybench turns exam preparation into a focused, adaptive workspace where progress, review, planning, and agent actions share one visible state. \n\n What it does \n\n Studybench shows mastery by topic, cards due for review, exam countdown, and readiness at a glance. Students can start a review session, reveal answers, self-grade cards, and focus on weak topics such as Semaphores & Mutexes or Deadlock Handling. \n\n The right-side agent workspace makes the product agent-native. A student can ask the agent to quiz them on their weakest topic, turn notes into cards, or rebuild a study plan. The Tools and Calls views expose the structured WebMCP actions so the student can see what the agent can do and keep control of the workflow. \n\n How we built it \n\n The project is a lightweight JavaScript web app deployed on Vercel. It uses a local-first study model for cards, topics, mastery, review sessions, plans, and activity. The agent surface is designed around WebMCP-style structured tools and observable calls rather than an opaque chat-only experience. \n\n Challenges and learnings \n\n The main challenge was making the agent useful without hiding the study state or taking control away from the student. We learned that a good agent-native interface needs explicit tools, visible calls, predictable state updates, and a manual path for every important action. \n\n What's next \n\n Future improvements include importing notes, richer spaced-repetition scheduling, collaborative study plans, and connecting the same structured tools to more browser agents. \n\n Links \n\n Live demo: https://studybench-clean-h7gjfzs5r-rajpurohitrani724-bit.vercel.app/ \nSource: https://github.com/rajpurohitrani724-bit/studybench-clean \n\n \n\n \n Built With \n\n css3 html5 javascript vercel webmcp \n \n\n \n Try it out \n\n \n \n \n studybench-clean-h7gjfzs5r-rajpurohitrani724-bit.vercel.app \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Rani rajpurhit \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n 1 \n \n \n\n\n \n 1 person likes this:\n \n\n \n \n \n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Rani rajpurhit \n started this project\n \n —\n \n 3 days ago \n \n \n\n
