By combining AI with WebMCP, we created a collaborative workflow for scripting, recording, and editing -> covering the whole content creator workflow \n\n What it does \n\n Deskmate is an AI powered content creation studio where both the user and AI can edit together. \n\n It allows you to: \n\n Write and refine video scripts collaboratively \n\n Record videos with an on screen teleprompter that follows your script \n\n Edit videos alongside AI using WebMCP \n\n Add transitions, animations, captions, and audio through natural language \n\n How we built it \n\n We built Deskmate using Vite, React, JS, Chatgpt, and Claude. \n\n The core idea was giving the AI direct access to a browser based editing environment through WebMCP, allowing it to make real edits while the user stays in control. \n\n Challenges we ran into \n\n One of our biggest challenges was balancing AI autonomy with user control. Early versions allowed the AI to overwrite changes that users wanted to keep, so we introduced an approval system where edits must be accepted before being applied. \n\n Also getting ai to make motion graphics, write script the way you want it. Our solution was allow users to make use of the abundant ai skills available online and to be able to import them to our app and use it \n\n As the project grew, the codebase became difficult to maintain. We eventually rebuilt the UI from scratch, creating a cleaner foundation before re integrating the features. \n\n Accomplishments that we're proud of \n\n We're especially proud of the collaborative video editor. Seeing ChatGPT successfully add motion graphics, animations, transitions, captions, and audio through WebMCP felt like a glimpse into the future of creative software. Something we used to spend hours building, literally was made in the blink of an eye \n\n What we learned \n\n This project taught us a huge amount about WebMCP, how AI interacts with browser applications, and the practical differences between traditional MCP servers and WebMCP. We also learned how important human approval is when building collaborative AI tools. \n\n What's next for Deskmate \n\n We're going to continue using Deskmate for our own content creation while expanding its features. Namely focus on adding sfx integration, more transitions and being able to generate complex transitions between clips \n\n Our goal is to make it an open source platform for AI assisted scripting, recording, and video editing. \n\n \n\n \n Built With \n\n css google-fonts html indexeddb javascript jsx react tailwind vercel vite webmcp whisper \n \n\n \n Try it out \n\n \n \n \n deskmate-cc.vercel.app \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Roshan Prabhu \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n\n \n Ridwaan Joomun \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n 1 \n \n \n\n\n \n 1 person likes this:\n \n\n \n \n \n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Roshan Prabhu \n started this project\n \n —\n \n a day ago \n \n \n\n
