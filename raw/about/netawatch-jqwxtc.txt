That is why we decided to make civic research more accessible by bringing key public records together on a single, structured platform. \n\n AI agents are at the same time turning into a new means of interacting with software, and we wanted to find out what would occur if an AI could go beyond drawing on its own knowledge to directly interact with a civic data platform. \n\n That was the result of NetaWatch WebMCP . \n\n What We Built \n\n NetaWatch is a civic research platform guided by evidence which arranges information on politicians into structured research dossiers. It combines data on parliamentary activity, public statements, election affidavits, assets, legal records and other publicly available information. \n\n We then included WebMCP features so that AI agents will be able to interact directly with NetaWatch. \n\n Instead of manually navigating through the website, a user can ask an AI agent to perform tasks such as: \n\n \n Find a politician's dossier \n Retrieve specific civic or parliamentary information \n Answer research questions using NetaWatch data \n Compare politicians across important metrics \n \n\n For instance, in the demo we request that ChatGPT finds Rahul Gandhi's dossier using NetaWatch; the agent identifies and makes use of the exposed features, retrieves the relevant information, and then makes it available in the conversation. \n\n The workflow becomes: \n\n ASK → DISCOVER → VERIFY → COMPARE \n\n How We Built It \n\n We created NetaWatch as a structured civic research platform, including politician-specific dossiers and organized datasets; the WebMCP layer makes available certain NetaWatch features so that compatible AI agents are able to discover and call them. \n\n The key idea is to separate the system into two parts: \n\n NetaWatch is the source of the structured evidence. \n\n The interface offered by WebMCP enables AI agents to interact with it. \n\n It turns natural-language requests into real interactions with the application rather than just chatbot responses. \n\n Challenges \n\n A major difficulty was working out how to make useful application capabilities available to an AI agent without ending up with an interface that consisted of too generally worded tools. \n\n We also had to give careful consideration to structured data, reliable retrieval, and making it easy for the user to understand the agent's interactions. In order for a workflow to be a success it had to be not only technically functional but also easy to demonstrate. \n\n A further difficulty was giving users complex civic information without it being overwhelming. To deal with this we grouped the information into targeted dossiers and important metrics. \n\n What We Learned \n\n We discovered that attaching AI to an application is fundamentally different from just attaching AI to a database, the agent having to have clear and well-defined capabilities which correspond naturally to user intent. \n\n We also found that structured civic data becomes considerably more useful when it can be queried using natural language and still keeps the underlying evidence and context. \n\n Most importantly, this project demonstrated to us how WebMCP is able to convert a conventional website into something that an AI agent can actively use, thus establishing a new kind of interaction model between users, AI, and web applications. \n\n What's Next \n\n We would like to enhance NetaWatch WebMCP by adding more research capabilities, incorporating a wider range of civic datasets, providing richer comparisons, and including further agent actions. \n\n We want evidence-based civic research to be just as easy as posing a question—yet at the same time we want the basic information to remain structured, transparent, and verifiable. \n\n \n\n \n Built With \n\n css3 lucid-css react typescript vite \n \n\n \n Try it out \n\n \n \n \n netawatch.ai.studio \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Ritesh Choubey \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Ritesh Choubey \n started this project\n \n —\n \n 2 days ago \n \n \n\n
