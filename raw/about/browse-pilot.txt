Analysts jump between spreadsheets, product pages, funding updates, and notes before they can form a clear opinion. We wanted to turn that scattered process into an AI-assisted, transparent workflow where every recommendation can be inspected instead of treated like a black box. \n\n What it does \n\n BrowsePilot is an autonomous startup-scout workspace that turns product data into investment-ready decisions. \n\n It allows a user or AI agent to: \n\n \n Search and filter startup opportunities by category, price/funding, status, tags, and keywords \n Explain why each company matched a scout mission \n Score opportunities with a visible Scout Fit score \n Compare up to three companies side by side \n Visualize market, execution, competition, and regulation risk \n Track a watchlist and simulate new company signals \n Generate executive market briefs and downloadable investment memos \n Run a one-click Judge Mode demo from discovery to decision \n \n\n How we built it \n\n BrowsePilot is a single-file web application built with vanilla HTML, CSS, and JavaScript. The interface uses Tailwind CSS via CDN. \n\n We implemented browser-native WebMCP tools using the imperative registration pattern: \n\n \n filter_and_search_data \n export_dataset_summary \n generate_market_brief \n \n\n Each tool validates its input, updates the live UI, records activity in an agent observability log, and returns structured output for AI-agent consumption. The app also includes a browser-only fallback so its interactive features still work when WebMCP is unavailable. \n\n Challenges we ran into \n\n WebMCP support depends on the browser environment and secure-context requirements. Loading a local file with file:/// does not expose the WebMCP API, so we designed a graceful fallback mode and tested the project from a local server. \n\n Another challenge was making AI-driven scoring trustworthy. Instead of hiding the reasoning, BrowsePilot shows evidence tags, status signals, fit scores, and risk factors directly in the interface. \n\n Accomplishments that we're proud of \n\n We created more than a data dashboard. BrowsePilot delivers an end-to-end decision workflow: \n\n \n Discover opportunities \n Filter and explain evidence \n Compare conviction and risk \n Generate an investment-ready memo \n \n\n We are especially proud of Judge Mode, which demonstrates the complete workflow in under a minute, and the observability panel, which makes agent actions visible and understandable. \n\n What we learned \n\n We learned that an effective AI-agent interface needs more than tool calling. It needs clear state, recoverable errors, visible reasoning, and outputs people can act on. \n\n We also learned how WebMCP can make websites more useful to AI agents by exposing safe, structured browser tools instead of relying only on text or screenshots. \n\n What's next for BrowsePilot \n\n Next, we plan to add live data sources, source provenance and freshness signals, persistent watchlists, richer evidence drawers, and multi-agent diligence handoffs. \n\n Our long-term goal is to make BrowsePilot a trusted research copilot for investors, accelerators, and product strategy teams. \n\n \n\n \n Built With \n\n agents css github html javascript mcp pagesai responsive tailwind web webmcp \n \n\n \n Try it out \n\n \n \n \n jainagrim297-art.github.io \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Agrim Jain \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n\n \n Akul Bansal \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n\n \n Atishey Jain \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n 1 \n \n \n\n\n \n 1 person likes this:\n \n\n \n \n \n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Agrim Jain \n started this project\n \n —\n \n 3 days ago \n \n \n\n
