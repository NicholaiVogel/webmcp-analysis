GitWand started from a boundary-first idea: resolve what is objectively deterministic, surface what is ambiguous, and keep the human in control of the decision. \n\n What it does \n\n GitWand Agent turns a Git conflict into a shared Merge Room for humans and agents. The page exposes three WebMCP tools: resolve_conflict , parse_git_error , and list_cases . Deterministic hunks are settled automatically; genuinely ambiguous ones are filed for the human to choose; and the agent can read the room back to resume work once a decision is made. \n\n How we built it \n\n We registered the tools directly on the page and wired the UI around live case state. The same browser tab that the agent sees also shows the Merge Room, so the result is visible in real time. The implementation keeps the resolution logic narrow and explicit: no guessing, no hidden side effects, and no tool that can silently pick a side for you. \n\n Challenges we ran into \n\n The main challenge was resisting the temptation to make the agent do too much. Git conflicts often mix deterministic edits with real intent decisions, so the product had to make that boundary obvious. Another challenge was designing list_cases so the agent can return after a human decision and continue without losing context. \n\n What we learned \n\n Agent-native software works best when it is precise about what the machine can and cannot decide. WebMCP is a good fit because it lets a website define exactly how an agent should interact with it, instead of forcing the agent to infer the UI. \n\n What's next \n\n More conflict patterns, richer case history, and tighter integration with real repository workflows. \n\n \n\n \n Built With \n\n tauri-2 typescript vue-3 webmcp \n \n\n \n Try it out \n\n \n \n \n gitwand.app \n \n \n \n GitHub Repo \n \n \n \n gitwand.app \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Laurent G. \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Laurent G. \n started this project\n \n —\n \n 5 days ago \n \n \n\n
