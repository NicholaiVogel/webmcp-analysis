We realized that teachers and school administrators spend hours navigating these clunky interfaces instead of focusing on what truly matters: education. When WebMCP was introduced, we saw the perfect opportunity to bridge the gap between complex databases and human intent. We wanted to transform the UX from "navigational" to "conversational," allowing educators to manage an entire school through simple natural language. \n\n What it does\nOur project is a full-stack, Agent-Native School Management System. It allows AI agents (like ChatGPT) to act as an administrative co-pilot directly within the browser. Once an administrator logs securely into the dashboard, the app exposes 7 powerful WebMCP tools: \n\n search_student_records\nmark_attendance\ncheck_pending_fees\nget_class_summary\nget_class_students\ngenerate_invoice\nadd_student\nInstead of clicking through five different screens to find pending fees and generate an invoice, an administrator can simply type: "Find all Grade 3 students with pending fees and generate their invoices." The AI agent automatically chains the WebMCP tools to complete the workflow in seconds. \n\n How we built it\nWe adopted a robust full-stack architecture: \n\n Frontend: React and Vite, deployed on Netlify.\nBackend: Java Spring Boot, deployed on Render.\nDatabase: PostgreSQL hosted on Supabase.\nWebMCP Integration: We used the window.document.modelContext.registerTool API inside a secure, authenticated React useEffect hook. We ensured that tools are strictly exposed only after a successful JWT/Session login. Each tool is equipped with a strict JSON schema for input validation, and the execute function securely passes the user's authentication token/cookies to our Spring Boot backend.\nChallenges we ran into\nBuilding a production-ready WebMCP app came with serious hurdles: \n\n Supabase Connection Limits: Our Spring Boot's default HikariCP connection pool quickly exhausted the Supabase free tier's 15 concurrent connections limit, causing FATAL: EMAXCONNSESSION errors during deployment. We solved this by strictly limiting the maximum-pool-size and managing idle timeouts.\nCross-Domain Authentication: Because our frontend was on Netlify and backend on Render, the browser blocked our session cookies, throwing 400 Bad Request errors. We had to dive deep into Spring Security to configure Cross-Site cookies using SameSite=None and Secure=true.\nStrict CORS Policies: Managing wildcard origins with credentials proved difficult until we upgraded our configuration to use allowedOriginPatterns.\nAI Form-Filling Limitations: We learned that headless browsers used by AI agents sometimes struggle with complex SPA login forms, which required us to optimize our DOM structure for agent readability.\nAccomplishments that we're proud of\nSuccessfully building and integrating 7 diverse read and write WebMCP tools in a short span of time.\nAchieving a secure architecture where AI agents operate strictly within the bounds of human authentication (tools are hidden behind the login screen).\nSuccessfully deploying a complex 3-tier architecture (Netlify + Render + Supabase) that runs seamlessly in the cloud.\nWhat we learned\nWe gained a profound understanding of the new WebMCP specifications and how the document.modelContext interacts with the browser's DOM. We also learned how to write strict JSON schemas that prevent AI hallucinations, ensuring the agent always sends exactly what the Spring Boot backend expects. \n\n What's next for Agent-Native School ERP: Powered by WebMCP\nWe plan to expand the agent's capabilities by adding WebMCP tools for generating report cards, scheduling parent-teacher meetings, and eventually integrating an automated WhatsApp notification system for parents directly triggered by the AI agent's actions. \n\n \n\n \n Built With \n\n java postgresql react redux spring typescript webmcp \n \n\n \n Try it out \n\n \n \n \n schoolerp123.netlify.app \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Sumitgupta54856171 Sumit Gupta \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Sumitgupta54856171 Sumit Gupta \n started this project\n \n —\n \n a day ago \n \n \n\n
