The receiving computer rehydrates the same task state for its destination. \n\n People and agents can now collaborate on cross-device task handoff through simple WebMCP tools rather than screen sharing, manual copying, or platform-specific workflows. \n\n Implementation: the web app registers WebMCP tools with document.modelContext.registerTool(...). A small relay stores the latest neutral capsule/state. Each browser can send, receive, and apply that state locally while showing a destination-specific representation. \n\n \n\n \n Built With \n\n cloudflare-tunnel css html javascript node.js webmcp \n \n\n \n Try it out \n\n \n \n \n finder-editor-truly-instructor.trycloudflare.com \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Angie Wilkinson \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n SynHumanity: Safety-focused AI partnerships making tech easy for less-advantaged users, driven by a love for non-profits. \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Angie Wilkinson \n started this project\n \n —\n \n a day ago \n \n \n\n
