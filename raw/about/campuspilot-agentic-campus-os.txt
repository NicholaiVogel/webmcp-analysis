Students may need to find a quiet study space, check availability, plan their day, or perform campus-related actions, but they often have to manually search through multiple pages and interfaces. \n\n We wanted to explore a different approach: what if a campus website could be used directly by an AI agent as a set of structured tools, while still keeping the student in control? \n\n That idea led to CampusPilot — Agentic Campus OS , a WebMCP-powered campus assistant designed to connect students and AI agents with useful campus actions. \n\n What it does \n\n CampusPilot provides an agent-friendly interface for common campus workflows such as: \n\n \n 🔎 Discovering available campus spaces \n 📚 Finding suitable study locations \n 🗓️ Planning campus-related tasks \n ⚡ Executing actions through structured WebMCP tools \n 🤖 Showing an agent's reasoning and planned actions \n 👤 Keeping the human involved through approval before important actions \n \n\n Instead of treating the website as something an agent can only read, CampusPilot exposes functionality through WebMCP tools that an AI agent can understand and invoke. \n\n How we built it \n\n CampusPilot was built as a modern React web application with a premium, responsive interface. \n\n The core architecture is organized around a WebMCP tool layer. We created structured tools with defined schemas and handlers so that an agent can interact with campus functionality in a predictable way. \n\n The application includes: \n\n \n React + TypeScript for the application \n Tailwind CSS for the interface \n Lucide icons for UI elements \n WebMCP imperative APIs for agent-tool interaction \n A deterministic demo agent for demonstrating the complete workflow \n An Agent Reasoning timeline to make agent actions understandable \n A Plan Card that allows the human to review and approve planned actions \n \n\n The most important part of the implementation is that the demo agent and the WebMCP interface use the same underlying tool logic. This helped us demonstrate how an AI agent could move from understanding a user's request to selecting tools and executing a campus workflow. \n\n What we learned \n\n The biggest lesson was that building an agentic application is not only about adding an AI model. \n\n The interface between the agent and the application matters just as much . \n\n WebMCP provides a structured way to expose website capabilities to agents. Designing clear tool names, schemas, inputs, outputs, and handlers made us think about the application from an agent's perspective rather than only from a human user's perspective. \n\n We also learned that human-in-the-loop interaction is important . An agent should be able to plan and recommend actions quickly, while the user should still understand what is going to happen before approving important operations. \n\n Challenges we faced \n\n One of the main challenges was designing WebMCP tools that were both useful for humans and understandable to an AI agent. \n\n We had to carefully structure tool inputs and outputs so that each action had a clear purpose and predictable behavior. \n\n Another challenge was creating a convincing agent experience without hiding what the agent was doing. Instead of simply showing a final result, CampusPilot exposes an Agent Reasoning timeline and planned actions so users can follow the workflow. \n\n We also had to ensure that the application remained reliable during the demo. We tested the application build and the complete tool interaction flow to make sure the WebMCP functionality worked consistently. \n\n Why CampusPilot? \n\n CampusPilot is a small step toward a future where websites are not just pages that humans navigate, but interactive environments that AI agents can safely operate through structured capabilities . \n\n Our goal is to extend this concept beyond a demo into a real campus operating layer where students can ask an agent to accomplish tasks across campus systems while remaining in control of the final decisions. \n\n \n CampusPilot turns a campus website into an agent-ready environment — connecting human intent, WebMCP tools, and AI agents in one workflow. \n \n\n \n\n \n Built With \n\n agentic agents ai artificial css development human-in-the-loop intelligence javascript lucide react tailwind typescript web webmcp \n \n\n \n Try it out \n\n \n \n \n GitHub Repo \n \n \n \n campuspilot-agentic-campus-os-mggi.vercel.app \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Himanshu Meena \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Himanshu Meena \n started this project\n \n —\n \n 2 days ago \n \n \n\n
