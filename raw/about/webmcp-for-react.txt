Inspiration Instead of asking which app to build for WebMCP, I asked how it could reach the open-source tools people already use. Tiptap, react-big-calendar, Excalidraw and Puck cannot be driven from outside the tab; a work queue and a launch room that give each of them a tool set of its own, on a React library that registers tools from hooks and, for a page with no tools, derives them from what it renders with one import and one wrapper, became the entry: Handoff and Kickoff on withreact , built on react-model-context . How WebMCP was implemented Every tool reaches document.modelContext.registerTool through one framework-free registry ( packages/model-context/src/registry.ts in react-model-context ), so the browser's agent, the terminal's agent and the page's UI land in one activity feed, not three. React hooks bind a tool's lifetime to its component's, so the tool set scopes with the UI through toolchange ; on the ChatGPT desktop shim scoped tools stay registered and answer SCOPE_INACTIVE , because churn there costs a page its tools. Failures come back as data ( INVALID_INPUT , DECLINED with the reason, NOT_READY ); calls in flight drain before an abort, which Chrome up to 152 needs. Snapshots carry readOnlyHint and untrustedContentHint , destructive tools consequentialHint . Both repositories were built spec-first from 2026-08-29 , inside the submission period, with dated commits and one archived OpenSpec change per feature — git log and openspec/changes/archive/ show it. The ChatGPT desktop app reaches WebMCP through a shim with a budget of ten tool-set changes per agent turn, sticky scopes and about twenty seconds per call, while Chrome fires toolchange on every registration. Hooks that bind a tool to its component's lifetime would spend that budget in one room, so on the shim scoped tools stay registered and answer SCOPE_INACTIVE instead of unregistering. Unregistering under a call in flight. Chrome up to 152 rejects the page-side caller when a tool goes away mid-call, so the registry drains calls in flight before it aborts a registration.
