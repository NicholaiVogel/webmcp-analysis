WebMCP exposes structured board tools so agents can inspect and act on the live canvas. \n\n Challenges we ran into \n\n The main challenge was making AI actions reliable and transparent. Freehand sketches from an LLM were inconsistent, so we shifted to deterministic visual diagrams. \n\n Accomplishments that we're proud of \n\n We created a working shared canvas, autonomous AI contributions, structured WebMCP tools, and a visible activity trail showing how AI acted. \n\n What we learned \n\n AI works better in collaborative tools when it has clear actions, shared context, and visible boundaries—not unlimited freedom. \n\n What's next for AIchemist \n\n We want to add richer diagram tools, real-time multi-user collaboration, more AI roles, and smarter facilitation for longer brainstorming sessions. \n\n \n\n \n Built With \n\n groq next.js node.js react supabase typescript vercel webmcp \n \n\n \n Try it out \n\n \n \n \n alchemist-liart.vercel.app \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Haaris Muhammed \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Haaris Muhammed \n started this project\n \n —\n \n 3 days ago \n \n \n\n
