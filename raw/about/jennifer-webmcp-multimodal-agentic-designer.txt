\n \n\n \n \n 1-Click Direct Checkout: Automated Shopify Cart Permalink pre-loading bundled items and promotional discounts. \n \n 1 2 3 4 5 6 \n\n\n\n \n Inspiration \n\n Shopping for home furniture online has a fundamental visual and spatial disconnect: \n\n \n A customer uploads a photo of their living room and asks: "Which sofa from this website will look beautiful in this room, fit between my walls with proper walking clearance, and stay under my $ 2,500 budget?" \n Standard AI chatbots fail because they either hallucinate fictional 3D furniture models that do not exist, or they just return a list of text links without understanding the room's physical layout or visual aesthetics. \n \n\n We built Jennifer WebMCP to turn Jennifer Furniture's Shopify Plus store (14,447 catalog products) into an agent-native spatial shopping engine . By implementing the experimental WebMCP standard, AI agents in ChatGPT and Google Chrome can natively interact with the catalog, evaluate room spatial clearance, extract authentic visual assets, and generate 1-click direct checkouts. \n\n \n\n What it does \n\n Jennifer WebMCP exposes a suite of structured tools directly to AI agents via /api/mcp/manifest : \n\n \n find_products_by_constraints :\nSearches Jennifer Furniture's 14,447 catalog items by price budget ($B \\le $ 2,500$), dimensions, room category, and fabric types. \n get_product_visual_asset (The Visual Bridge) :\nSolves the core problem of AI visual hallucinations. Instead of describing furniture in plain text, WebMCP fetches the canonical high-resolution Shopify CDN photography, converts it into a byte-level base64 data URI, and supplies explicit geometry-preservation prompt anchors for GPT-4o Vision and diffusion models. \n calculate_room_fit_and_clearance :\nEvaluates spatial boundaries and perimeter walkway clearance $d_{\\text{clearance}}$: \n \n\n d clearance = W room − ( W sofa + 2 × d margin ) \n\n Verdict = { "OPTIMAL_FIT" , if  d clearance ≥ 36  inches   "ACCEPTABLE_FIT" , if  30  inches ≤ d clearance < 36  inches   "RESTRICTED_WALKWAY" , if  d clearance < 30  inches \n\n \n build_coordinated_room_bundle :\nPairs the chosen sofa with a matching ottoman and accent chair, automatically applying a promotional 15% bundle discount: \n \n\n P bundle = 0.85 × ∑ j = 1 3 P j \n\n \n create_checkout_handoff :\nGenerates an official direct Shopify Cart Permalink that pre-loads all selected items and discounts into a 1-click instant checkout. \n \n\n \n\n How we built it \n\n \n WebMCP Platform : Next.js 14 App Router and TypeScript deployed live on Vercel ( https://jennifer-webmcp.vercel.app ), serving OpenAPI 3.1.0 JSON-RPC manifests at /api/mcp/manifest . \n Multimodal Visual Asset Bridge : Dedicated edge endpoint ( /api/tools/visual-asset ) proxying Shopify CDN assets into base64 visual anchors with geometry preservation rules. \n Storefront Voice & Web Client : Lightweight zero-dependency SDK ( public/widget.js ) registering WebMCP tools on the client window.WebMCP object for browser-based agents. \n Shopify Plus Commerce Engine : Direct integration with Shopify Storefront API and cart permalink architecture for frictionless checkout handoff. \n \n\n \n\n Challenges we ran into \n\n \n Eliminating Generative Hallucinations in Room Staging :\nWhen vision models try to place a sofa into a user's photo using only text, they frequently alter the cushions, armrests, or fabric color. We built get_product_visual_asset to feed byte-level pixel data directly into the model's multimodal prompt, anchoring the generation to the authentic product. \n Standardizing Agent Tool Schemas :\nEnsuring that complex spatial queries (room dimensions, lighting conditions, budget constraints) are cleanly validated using standard WebMCP JSON schemas so any client (ChatGPT, Chrome extension, Claude) can invoke them reliably. \n \n\n \n\n Accomplishments that we're proud of \n\n \n Zero-Hallucination Visual Staging : Proving that WebMCP visual asset bridges allow agents to stage authentic catalog furniture with 100% geometric fidelity. \n Sub-200ms Latency : Delivering real-time catalog search and room fit calculations across 14,400+ products on Vercel Edge. \n True 1-Click Checkout Loop : Seamless transition from conversational room design in ChatGPT straight into Shopify checkout. \n \n\n \n\n What we learned \n\n WebMCP bridges the gap between text-only AI reasoning and real-world spatial commerce. By providing agents with structured tools and canonical visual assets, e-commerce stores can offer personal interior design consultations directly inside AI chats. \n\n \n\n What's next for Jennifer WebMCP: Multimodal Agentic Interior Designer \n\n \n Mobile LiDAR 3D Room Mesh Extraction : Direct boundary estimation from iPhone LiDAR scans. \n WebXR Spatial Staging : Streaming interactive 3D GLTF models to Apple Vision Pro and Meta Quest agents. \n Real-Time Fabric & Finish Swapping : Allowing agents to swap velvet, leather, and wood finishes dynamically via WebMCP variant tools. \n \n\n \n\n \n Built With \n\n ai-agents amazon-web-services aws-lambda aws-secrets-manager computer-vision e-commerce generative-ui graphql json-rpc model-context-protocol multimodal-ai next.js node.js openai postgresql python react rest-api shopify shopify-api tailwind-css typescript vercel webmcp \n \n\n \n Try it out \n\n \n \n \n jennifer-webmcp.vercel.app \n \n \n \n jennifer-webmcp.vercel.app \n \n \n \n jennifer-webmcp.vercel.app \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Pran4th Kedia \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n 1 \n \n \n\n\n \n 1 person likes this:\n \n\n \n \n \n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Pran4th Kedia \n started this project\n \n —\n \n 2 days ago \n \n \n\n
