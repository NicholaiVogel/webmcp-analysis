I wanted one place where I could see where chords land in the beat, hear the groove, find useful funk chords, and practice against drums instead of jumping between different tools. \n\n What it does \n\n Funk Trainer is a visual sequencer for practicing funk guitar. You can place chords on rhythmic subdivisions, change keys, explore funk chord voicings, generate grooves, and play along with drums.\nThe goal is to make where you play as clear as what you play. \n\n How we built it \n\n is an interactive web-based sequencer that keeps the visual grid, guitar, and drums synchronized. \n\n also added WebMCP, exposing the trainer's controls as tools that an AI agent can use. An agent can change the key, generate a groove, select chords, and place beats in the sequencer. \n\n This means you can ask something like "Show me a groove using the chords from Superstition" and let the agent translate its musical knowledge into the UI. \n\n Challenges we ran into \n\n The main challenge was timing: keeping the sequencer, drums, guitar, and visual feedback synchronized while keeping the interface simple enough for practice. \n\n Another challenge was designing useful WebMCP tools that let an agent control the application without needing to understand its internal implementation. \n\n Accomplishments that we're proud of \n\n Turning something I personally struggle with into a tool I can actually practice with. \n\n I am also excited about making the application agent-controllable through WebMCP. Instead of AI only explaining a rhythm, it can actually build that rhythm inside the trainer. \n\n What we learned \n\n Building the trainer reinforced that funk isn't just about which chords you play. The placement, subdivisions, silence, and relationship with the drums are what create the groove. \n\n I also learned that WebMCP creates an interesting bridge between an AI's musical knowledge and an interactive application. \n\n What's next for funk-trainer \n\n The next step is connecting the agent to real song data. \n\n For example, the agent could retrieve the chords and structure of a song from a platform such as Ultimate Guitar and then automatically plot those chords and their timing into Funk Trainer. this would speed up the process as Codex does not have to look on the internet but already has a reliable source. \n\n From there, Funk Trainer could become a way to go from "I want to learn this song" to an interactive, playable rhythm exercise generated directly from the song. \n\n The immediate change will be to add a an acoustic sound instead of a machine like one. \n\n \n\n \n Built With \n\n html5 javascript webmcp \n \n\n \n Try it out \n\n \n \n \n funk-trainer.kmil0cv.chatgpt.site \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Camilo Vasco \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Camilo Vasco \n started this project\n \n —\n \n 2 days ago \n \n \n\n
