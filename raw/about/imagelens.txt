ImageLens does. \n\n How we built it \n\n ImageLens is a web application with a client-side forensic analysis engine and a WebMCP integration. \n\n The application's analysis engine produces structured results that are exposed through WebMCP tools. \n\n The agent can query capabilities such as: \n\n \n analyze_image \n get_detection_score \n get_forensic_signals \n get_metadata \n get_frequency_analysis \n get_report \n \n\n These tools provide the agent with the same information available inside the application, without requiring the user to manually copy and paste results into an AI assistant. \n\n The application and its WebMCP tools share the same underlying analysis logic, keeping the agent's information synchronized with the actual application state. \n\n Challenges we ran into \n\n One of the main challenges was deciding where the responsibility between the application and the AI should stop. \n\n We deliberately did not make the AI the detector. \n\n The forensic engine is responsible for analyzing the image and producing evidence. The AI is responsible for querying that evidence, connecting the different signals, and explaining them. \n\n Another challenge was turning complex forensic information into structured WebMCP tools that an agent can understand and use effectively. \n\n Accomplishments that we're proud of \n\n We are proud that ImageLens is more than an image analyzer with an AI chatbot attached to it. \n\n The WebMCP integration allows an agent to directly access the application's real forensic data. \n\n An agent can independently retrieve different types of evidence, combine them, and produce an investigation-style explanation. \n\n This creates a clear division of responsibilities: \n\n ImageLens analyzes.\nThe agent investigates.\nThe human makes the final judgment. \n\n We also designed the application to avoid making absolute claims about image authenticity. Forensic signals can indicate suspicious characteristics, but they cannot provide mathematical proof that an image was generated by AI. \n\n What we learned \n\n We learned that WebMCP can be particularly powerful for specialized applications. \n\n Instead of trying to make the AI reproduce the application's domain-specific logic, the application can expose its expertise through structured tools. \n\n This allows an AI agent to become an interface to specialized software without replacing the software itself. \n\n We also learned that good WebMCP tools should expose meaningful domain-level capabilities rather than simply reproduce UI interactions. \n\n What's next for ImageLens \n\n The next step would be to expand the forensic toolkit with additional analysis methods and comparison capabilities. \n\n Possible future features include comparing multiple images, detecting inconsistencies between image regions, generating more detailed forensic reports, and allowing agents to conduct multi-step investigations across several images. \n\n The long-term goal is to make ImageLens a specialized forensic engine that AI agents can use as part of larger investigation workflows. \n\n ImageLens doesn't just detect. It gives agents evidence they can investigate and explain. \n\n \n\n \n Built With \n\n ai-agents artificial-intelligence image-forensics lucide openai react tailwind vite web-development webmcp \n \n\n \n Try it out \n\n \n \n \n imagelens.vercel.app \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Clément Jonghmans \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n 1 \n \n \n\n\n \n 1 person likes this:\n \n\n \n \n \n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Clément Jonghmans \n started this project\n \n —\n \n 2 days ago \n \n \n\n
