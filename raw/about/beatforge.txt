Inspiration \n\n I wanted to explore what music creation would feel like if an AI agent could actually work inside a sequencer instead of just telling us what to play. \n\n What it does \n\n BeatForge is a live 16-step music sequencer where humans can create beats manually while an AI agent can control the same session through WebMCP. \n\n How we built it \n\n Built with Vite, JavaScript, Tone.js and WebMCP with structured tools that let an agent change the tempo, tracks, steps and patterns directly in the sequencer. \n\n Challenges we ran into \n\n The biggest challenge was making agent actions and human controls work together smoothly while keeping the music responsive in real time. \n\n Accomplishments that we're proud of \n\n Built a working experience where anyone can create a beat themself, ask an agent to change it and immediately hear the result while still keeping control as the human. \n\n What we learned \n\n Learnt how actually the WebMCP works \n\n What's next for BeatForge \n\n want to expand BeatForge with more instruments, richer patterns, better collaboration and more ways for humans to guide the music. \n\n \n\n \n Built With \n\n html javascript tone.js
