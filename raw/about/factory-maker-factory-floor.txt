A shared 3D Earth that people and browser agents can explore together through six typed WebMCP tools. Like Comment Story Updates Inspiration Climate systems are difficult to understand from articles and static charts alone. TERRA explores a more direct interface: ask a question, let a browser agent change the shared Earth scene through WebMCP, and inspect the same evidence together. What it does TERRA is an interactive 3D Earth for exploring climate evidence. A person can drag and zoom the globe, choose a region, scientific layer, IPCC scenario, year, and presentation style. A WebMCP-capable browser agent can operate those same controls through six typed tools. The current experience connects: NASA Blue Marble day imagery, Black Marble night lights, and a moving cloud shell OSCAR-derived open ocean-current streamlines NOAA OISST v2.1 observed sea-surface temperature NSIDC Sea Ice Index observed September 2025 extent IPCC AR6 global temperature and sea-level assessment ranges Short, interruptible Arctic–AMOC and global sea-level stories Why WebMCP This is not a chatbot placed beside a globe. The website exposes its real controls with document.modelContext.registerTool . The agent can read the scene, fly to named regions, change an evidence layer, set a scenario and year, change the rendering style, or play a guided story without guessing DOM coordinates. Every write requires the current revision. Stale writes are rejected with revision_conflict . Human controls and agent tools mutate the same visible browser state, and a human action interrupts an active agent story. Human and agent collaboration The agent can compose several precise scene changes from a natural-language question. The person keeps direct control: they can rotate and zoom the globe, interrupt the sequence, compare sources, and choose how the evidence is presented. Both sides see the same camera, data layer, year, sources, and uncertainty labels. How we built it TERRA uses Next.js 16, React 19, TypeScript, Three.js, Vinext, and ChatGPT Sites. The page registers six imperative WebMCP tools: earth_read_scene earth_focus_region earth_set_layer earth_set_scenario earth_set_render_style earth_play_story The Earth renderer uses locally bundled NASA imagery. Ocean-current paths were generated from the July 2014 mean of six OSCAR five-day composites obtained from the public NOAA CoastWatch mirror. The temperature texture is an August 2026 mean of 30 available daily NOAA OISST preliminary fields. Missing SST cells remain transparent. The sea-ice geometry is based on the NSIDC September 2025 extent mask. Scientific boundary TERRA is an exploratory, reduced-order visualization. It does not run a global climate model, predict weather, or map local flooding. The fixed day/night lighting is presentation lighting, not the current solar position. Future sea-ice contraction is marked as illustrative rather than presented as a geographic forecast. Challenges The hardest work was maintaining scientific honesty while still creating a cinematic experience. We separated observed textures, assessed global ranges, reduced-order interpolation, and illustrative future geometry in both the interface and narration. We also corrected longitude alignment, story interruption, scenario-dependent AMOC values, and reduced-motion behavior through an adversarial audit. Accomplishments A working public 3D Earth that both a person and a browser agent can control Six narrow, discoverable WebMCP tools with optimistic locking Visible provenance and uncertainty boundaries Photographic Earth rendering with data-derived scientific overlays English and Japanese interfaces A public MIT-licensed repository with reproducible data-generation scripts What we learned WebMCP is most valuable when it lets an agent conduct a living interface rather than imitate clicks. The protocol also makes responsibility clearer: the site defines the available actions and data boundaries, while the person can see, interrupt, and redirect every shared state change. Testing Open the live URL in ChatGPT's in-app browser with WebMCP enabled. Ask the agent to read the scene, focus on Japan, show ocean currents, then move to the Arctic and display sea ice in 2100. The final Arctic state should be labelled illustrative. You can also drag the globe and use the zoom controls directly.
