They were either restricted to 2D screenshot vision models or dependent on external backend servers and custom plugins. \n\n PointCanvas changes this completely by leveraging WebMCP — registering native client-side spatial inspection tools directly to document.modelContext . \n\n \n\n 🛰️ What It Does \n\n PointCanvas is a high-performance, browser-based collaborative 3D point cloud inspection workspace where humans and AI agents work together in real-time. \n\n \n Client-Side WebMCP Tool Registration : Registers 5 specialized spatial primitives ( load_demo_dataset , filter_classification , focus_bounding_box , apply_cross_section_slice , add_spatial_annotation ) using standard JSON Schemas directly on document.modelContext . \n Zero-Latency In-Browser Execution : Tool calls execute client-side inside the browser tab in under 10ms with zero backend API roundtrip latency. \n Bi-Directional 3D Visual Feedback : As the AI agent executes WebMCP tools, custom Three.js shaders isolate ASPRS point classes (Ground, Vegetation, Buildings, Poles & Power Wires), WebGL clipping planes slice structural cross-sections, and camera controls smoothly animate to focus coordinates. \n Collaborative Spatial Pins : AI agents can detect structural defects or wire sags and drop interactive 3D billboard pins right onto target coordinates for human review. \n Real-time Telemetry Drawer : Includes a live WebMCP execution activity feed drawer displaying tool calls, raw JSON parameters, and execution state. \n \n\n \n\n 🛠️ How We Built It \n\n PointCanvas is built from the ground up as a modern, single-page WebGL application: \n\n \n Core Framework : React 18 + Vite + TypeScript + Tailwind CSS \n 3D Graphics Engine : Three.js + React Three Fiber ( @react-three/fiber ) + @react-three/drei \n Data Loaders : Custom PCD (Point Cloud Data) ASCII/Binary & PLY mesh parsers supporting ASPRS feature classifications and RGB channels. \n State Management : Zustand store ( usePointCanvasStore ) tracking active datasets, shader modes, clipping planes, annotations, and WebMCP call logs. \n WebMCP Integration : Native document.modelContext.registerTool(...) registration module ( src/lib/webmcp.ts ) connected directly to client-side store actions. \n Open Source : Licensed under the OSI-approved MIT License . \n \n\n \n\n 🚧 Challenges We Ran Into \n\n \n High-Dimensional 3D Primitives in JSON Schema : Designing clean, serializable JSON schemas for 3D camera matrices, ASPRS classification arrays, and WebGL clipping plane vectors that LLM agents can reliably invoke. \n Sub-10ms WebGL Shader Updates : Ensuring custom Three.js ShaderMaterial uniforms re-render dynamically as classification filters or elevation range windows change without dropping below 60 FPS. \n Simulated vs Native WebMCP Bridge : Providing an interactive WebMCP Agent Execution Feed and simulator playground so judges can test and observe real-time tool calls in any browser environment. \n \n\n \n\n 🏆 Accomplishments We're Proud Of \n\n \n Successfully implementing native client-side document.modelContext.registerTool for complex 3D WebGL graphics in the browser. \n Achieving sub-10ms tool execution latency by running all spatial primitives client-side. \n Creating a fully functional 3D inspector with custom PCD/PLY data generators, cross-section slicing, ASPRS point classification, and 3D billboard callout pins. \n Producing a complete narrated demo video using ndemo with title cards, automated browser actions, and synchronized audio. \n \n\n \n\n 🎓 What We Learned \n\n \n How WebMCP bridges the gap between LLM web agents and complex web graphics, turning static browser canvases into interactive, agentic workspaces. \n Best practices for designing intuitive JSON Schema interfaces for spatial domain tools. \n \n\n \n\n 🔮 What's Next for PointCanvas \n\n \n Multi-User WebSockets : Real-time multi-agent and multi-human collaborative sessions. \n Large-Scale EPT / Entwine Point Tile Loading : Support for multi-gigabyte LiDAR datasets via octree streaming. \n Automated WebMCP Defect Detection : Training agent prompts to run automated structural
