CodeYam makes it easy to vibe code complex software applications but you still need to think deeply about what that software should do and how it should behave in various situations. Thinking Map helps with this but is not limited to software challenges. It is a general thinking tool. \n\n What it does \n\n Thinking Map is designed to help you think. Whether you want to plan a party, go on a trip, or build a software application, Thinking Map creates a robust user-experience for you and an AI agent to think about complex situations and challenges from multiple different perspectives while coming up with insights and devising experiments to move you forward. The visual experience and interactions complement the available agent chat, making the complexity of the project more understandable and easier to iterate on as you learn more and engage in experiments. \n\n How we built it \n\n Thinking Map was built using CodeYam to ensure a highly maintainable application. CodeYam let us vibe code it using both Codex and Claude Code. We were able to rapidly build and iterate on it over the course of just three days. \n\n Challenges we ran into \n\n Our biggest challenge was creating a useful user-experience while sharing screen real estate with the agent in ChatGPT Desktop. We are still working to improve this. \n\n Accomplishments that we're proud of \n\n We were able to build and iterate across a number of possible designs quickly over the course of just three days to create our submission. \n\n What we learned \n\n We were not aware of the WebMCP format but have been looking for a high quality way to supplement agent chat experiences with robust browser-based user experiences. We plan on leveraging WebMCP more going forward. \n\n What's next for Thinking Map \n\n We want to continue to improve the user-experience and the different ways Thinking Map can help you deconstruct your challenge and look at it from different perspectives. We also want to make it easier to engage in the experiments it suggests. \n\n \n\n \n Built With \n\n claude codex codeyam supabase typescript vercel \n \n\n \n Try it out \n\n \n \n \n thinkingmap.codeyam.com \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Jared Cosulich \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n\n \n Nadia Eldeib \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n 1 \n \n \n\n\n \n 1 person likes this:\n \n\n \n \n \n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Jared Cosulich \n started this project\n \n —\n \n a day ago \n \n \n\n
