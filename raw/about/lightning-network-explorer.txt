We wanted to build a tool the wider Nostr community could actually use, and one that's genuinely built for the agent-native web this hackathon is exploring — not just a human-facing dashboard, but a site AI agents can query and act on directly. \n\n What it does \n\n Lightning Network Explorer lets you: \n\n \n Search Lightning nodes by pubkey or alias, with capacity, channel count, and network scoring pulled from Amboss \n View detailed node stats on a per-node basis \n See network-wide stats — total nodes, channels, and capacity \n Match a Nostr identity (npub or NIP-05) to its associated Lightning address and node data, resolved live against our own relay (wss://hasky.chat) \n \n\n With WebMCP support, an AI agent can call these same lookups directly — searching a node, pulling network stats, or resolving a Nostr identity's Lightning presence — without needing a human to click through the UI first. \n\n How we built it \n\n Built with Next.js, TypeScript, and Tailwind. Node and network data comes from the Amboss GraphQL API; Nostr profile resolution runs against our own relay at wss://hasky.chat. WebMCP tools are registered via document.modelContext.register(), exposing node search, node detail, and network stats directly to agents. \n\n Challenges we ran into \n\n Getting clean fallback behavior for malformed or unknown pubkeys (Amboss returns a GraphQL error rather than a clean "not found," which we had to handle gracefully), and designing the Nostr × Lightning matcher so it degrades sensibly when no match is found rather than treating that as an error state. \n\n What's next \n\n Deeper zap/wallet interactions via Alby Hub and NWC, historical trend charts for network growth, and expanding node scoring with more data sources. \n\n \n\n \n Built With \n\n amboss-api bitcoin graphql lightning-network next.js nostr tailwind-css typescript webmcp \n \n\n \n Try it out \n\n \n \n \n ln-explorer-hasky.netlify.app \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n I worked and develop relay was://hasky.chat. for the nostr community and for mass adaptation bitcoin using my own node . \n \n\n \n \n \n \n \n \n\n \n Ernawati Djuansjah \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n alias hasky \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Ernawati Djuansjah \n started this project\n \n —\n \n 5 days ago \n \n \n\n
