We wanted to test whether WebMCP could give an AI agent structured tools while keeping every decision visible to a human. \n\n What it does- The workbench contains fictional HVAC intake cases and exposes 9 WebMCP tools. An agent can inspect cases, classify trade/intent/urgency, identify missing information, and evaluate results with deterministic scoring. \n\n How we built it- We built a browser-based evaluation workbench with structured WebMCP tools, a deterministic scorer, fictional test cases, and a human-visible interface so agent and human can work from the same information. \n\n Challenges we ran into- The biggest challenge was making the tool behavior deterministic and easy to verify while getting WebMCP browser support working reliably. \n\n Accomplishments that we're proud of- A live WebMCP-enabled application, 9 working tools, public source code, and repeatable scoring that makes agent decisions inspectable. \n\n What we learned- WebMCP can reduce brittle browser automation by exposing structured actions directly to agents while preserving human oversight. \n\n What's next for HVAC Intake Eval Workbench- Expand the benchmark, add more service-industry workflows, and test the same approach with real-world intake systems. \n\n \n\n \n Built With \n\n css html javascript webmcp \n \n\n \n Try it out \n\n \n \n \n firstmoverprojects.github.io \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n firstmoverprojects Jamison \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n 1 \n \n \n\n\n \n 1 person likes this:\n \n\n \n \n \n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n firstmoverprojects Jamison \n started this project\n \n —\n \n 2 days ago \n \n \n\n
