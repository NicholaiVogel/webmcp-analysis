That was my inspiration for this project \n\n Businesses often rely on data spread across CSV files, supplier records, inventory systems, purchase histories, and other disconnected sources. The idea behind DataBridge Agent was to create a practical AI workflow that can inspect that fragmented data, identify problems, and turn the findings into clear business actions without allowing the agent to make consequential changes without human approval. \n\n What it does \n\n DataBridge Agent is a WebMCP-enabled business data assistant. \n\n It exposes eight structured tools: \n\n \n inspect_dataset \n find_duplicates \n detect_missing_fields \n compare_datasets \n detect_anomalies \n analyze_price_changes \n create_action_plan \n export_clean_data \n \n\n The agent can inspect loaded business data, detect duplicate records and missing fields, compare related datasets, identify unusual numeric values, analyze price movements, and generate a prioritized action plan. \n\n Export is intentionally protected by a human-approval gate. The source data remains unchanged, and a cleaned copy is only created after explicit approval. \n\n How I built it \n\n I built DataBridge Agent as a React and TypeScript application hosted on Replit. \n\n The WebMCP tool layer is registered through the browser model context so compatible agents can discover and call structured tools instead of relying on page scraping or fragile UI automation. \n\n The application also includes an embedded AI Agent Demo that runs the same DataBridge business logic locally when native WebMCP is unavailable. The interface clearly distinguishes native WebMCP activity from local demo-agent activity. \n\n The core data-analysis functions are shared between the WebMCP tool wrappers and the embedded demo workflow so the results come from the loaded data rather than hardcoded demo values. \n\n Challenges I faced \n\n One major challenge was testing an experimental browser capability across different environments. In a normal browser, the WebMCP API was not exposed, so I added clear capability detection rather than falsely presenting local execution as native WebMCP. \n\n After enabling WebMCP testing in a compatible Chrome environment, the live application successfully detected native WebMCP support. \n\n Another challenge was designing safe agent behavior. Data analysis can run automatically, but export is treated as a consequential action and requires explicit human approval. \n\n I also focused on making the execution transparent by showing the tool sequence, results, data source, and approval status directly in the interface. \n\n What I learned \n\n This project showed me how WebMCP can make web applications much more useful to AI agents by exposing structured capabilities instead of forcing agents to interpret interfaces visually. \n\n I also learned that agent capability should be paired with transparency and human control. A useful business agent should not only produce an answer; it should make its actions auditable and clearly separate analysis from actions that can affect data. \n\n What's next \n\n The next step is to expand DataBridge Agent beyond CSV-based workflows into more live business systems, including databases, procurement platforms, inventory systems, and other operational data sources. \n\n I would also like to add more configurable tool schemas, stronger cross-dataset matching, and reusable approval policies for different business actions. \n\n \n\n \n Built With \n\n css github html javascript papa react replit typescript webmcp \n \n\n \n Try it out \n\n \n \n \n data-bridge-agent.replit.app \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Tray Young \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Tray Young \n started this project\n \n —\n \n 2 days ago \n \n \n\n
