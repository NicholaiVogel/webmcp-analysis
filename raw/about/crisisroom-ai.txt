The project explores how an AI agent can investigate a security incident, analyze evidence, and prepare a containment action while keeping a human in control of the final decision. \n\n What I built \n\n CrisisRoom AI is a fictional incident-response dashboard connected to WebMCP. It exposes structured tools that an AI agent can use to retrieve incident information, inspect affected assets, analyze the situation, create an action draft, and generate an incident report. \n\n Human-in-the-loop \n\n The key design principle is that the AI can investigate and prepare an action, but it cannot execute containment on its own. The proposed action remains pending until a human explicitly approves or rejects it. \n\n What I learned \n\n This project helped me understand how WebMCP can connect AI agents directly to useful web application capabilities instead of relying only on UI interaction. I also learned how important clear tool definitions, application state, and human approval are when building AI-assisted security workflows. \n\n Challenges \n\n The main challenge was designing a realistic workflow while keeping the application fictional and safe. I focused on demonstrating the interaction between the agent, WebMCP tools, the incident state, and the human approval interface. \n\n \n\n \n Built With \n\n css html javascript vite webmcp webmcp-polyfill \n \n\n \n Try it out \n\n \n \n \n crisisroom-ai.netlify.app \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Kouassi Hermann Kouakou \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Kouassi Hermann Kouakou \n started this project\n \n —\n \n 6 days ago \n \n \n\n
