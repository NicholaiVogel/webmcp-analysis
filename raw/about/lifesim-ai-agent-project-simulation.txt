These tools return real data from the running simulation instead of relying on a static description. \n\n Human-in-the-loop \n\n An important part of LifeSim is keeping the human in control. \n\n The AI agent can analyze the situation and recommend an action, but consequential state changes go through an explicit preview and confirmation flow. This makes the agent's actions visible and understandable instead of allowing decisions to happen silently. \n\n The interface also shows Agent Activity so that users can see what the agent is doing and how successful tool calls affect the simulation. \n\n What we learned \n\n Building LifeSim helped us understand how WebMCP can connect an AI agent with a real interactive web application through structured tools. \n\n Instead of treating an AI agent as a separate chatbot, WebMCP allows the agent to work with the application's actual state and capabilities. \n\n We also learned the importance of designing clear tool interfaces and making state-changing actions observable and controllable. \n\n Challenges \n\n One of the main challenges was making sure that the AI agent, WebMCP tools, and simulation UI remained synchronized. \n\n We tested the project through multiple demo steps and verified that the WebMCP tools returned the expected simulation data and that the project could successfully build and run. \n\n We also had to work around an API quota limitation during development. Because the core WebMCP functionality is independent from that limitation, we focused on making the underlying simulation, tools, validation, and agent workflow reliable. \n\n Why WebMCP matters \n\n LifeSim demonstrates how WebMCP can let an AI agent interact with a live web application through structured tools while keeping the human in control of consequential actions. \n\n The goal is not simply to make an AI that talks about a simulation, but an AI that can understand the application's state, reason about available actions, and interact with the application through explicit, verifiable tools. \n\n \n\n \n Built With \n\n openai typescript vite webmcp \n \n\n \n Try it out \n\n \n \n \n GitHub Repo \n \n \n \n life-sim-pied.vercel.app \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Ramiz Matlabov \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Ramiz Matlabov \n started this project\n \n —\n \n 2 days ago \n \n \n\n
