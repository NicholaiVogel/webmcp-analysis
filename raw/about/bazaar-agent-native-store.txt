AI assistants can recommend products, but they usually cannot directly interact with a website to perform real shopping actions. \n\n We wanted to explore a simple question: What if an AI agent could actually shop on the same website as a human? \n\n That idea inspired Bazaar — Agent-Native Store. We built Bazaar to demonstrate how WebMCP can turn a traditional e-commerce website into an agent-native experience where AI agents can discover products, make decisions, manage carts, and complete purchases. \n\n Our goal was not to build another AI chatbot, but to make the website itself usable by AI agents. \n\n What it does \n\n Bazaar is an agent-native e-commerce store powered by WebMCP. \n\n It exposes 12 functional WebMCP tools that allow AI agents to: \n\n • Search and filter products\n• View product details\n• Compare products\n• Get recommendations\n• Add products to the cart\n• Update cart quantities\n• Remove products\n• View the cart\n• Clear the cart\n• Checkout\n• View order history\n• Browse product categories \n\n For example, an agent can receive a request like: \n\n "Find me running shoes under ₹2000 and add the cheapest one to my cart." \n\n The agent can search the catalog, find the best matching product, and add it directly to the user's cart. \n\n The most important part is that humans and AI agents share the same application state. When an agent adds a product, it immediately appears in the user's normal cart and is marked as "Added by agent." \n\n Bazaar also includes a live Agent Activity feed so users can see what the agent is doing. \n\n How we built it \n\n We built Bazaar using Next.js 16, React, TypeScript, Tailwind CSS, shadcn/ui, Zustand, Prisma ORM, SQLite, and WebMCP. \n\n The WebMCP integration uses: \n\n document.modelContext.registerTool() \n\n We created 12 tools with clear descriptions, input schemas, and execution functions. \n\n A key architectural decision was to make WebMCP use the same application logic as the human interface. \n\n The WebMCP tools call the same Zustand store actions used by the React UI. \n\n This creates a shared architecture: \n\n Human UI → Zustand Store ← WebMCP Tools ← AI Agent \n\n Because both interfaces use the same store and business logic, humans and AI agents share the same product catalog, cart, application state, and order flow. \n\n The application is deployed on Vercel and includes an Agent Activity system for transparent tool execution. \n\n Challenges we ran into \n\n One of our biggest challenges was understanding how WebMCP tools are exposed and executed in the browser. \n\n Initially, we expected tools such as search_products() to behave like normal JavaScript functions. We learned that WebMCP tools are exposed through the browser's model context instead. \n\n We also had to carefully design tool descriptions and input schemas so AI agents could understand what each tool does, which parameters it accepts, and what information it returns. \n\n Another challenge was synchronizing agent actions with the human UI. \n\n We did not want the AI agent to have a separate cart or application state. Instead, every agent action had to use the same business logic as the human interface. \n\n Testing complete workflows such as product search → selection → add to cart → cart management → checkout also required careful integration between WebMCP and our application state. \n\n Accomplishments that we're proud of \n\n We are proud that Bazaar goes beyond simply registering WebMCP tools. We built a complete agent-native shopping workflow. \n\n Our key accomplishments include: \n\n • 12 functional WebMCP tools\n• Shared human + AI shopping cart\n• Agent actions visibly marked in the UI\n• Live Agent Activity feed\n• Natural-language product discovery\n• Price filtering and product sorting\n• Product comparison and recommendations\n• Cart management and checkout\n• Order history\n• WebMCP connected directly to the same business logic used by the UI\n• A fully deployed live web application \n\n The biggest accomplishment is demonstrating that WebMCP can transform a traditional e-commerce website into an application that AI agents can actively operate, not just read. \n\n What we learned \n\n Building Bazaar taught us that creating an agent-native application is more than adding an AI chatbot. \n\n The tools themselves become an important part of the application's interface. \n\n We learned that WebMCP tools need clear descriptions, well-defined schemas, predictable outputs, and reliable execution. \n\n We also learned the importance of shared application state. By connecting WebMCP directly to our existing business logic, agent actions behave consistently with actions performed through the human UI. \n\n Most importantly, we learned that websites can be designed for two types of users: humans through visual interfaces and AI agents through structured tools. \n\n WebMCP provides an exciting way to bridge these two experiences. \n\n What's next for Bazaar — Agent-Native Store \n\n Bazaar currently focuses on the core agent-native shopping experience. Our next goal is to make the platform more intelligent, autonomous, and user-controlled. \n\n Future plans include: \n\n • More intelligent personalized recommendations\n• Conversational shopping experiences\n• Multi-step autonomous shopping workflows\n• Better agent activity and audit history\n• Permission controls for sensitive actions\n• More payment and checkout options\n• Improved mobile experience\n• Integration with external commerce services\n• Multi-agent shopping workflows \n\n Our long-term vision is to build an e-commerce platform where AI agents can safely discover, compare, purchase, and manage products on behalf of users while keeping the user in control. \n\n \n\n \n Built With \n\n agentic agents ai artificial css development e-commerce generative intelligence javascript next.js prisma react sqlite tailwind typescript vercel web webmcp zustand \n \n\n \n Try it out \n\n \n \n \n GitHub Repo \n \n \n \n youtu.be \n \n \n \n docs.google.com \n \n \n \n bazaar-web-mcp.vercel.app \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n I designed, developed, and deployed Bazaar — Agent-Native Store.
