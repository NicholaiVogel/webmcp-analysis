The best SKILL.md files are scattered across GitHub, and loading them blindly is risky. One prompt injection can hijack an agent. We wanted one link that gives any agent safe, searchable skills with zero setup. \n\n What it does \n\n SkillsWebMcp is a WebMCP + MCP server with 4,986 agent skills from 22 GitHub repos, all security-audited for prompt injection. \n\n Any agent opens this and can use it like its own MCP server:\n https://swmcp.vercel.app/api/webmcp/intro \n\n Live demo: https://swmcp.vercel.app/ \nOpen source: https://github.com/AbinashBalaraman/skills-webmcp \n\n How I built it \n\n Node + Express + TypeScript backend, React + Vite + Tailwind frontend. \n\n \n Scrape GitHub for SKILL.md , check license, audit content, store by SHA \n Expose 2 tools: search_skills and get_skill_manual \n Serve 3 ways: browser WebMCP via document.modelContext , classic MCP JSON-RPC, plain REST + GET for small LLMs \n Ship a 9.5MB gzipped snapshot so Vercel cold-starts in seconds \n \n\n Challenges I ran into \n\n Literal search failed. waterfall animation returned 0 hits. We fixed it by teaching agents to decompose tasks like professionals first — animation, 3d, canvas, shader, gsap — then search each domain. \n\n Accomplishments that we're proud of \n\n \n 4,986 skills, 100% audited, live and fast \n Any LLM works with 2 calls, no browser or config needed \n Real proof: an agent built a working WebGL waterfall page from our skills alone \n \n\n What I learned \n\n Small models are not dumb, they just need clearer steps. A short quickStart + primaryTools + GET fallback helped more than any protocol change. \n\n Token math proved progressive disclosure wins: \n\n t o k e n s s a v e d = 4986 × s c h e m a s i z e − ( s e a r c h + m a n u a l ) \n\n What's next for skillswebmcp \n\n Daily auto-refresh for more repos, better domain ranking, and one-click deploy so anyone can host their own copy in a minute. \n\n \n\n \n Built With \n\n esbuild express.js javascript json-rpc model-context-protocol node.js react render rest-api tailwind-css typescript vercel vite webmcp \n \n\n \n Try it out \n\n \n \n \n swmcp.vercel.app \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Abinash Balaraman \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Abinash Balaraman \n started this project\n \n —\n \n 2 days ago \n \n \n\n
