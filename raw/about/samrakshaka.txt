Before this I had heard MCP, but WebMCP was the first time I heard this word. Previously I had built my website using AI, and when I checked this competition, I thought I could make my application aligned with WebMCP standard and in the process would learn something new. \n\n What it does \n\n Samrakshaka is my personal portfolio website. Earlier it was for humans to check out my work experience along with my substack post listed here. Further I now aligned it with WebMCP protocol to allow agents to interact with tools I have added. In demo video i recorded, it's don't have my voice as requested in submission guidelines but i have shown navigation to my website, and then to my GitHub repository which has commands of to get tools listed from chrome devtools and further execution of some tools utilizing WebMCP protocol \n\n How we built it \n\n Well I told Gemini what I want, and what agents want under this new WebMCP protocol.
