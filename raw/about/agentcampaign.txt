As a marketer and full-stack developer, I saw an opportunity to bridge the gap between human strategy and AI execution. AgentCampaign is inspired by the need to transform passive dashboards into active API landscapes using the new WebMCP standard. \n\n Why your use case is a strong fit for WebMCP \n\n AgentCampaign perfectly aligns with WebMCP because it moves AI from being a passive advisor (generating text) to an active software operator. By exposing core marketing functions (like audience analysis, budget allocation, and ad copywriting) as WebMCP tools, we allow AI agents to directly orchestrate backend logic and manipulate application state. \n\n How it creates a better user experience \n\n Instead of manually clicking through tabs to set up a campaign, marketers can now use natural language in ChatGPT. The UX shifts from "navigating software" to "collaborating with a co-pilot." The marketer simply prompts the agent, and the dashboard instantly populates with a fully configured campaign, saving hours of manual data entry while maintaining a clean, visual interface for final human review. \n\n What people and agents can do together that was difficult or impossible before \n\n Before, an AI could draft ad copy, but a human still had to manually copy-paste it, format it, set the budget, and configure the targeting in a complex dashboard. With AgentCampaign, humans and agents collaborate concurrently. The agent handles the heavy lifting—processing demographic data and distributing funds across platforms based on expected ROI—while the human acts as the strategic director, reviewing the AI's transparent actions (visible in our Activity log) and adjusting sliders or copy before final launch. \n\n How we implemented WebMCP \n\n We built a React frontend and a Node.js backend. We implemented the WebMCP standard by exposing a secure context model. We registered 7 custom tools using document.modelContext.registerTool({...}) . These tools include: \n\n \n generate_campaign_brief \n set_target_audience \n allocate_budget \n generate_ad_copy \n \n\n The ChatGPT in-app browser reads these tools, allowing the agent to parse the input schema, execute the functions asynchronously, and update our database, which instantly reflects on the React dashboard. \n\n \n\n \n Built With \n\n css3 framer-motion javascript react recharts vercel vite webmcp \n \n\n \n Try it out \n\n \n \n \n hachathon-1.vercel.app \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Mohamed el mahfoudi \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n 1 \n \n \n\n\n \n 1 person likes this:\n \n\n \n \n \n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Mohamed el mahfoudi \n started this project\n \n —\n \n a day ago \n \n \n\n
