Many steps are repetitive, but exceptions still require professional judgment. \n\n FV® Tax Engine was created from real accounting, fiscal, and Odoo implementation workflows to reduce repetitive work while preserving evidence, traceability, and human control. \n\n Why WebMCP \n\n The existing FV® Tax Engine foundation analyzes structured fiscal information and prepares accounting findings. The WebMCP Challenge edition is focused on adding a browser-native collaboration layer so an AI agent can discover explicit fiscal tools exposed by the web application instead of guessing how to operate the UI. \n\n This is a strong fit for WebMCP because fiscal workflows require precise, auditable actions with narrow schemas and clear boundaries. The agent should be able to invoke defined functions such as reviewing CFDI records, filtering exceptions, explaining detected risks, and preparing a proposed accounting action while the professional remains in control of sensitive decisions. \n\n What people and agents can do together \n\n The intended WebMCP workflow is: \n\n \n The accountant opens the FV® Tax Engine web interface. \n The page exposes structured WebMCP tools through document.modelContext.registerTool() . \n The agent discovers only the actions the application explicitly makes available. \n The agent can analyze or filter fiscal records and return structured findings. \n Sensitive or accounting-impacting actions remain subject to human review and approval. \n The application preserves traceability from fiscal source data to finding, proposed action, and human decision. \n \n\n This avoids brittle UI automation and gives the agent a precise contract for interacting with the fiscal application. \n\n Existing foundation vs. WebMCP Challenge work \n\n FV® Tax Engine existed before the WebMCP Challenge. The pre-existing foundation includes Python-based CFDI/fiscal validation concepts, deterministic rules, evidence-oriented workflows, and Odoo integration design. \n\n For this challenge, the project is being extended with a WebMCP-enabled web experience and structured agent-callable tools. The WebMCP-specific implementation is the new competition work and is being kept distinct from the pre-existing fiscal engine so the extension is auditable. \n\n Architecture \n\n The design separates deterministic fiscal controls from agent orchestration: \n\n \n deterministic rules determine what happened in the fiscal data; \n WebMCP exposes explicit application capabilities to the agent; \n the agent coordinates analysis and explanation; \n the accountant approves sensitive actions; \n Odoo remains the target ERP workflow layer. \n \n\n This separation is intended to reduce hallucination risk and keep professional accountability with the human user. \n\n Implementation target for the challenge \n\n The WebMCP layer uses the emerging browser API under document.modelContext with explicit tool names, descriptions, JSON input schemas, and execution callbacks. The challenge build is designed around read/analyze-first tools and human approval gates for any action that could affect accounting records. \n\n Impact \n\n The project targets a concrete operational problem: fiscal review is time-consuming, repetitive, and difficult to automate safely. A browser-native agent interface can let professionals delegate structured review tasks without giving an AI unrestricted control of the ERP or relying on fragile screen automation. \n\n Current submission status \n\n This Devpost entry is the WebMCP Challenge edition of FV® Tax Engine. The underlying fiscal engine and repository are existing work; the WebMCP web layer, challenge demo, and challenge-specific testing flow are the new submission-period deliverables. \n\n \n\n \n Built With \n\n cfdi html javascript odoo openai python webmcp \n \n\n \n Try it out \n\n \n \n \n GitHub Repo \n \n \n \n raw.githack.com \n \n \n \n\n \n\n \n\n \n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n José Francisco Villaseñor Zúñiga \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n José Francisco Villaseñor Zúñiga — Financial & Tax Process Innovator | Odoo Implementation Expert | Creator of FV® & IA \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n\n\n\n\n\n\n\n\n \n \n\n \n\n \n \n \n \n \n Devpost \n \n About \n Careers \n Contact \n Help \n \n \n \n\n \n \n
