We wanted something that just works — install via pip, run a command, and have a fully capable AI agent with access to 100+ tools, 2000+ MCP servers, and 60,000+ skills. Named after the Cigua Palmera (our national bird 🇩🇴), Dulus represents freedom, adaptability, and reaching higher. \n\n What it does \n\n Dulus is a Python-native AI harness that transforms any LLM into a super-powered agent: \n\n \n Auto-Adapter : Drop any Python repo into Dulus and it becomes a native tool automatically \n 104+ built-in tools : Bash, file I/O, web search, browser automation, git, tmux, image OCR, and more \n 2000+ MCP servers : Via the Auto-Adapter — any MCP-compatible server plugs in instantly \n 60,000+ skills : From Anthropic marketplace, awesome-skills catalog, and Composio (1000+ apps) \n Multi-agent swarms : Spawn sub-agents in isolated git worktrees for parallel coding tasks \n Desktop GUI : Cross-platform app with embedded terminal, file manager, browser, and chat \n OpenAI-compatible endpoint : Self-host with 12 frontier models, your own API keys, your rules \n Fleet Platform : Control Room to orchestrate agent swarms across machines \n $Dulus token : First utility coin usable as AI compute/quota (launching soon) \n \n\n How we built it \n\n Pure Python , zero dependencies for core. The architecture is modular: \n\n \n Plugin system : Auto-discovers tools from any Python package via entry points \n Skill system : Reusable prompt templates with argument substitution \n MCP bridge : Native integration with the Model Context Protocol standard \n WebMCP support : Apps can expose tools that agents use directly on the page \n Nuitka builds : Compiled binaries for Windows/macOS/Linux with auto-updater \n Fleet server : FastAPI backend with SQLite, deployable anywhere \n \n\n Built in the Dominican Republic 🇩🇴 by a single developer with an army of AI allies. \n\n Challenges we ran into \n\n \n Binary size vs. features : Nuitka compiles are heavy — we split into core + plugin ecosystem \n Cross-platform paths : Windows POSIX shell quirks, OneDrive redirections, path escaping \n Real-time sync : Making the desktop GUI feel native while running Python in background \n API costs : Built local-first with $0 API fallbacks (OCR, search, etc.) \n Trust : Gained by shipping for 3+ months, 90K+ PyPI downloads, real customer 911s \n \n\n Accomplishments that we're proud of \n\n \n 90,000+ PyPI downloads and counting \n 19,000+ MCP tools
