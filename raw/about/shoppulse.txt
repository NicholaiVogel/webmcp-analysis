When autonomous AI agents try to interact with web stores, they're forced to rely on fragile screen-scraping and brittle DOM selectors that break whenever a CSS class changes. \n\n With the emerging W3C Web Model Context Protocol (WebMCP), websites can expose structured, type-safe tools directly to agents inside the browser. We built ShopPulse to show what a real, production-grade agent-native commerce platform looks like. \n\n What it does \n\n ShopPulse unites consumers, merchant operators, and autonomous browser agents in a single, responsive web application: \n\n \n For Shoppers : An AI Co-Pilot uses document.modelContext.configure_bundle to dynamically curate multi-item bundles with instant volume discounts based on natural language requests. \n For Merchants : A command center with automated purchase order dispatching and econometric price elasticity simulation. \n Enterprise Safety : A 3-tier permission model requiring explicit human approval on high-risk operations (bulk restocking, financial checkouts). \n Dual WebMCP Implementation : Supports both imperative JavaScript tool registration ( registerTool ) and declarative HTML attributes ( toolname , tooldescription ). \n \n\n How we built it \n\n \n Framework : Next.js 14 App Router with React and TypeScript. \n Agent Layer : W3C WebMCP draft specification with structured JSON Schema tools. \n Visuals : Three.js interactive 3D particle and mesh acceleration. \n Styling : Tailwind CSS with custom glassmorphism and executive typography. \n \n\n Challenges we ran into \n\n \n Designing a non-blocking Human-in-the-Loop workflow that safely pauses async tool execution while preserving the browser session. \n Seamlessly blending agent actions with live UI state updates without reloads. \n \n\n What's next for ShopPulse \n\n \n Direct integration with Chrome's built-in on-device Gemini Nano via window.ai . \n WebMCP-native multi-store checkout federation. \n \n\n \n\n \n Built With \n\n next.js node.js react tailwind-css three.js typescript webmcp \n \n\n \n Try it out \n\n \n \n \n shoppulsewebmcp.netlify.app \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n Full-stack design and development.
