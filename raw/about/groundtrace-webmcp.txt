Warranted operational memory for browser agents: WebMCP lets agents retrieve precedent, while GroundTrace decides whether it is safe to rely on. Like Comment Story Updates Inspiration Browser agents can retrieve more and more information, but retrieval is not the same thing as authority. A remembered action may be stale, unsuccessful, unverified, or simply inappropriate to reuse. GroundTrace WebMCP gives browser agents access to operational memory while preserving that distinction: memory is a candidate, not authority. What it does GroundTrace exposes three native WebMCP tools directly from the web application: groundtrace_remember records a resolved incident with its action, outcome, verification state, timestamp, and provenance. groundtrace_recall retrieves relevant precedent and applies a deterministic warrant gate. groundtrace_explain exposes why GroundTrace admitted, held, or rejected the retrieved memory. Candidate memories receive a RELY , HOLD , or REJECT admission. Only RELY memories may supply an action as a recommendation. The key demonstration is deliberately a refusal. ChatGPT retrieves an exact-match incident with similarity 1, but because the stored memory is unverified, GroundTrace returns HOLD , reason memory_unverified , and recommendation: null . The agent successfully remembers.
