We wanted to make this experience more natural by allowing users to simply talk to the website. \n\n What it does \n\n Voice Enable Pizza App is a voice-first pizza ordering experience powered by OpenAI and WebMCP . \n\n Users can talk naturally to the AI to browse pizzas, customize their order, add or modify items in the cart, and review their order. \n\n Instead of the AI just telling the user what to do, it can actually interact with the web application through WebMCP tools and perform the requested actions. \n\n How we built it \n\n We built the application using React for the frontend and integrated an OpenAI-powered voice agent using an OpenAI API key. \n\n We exposed the key pizza ordering capabilities through WebMCP tools , allowing the AI agent to understand natural-language requests and interact with the web application. \n\n This connects voice conversations directly to real actions such as browsing pizzas, customizing items, and managing the cart. \n\n Challenges we ran into \n\n The biggest challenges were making voice interactions feel natural, handling ambiguous or incomplete requests, designing reliable WebMCP tools, and keeping the AI's understanding synchronized with the actual application state. \n\n We also had to carefully design the interaction between the voice agent, WebMCP tools, and the React application so that actions performed by the AI were correctly reflected in the UI. \n\n Accomplishments that we're proud of \n\n We're proud that we built more than just a voice chatbot. The AI can actually interact with a website and perform actions using WebMCP . \n\n We successfully connected natural voice commands with a real pizza ordering flow, creating an experience where users can simply describe what they want instead of manually navigating every step. \n\n What we learned \n\n We learned that building an AI agent that can take real actions requires much more than generating good responses. Tool design, state management, context, and handling ambiguous user requests are equally important. \n\n We also learned how WebMCP can provide a powerful bridge between AI agents and web applications , enabling agents to interact with websites in a structured way. \n\n What's next for Voice Enable Pizza App \n\n We want to make the voice experience more conversational and robust, improve personalization and order recommendations, and expand the range of actions the agent can perform. \n\n Beyond pizza, we believe the same approach could be applied to e-commerce, restaurant ordering, travel, bookings, and many other web applications — creating a future where users can tell websites what they want instead of learning how to navigate them . \n\n \n\n \n Built With \n\n chatgpt css3 html5 openai react \n \n\n \n Try it out \n\n \n \n \n GitHub Repo \n \n \n \n voice-enable-pizza-app.vercel.app \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n Played a key role in shaping and building the hackathon idea end-to-end, from defining a voice-first product experience that moves beyond traditional menu- and list-based interactions, to designing the complete pizza-ordering journey from discovery to cart. \n\n A key part of my contribution was designing the product UX for a voice first application, using WebMCP to bridge the voice agent and the web application.
