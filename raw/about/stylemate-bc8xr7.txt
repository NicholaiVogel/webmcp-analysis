After using AI so much, it probably knows more about my style than my girlfriend does. \n\n Sad, but true. 😄 \n\n That made me think: \n\n If AI already understands me, why am I still doing all the searching myself? \n\n That's how StyleMate started. \n\n We wanted to build a shopping experience where you don't have to think like a search engine. You can simply tell the agent what you're looking for, and it can understand your preferences, find the right products, and help you build your outfit. \n\n What it does \n\n StyleMate is an AI-powered personal stylist built for fashion shopping. \n\n Instead of searching through hundreds of products and manually applying filters, you can simply give StyleMate a natural-language request. \n\n For example: \n\n \n "I'm 5'7", I need a formal outfit for office — a shirt, trousers and shoes. My shirt size is 40, trouser waist is 32, shoe size is 9, and my budget is around ₹10,000." \n \n\n StyleMate can understand the request along with the user's existing style profile. \n\n It can then: \n\n \n Understand the user's style preferences \n Find personalized recommendations \n Search the product catalog \n Compare products \n Check size and inventory availability \n Build a complete outfit \n Add selected products to the cart \n \n\n The interesting part is that the AI doesn't just recommend products. \n\n It can actually interact with the website through WebMCP. \n\n How we built it \n\n Our main idea was: \n\n One brain, two front doors. \n\n A user can interact with StyleMate through the normal website UI, while an AI agent can interact with the same application through WebMCP. \n\n Both use the same underlying product and business logic. \n\n For the agent experience, we exposed purpose-built WebMCP tools: \n\n \n getUserStyleProfile — read the user's style preferences \n getRecommendations — find suitable products \n searchProducts — search the product catalog \n compareProducts — compare product options \n checkInventory — verify availability \n addToCart — add selected products to the cart \n \n\n We also use browser page controls to update the visible website, show products, display confirmation dialogs, navigate to the cart, and keep the user involved in the process. \n\n The flow is simple: \n\n User intent → AI reasoning → WebMCP tools → Website interaction → Human confirmation → Cart \n\n We built the application using modern web technologies including Next.js, React, TypeScript, and WebMCP. \n\n Challenges we ran into \n\n The biggest challenge was not simply connecting an AI agent to a website. \n\n We wanted the agent to interact with the actual application in a reliable and structured way. \n\n We had to think carefully about: \n\n \n Designing useful WebMCP tools instead of exposing generic actions \n Keeping the agent and human UI connected to the same business logic \n Making product search and recommendations work with natural-language requests \n Handling size and inventory checks \n Keeping important actions under human control \n Making the website visually respond to agent actions \n \n\n We also had to think about the difference between what an agent can do and what an agent should be allowed to do . \n\n For example, searching and comparing products are safe actions, while adding something to a cart or placing an order requires more user involvement. \n\n Accomplishments that we're proud of \n\n The biggest accomplishment is that StyleMate is not just an AI chatbot placed on top of an ecommerce website. \n\n The website itself is agent-operable. \n\n An agent can discover StyleMate's capabilities through WebMCP and use those capabilities to perform real shopping tasks. \n\n We can start with a simple sentence like: \n\n \n "Find me a formal office outfit under ₹10,000." \n \n\n And turn that into a complete interaction: \n\n Understand my style → Search products → Compare options → Check availability → Show me the choices → Get confirmation → Add to cart \n\n We are also proud of keeping the architecture simple. \n\n One brain, two front doors. \n\n The human experience and the agent experience are powered by the same underlying application logic. \n\n What we learned \n\n We started this project thinking about AI recommendations. \n\n We ended up thinking much more about agent-friendly websites . \n\n Traditional ecommerce is built around the question: \n\n "What product are you searching for?" \n\n But people usually think in terms of intent: \n\n "I have an office event tomorrow. What should I wear?" \n\n That's where we see the potential of WebMCP. \n\n Instead of an AI simply telling you what to click, the website can expose structured capabilities that an agent can actually use. \n\n We also learned that giving an agent more control doesn't mean removing the human. \n\n The best experience is: \n\n AI does the searching and decision support.\nHuman makes the important decisions. \n\n What's next for StyleMate \n\n Today, StyleMate focuses on fashion discovery and shopping. \n\n But the idea can go much further. \n\n We want StyleMate to understand how a person's style changes over time and become a long-term personal stylist rather than a one-time shopping assistant. \n\n Future possibilities include: \n\n \n Smarter personal style profiles \n Outfit planning for specific events \n Wardrobe-aware recommendations \n More brands and product categories \n Better fit and size intelligence \n Wishlist and purchase-history intelligence \n Personalized seasonal collections \n Agent-driven shopping across multiple stores \n \n\n The bigger vision is simple: \n\n Don't search. Be understood. \n\n \n\n \n Built With \n\n css next.js query react tailwind tanstack typescript vercel vitest webmcp \n \n\n \n Try it out \n\n \n \n \n stylemate-gilt.vercel.app \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Sandeep Ahuja \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Sandeep Ahuja \n started this project\n \n —\n \n 2 days ago \n \n \n\n
