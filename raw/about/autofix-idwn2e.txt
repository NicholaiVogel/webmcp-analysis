We asked: Why do biological systems heal wounds in real time, while web apps shatter at the first error? With the new W3C WebMCP standard, we realized we could embed an AI immune system directly inside browser memory to detect, diagnose, and repair broken code instantly.\n⚙️ What It Does\nAutoFix.run is a self-healing frontend engine that fixes crashes in under 2 seconds with zero page reload:\nWebMCP Flight Recorder: Buffers user clicks, DOM mutations, and component stacks.\nGemini Root-Cause Diagnosis: Dispatches crash dumps via WebMCP to synthesize surgical AST patches.\nAST Safety Auditor: Blocks prototype pollution, arbitrary network calls, and unsafe evaluations before execution.\nZero-Downtime Hotpatching: Injects the verified fix straight into browser memory, preserving active user state and unfreezing the UI.\nGit PR Automation: Generates clean Git diffs and ready-to-merge GitHub pull requests.\n🧗 Challenges We Faced\nHotpatching Without State Loss: Swapping code in a running React bundle without refreshing the page or losing user inputs required careful in-memory prototype interception.\nPreventing Hallucinations: Constraining Gemini via strict JSON schemas and AST invariant assertions so it only produces surgical, runnable code fixes.\nHigh-Demand API Reliability: Built an adaptive circuit breaker that seamlessly cascades across Gemini flash models if an endpoint hits temporary 503 limits.\n🏆 Accomplishments\nAchieved sub-1.8s Mean Time to Repair (MTTR) from crash to live heal.\nDemonstrated zero state loss across an authentic 2.7k★ React Calculator and an enterprise e-commerce checkout funnel.\nNative browser-level WebMCP implementation (window.navigator.modelContext) instead of an external chat wrapper.\n📚 What We Learned\nWebMCP transforms the browser from a passive display into an active, intelligent host.\nNeuro-symbolic design wins: Combining LLM reasoning with deterministic AST security checks is essential for running generated code safely in production.\nProduction web software no longer needs to be fragile—it can have its own immune system. \n\n \n\n \n Built With \n\n gemini \n \n\n \n Try it out \n\n \n \n \n whimsical-platypus-0c4419.netlify.app \n \n \n \n GitHub Repo \n \n \n \n\n
