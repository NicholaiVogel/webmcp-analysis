To me, a genome was just a massive text file. I wanted to build an experimental\n tool to bridge the gap between finding a 1D genomic mutation in a VCF file and visualizing its 3D structural impact, without needing a PhD to operate\n it. \n\n I built OmniStrand—a React and TypeScript web app that parses patient VCF files 100% locally in the browser for absolute privacy. To make it\n accessible, I integrated a custom WebMCP (Model Context Protocol) architecture. This allows an autonomous LLM agent to literally pilot the user\n interface—automatically typing in coordinates, navigating the genome browser, and pulling up the 3D AlphaFold structures via PDBe-Molstar. \n\n ## The Submission: A Perfect Score \n\n I used this experimental tool as my actual pipeline for the hackathon's clinical benchmark. I loaded the patient VCF into OmniStrand, and the WebMCP\n agent took over the UI. It successfully navigated the genome, identified the compound heterozygous mutation responsible for Mosaic Variegated\n Aneuploidy (MVA), resolved the UniProt ID, and highlighted the mutated residue on the 3D protein model. \n\n The AI then generated my clinical CSV payload directly from the UI. Despite my lack of prior genetics experience, I submitted that exact payload for\n Track 1, and it was accepted with a perfect score. \n\n ## Future Improvements \n\n While OmniStrand successfully automated a clinical workflow, this is just the foundation. My next steps for the project include: \n\n • Multi-Agent Orchestration: Expanding the WebMCP toolset so multiple AI agents can collaborate in the UI (e.g., one agent parses the genome while\n another simultaneously queries pharmacological databases for drug interactions).\n • In-Browser Molecular Docking: Upgrading the 3D Discovery Engine to support basic ligand-docking simulations, allowing researchers to test drug\n repurposing directly in the browser.\n • Wasm-Powered Genomics: Replacing the JavaScript VCF parser with a WebAssembly (Wasm) implementation to handle massive whole-genome sequencing (WGS)\n files with zero lag. \n\n \n\n \n Built With \n\n pdbe-molstar react tailwind typescript vite webmcp \n \n\n \n Try it out \n\n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n simulated buggy \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n simulated buggy \n started this project\n \n —\n \n 2 days ago \n \n \n\n
