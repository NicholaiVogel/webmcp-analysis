It feels less like querying a chatbot and more like handing the wheel to a co-pilot who can already see the screen. \n\n Why WebMCP \n\n WebMCP lets the page expose structured tools and its current state directly to an agent. Instead of asking an agent to describe what a user should click, the agent can operate the Kitespot Atlas experience itself: work with the map, re-score spots for the rider's setup, and create useful actions such as notes and weather watches. \n\n What's next \n\n More sports and gear profiles beyond kiting, richer multi-day trip planning across spot clusters, and pushing on what else a page can safely hand an agent once it's willing to expose its own state instead of hiding behind an API. \n\n \n\n \n Built With \n\n cloudflare-workers leaflet.js localstorage open-meteo vanilla-javascript webmcp wrangler \n \n\n \n Try it out \n\n \n \n \n jurgenw81.github.io \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Coding Joe \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Coding Joe \n started this project\n \n —\n \n 2 days ago \n \n \n\n
