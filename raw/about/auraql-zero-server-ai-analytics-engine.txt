When analysts consult AI, language models frequently hallucinate arithmetic calculations on large datasets. \n\n We built AuraQL to completely invert this paradigm: \n\n \n Zero-Server In-Browser OLAP : The columnar database and vectorized SQL evaluator run 100% inside your client-side browser tab memory. \n Deterministic AI Math : The AI agent writes the SQL query, but the in-browser engine evaluates aggregations (SUM, AVG, COUNT, STDDEV) in under 10 milliseconds with mathematical accuracy. \n WebMCP Dual-Control Canvas : Both the human user and AI agent collaborate simultaneously on the same dashboard canvas via the emerging open standard document.modelContext . \n \n\n \n\n ⚡ Why Our Use Case is a Strong Fit for WebMCP \n\n Analytics dashboards are notoriously difficult for computer-vision and click-based agents: DOM selectors break, dynamic canvas elements cannot be inspected, and SVG splines are opaque to LLMs. \n\n WebMCP provides the ideal interface: \n\n \n Instead of brittle DOM scraping, AuraQL exposes structured analytical primitives directly to the agent. \n The agent calls list_tables_and_schema to discover table schemas and column datatypes. \n It evaluates relational SQL via execute_sql_query . \n It commands the user's viewport directly via render_interactive_chart and apply_dashboard_filter . \n \n\n \n\n 🚀 How It Creates a Better User Experience \n\n \n 100% Client-Side Privacy : Financial data and customer churn metrics never leave the user's browser RAM. Zero cloud data storage costs, zero telemetry tracking, and zero database credentials to expose. \n Sub-10ms Latency : Queries against columnar memory buffers execute faster than a network roundtrip to a cloud data warehouse. \n Co-Pilot Simultaneous Vision : When you ask the agent a question like "Show quarterly revenue breakdown by region as a bar chart" , the dashboard mutates in real time before your eyes while the agent explains the business takeaways. \n Pro Studio Interface : Dual-axis resizable grid windows, high-contrast borders (black in light mode, neon purple in dark mode), and drag-and-drop CSV/JSON ingestion. \n \n\n \n\n 🤝 What People and Agents Can Do Together That Was Impossible Before \n\n \n Natural Language Scenario Simulation : Humans specify hypothetical business conditions ( "What if critical churn accounts decrease 25% and MRR increases 15%?" ). The agent calls simulate_forecast_scenario to execute in-memory adjustments and render baseline vs. projected variance charts immediately. \n Instant Statistical Anomaly Isolation : The agent uses detect_anomalies to calculate Z-scores ($|Z| \\ge 1.85$) and Interquartile Ranges (IQR) directly in browser memory, isolating revenue spikes or margin compression without needing Python or external Jupyter notebooks. \n True Cross-Platform Agent Access : The exact same WebMCP tools are available inside:\n\n \n ChatGPT’s native in-app browser ( document.modelContext ) \n Desktop ChatGPT & Claude Desktop via Server-Sent Events ( /sse ) \n OpenAI Codex CLI over Stdio JSON-RPC 2.0 \n \n \n\n \n\n 🛠️ How We Implemented WebMCP \n\n AuraQL implements the official W3C WebMCP specification: \n\n \n Native Browser Standard : Inspects document.modelContext on mount and registers 6 analytical tools: \n\n \n list_tables_and_schema (Schema & metadata discovery) \n execute_sql_query (Columnar SQL aggregations) \n render_interactive_chart (Viewport visualization mutation) \n apply_dashboard_filter (Cohort isolation) \n simulate_forecast_scenario (What-if financial modeling) \n detect_anomalies (Statistical anomaly detection) \n \n Universal Polyfill & Bridge : \n\n \n If running in standard Chrome or without native browser flags, AuraQL binds a spec-compliant fallback to document.modelContext and window.modelContext . \n An external Node.js WebMCP bridge deployed on Render ( scripts/mcp-bridge.mjs ) synchronizes with the active browser tab via Server-Sent Events ( /api/bridge/events ) with 25-second keepalive heartbeats, allowing desktop clients (Codex CLI, Claude Desktop, ChatGPT Desktop) to steer the live web app remotely. \n \n \n\n \n\n 💻 Built With \n\n \n
