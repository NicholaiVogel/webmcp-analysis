Request Inbox can be useful, but properly configuring dynamic responses with templates can be painful. I saw that WebMCP could solve that gap — specific knowledge that no one wants to spend time learning. \n\n What it does \n\n Allows using the tool without having to configure the callbacks or responses yourself. I also added a few UI improvements like retrying callbacks and copying requests as cURL. \n\n How we built it \n\n I used my Request Inbox as the base project. I used VSC as my IDE and Opencode configured with an OpenAI subscription.
