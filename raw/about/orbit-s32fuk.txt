Orbit is built with plain JavaScript ES modules, with no framework or build step.\nA single shared scene store powers the viewport, inspector, AI planner, Webmcp tools, and persistence. This keeps the human and AI working on exactly the same scene state.\nThe natural-language router is a pure, deterministic function that converts user requests into tool calls. This makes the agent predictable and easy to test. Our current router evaluation is 38/38 passing. \n\n Challenges we ran into \n\n There were many challenges in the orbit like the early stl exports could appear correct but fail in slicers because some geometry had zero thickness. We fixed this by deriving the export from the actual scene geometry.One challenge was balancing live AI updates with reliable undo. We solved this by grouping an entire AI run into a single undoable operation. \n\n Accomplishments that we're proud of \n\n Iam proud of many things that I have done that Orbit turned AI-controlled 3D
