Users can type requests like "Create a WiFi QR for network 'HomeNet' with password 'pass123'", and the system automatically parses the intent, formats the structured payload, and renders high-resolution customizable vector outputs. \n Why WebMCP is Essential for this Use Case:\nTraditional QR generators rely heavily on manual form filling, which creates friction when AI agents (like ChatGPT or WebMCP-enabled browsers) try to assist users. By implementing WebMCP, our platform exposes native tool definitions directly to the DOM (window. WEBMCP_TOOLS ). This allows AI agents to dynamically generate, customize, and extract QR payload data directly on behalf of the user without needing complex API wrappers or headless browser scraping. \n Key Features & Architecture:\nNatural Language Parsing: Powered by Google Gemini 1.5 Flash API to convert unstructured text inputs into valid vCards, WiFi configurations, WhatsApp links, and URLs.\nWebMCP Native Integration: Includes webmcp.json discovery manifest and client-side tool bindings for generate_qr functions.\nInstant Client-Side Rendering: Real-time canvas preview supporting custom branding, logos, error-correction levels, and SVG/PNG/PDF exports.\nZero Overhead Stack: Built with React, TypeScript, and Tailwind CSS; easily hostable on Vercel, Netlify, or Lovable edge servers. \n How We Built It:\nThe entire application was prototyped and assembled using Lovable for full-stack React UI generation. For intelligence, we integrated the Google Gemini API (via @google/generative-ai) with a robust Regex fallback for offline capability. WebMCP tool schemas were declared directly within the app's root layout to maintain 100% compliance with ChatGPT and Chrome WebMCP flags. \n Links & Deliverables:\nGitHub Repository: https://github.com/YOUR_USERNAME/ai-qr-studio \nLive Demo: https://YOUR_APP_SUBDOMAIN.netlify.app (or Lovable live link) \n \n\n What's next for AI QR Studio \n\n \n\n \n Built With \n\n ai \n \n\n \n Try it out \n\n \n \n \n prompt-to-qr.lovable.app \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Aloush Stores Al-Rubaie \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Aloush Stores Al-Rubaie \n started this project\n \n —\n \n 3 days ago \n \n \n\n
