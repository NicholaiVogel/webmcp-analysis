An AI agent is great at the research part searching activities, checking budgets but most agents have to guess their way through a website's buttons and forms to actually act on anything. WebMCP changes that: a site can just tell the agent exactly what it's allowed to do. We wanted to build something where that difference is immediately visible, not just theoretical \n\n What it does \n\n CoPlan is a shared trip-planning board. You can edit it by hand add activities, adjust costs, change the destination and an AI agent can edit the exact same board through real WebMCP tools (add_activity, search_activities, set_trip_details, and more). Whether a person or an agent makes a change, it lands on the same live itinerary, instantly. \n\n How we built it \n\n Next.js (App Router) with TypeScript, deployed on Vercel. The backend is a set of simple API routes backed by in-memory state. On the frontend, we register WebMCP tools via document.modelContext.registerTool(), and every tool's execute() calls the same API routes the human-facing UI uses one source of truth, no separate "agent path." \n\n Challenges we ran into \n\n Next.js (App Router) with TypeScript, deployed on Vercel. Keeping one shared backend for both human and agent actions turned out to be the most important decision we made it meant we never had to worry about the two getting out of sync. \n\n \n\n \n Built With \n\n css javascript manus nextjs node.js react typescript vercel webmcp \n \n\n \n Try it out \n\n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Vic Erioluwa Akinlabu \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Vic Erioluwa Akinlabu \n started this project\n \n —\n \n 3 days ago \n \n \n\n
