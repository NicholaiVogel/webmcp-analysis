While modern AI trip planners promise convenience, they often introduce new problems: weak budget reasoning, fabricated venue suggestions, poor route planning, and slow response times. We wanted a better approach.\nTripster combines the flexibility of AI assisted planning with the reliability of deterministic algorithms. Instead of relying on a model to guess the best trip, we use structured optimization logic to generate realistic, budget aware itineraries quickly and consistently. \n\n What it does\nTripster is a trip planning app that helps groups create better travel plans based on their constraints. It supports multi origin trip planning for group members, budget aware itinerary generation, terrain and effort preference handling, spatially balanced destination selection, venue rerolling and itinerary refinement, interactive visual planning through a map and timeline, optional submission of new trip spots into the planning system, and agent style integration through browser native tool execution. \n\n How we built it\nWe built the frontend with React and Vite, used Leaflet and React Leaflet for maps, applied custom CSS for styling, and relied on Supabase for the data layer. The planning logic is powered by a custom deterministic engine for itinerary generation, route optimization, and constraints handling. For agent integration we added a browser side WebMCP bridge for tool interoperability. This stack keeps the app fast, lightweight, and cost efficient while still supporting an interactive planning experience. \n\n Challenges we ran into\nWe had to figure out how to find a fair group midpoint across multiple starting locations, balance travel distance with budget and venue suitability, handle edge cases where no venues fit perfectly within the provided constraints, keep route generation realistic while avoiding over optimization, and synchronize UI state with planning actions without breaking the user experience. \n\n Accomplishments we are proud of\nWe built a functioning trip planning app focused on real constraints instead of generic AI suggestions. We created a structure that blends deterministic planning with interactive user experience, designed a system that is lightweight, fast, and easy to extend, and integrated map based planning and itinerary visualization in a single interface. \n\n What we learned\nThe best travel planning experiences do not come from forcing AI to solve everything with raw generation. They come from combining AI interaction with well defined optimization logic. For structured tasks like trip planning, deterministic heuristics and route aware algorithms are often more reliable than purely generative approaches. \n\n What is next for Tripster\nWe plan to add real time shared itinerary updates, better transit aware route planning, more venue verification and review workflows, offline support for saved itineraries, and improved personalization and recommendation engines. \n\n \n\n \n Built With \n\n agent frontend github javascript leaflet.js node.js npm react supabase vite webmcp \n \n\n \n Try it out \n\n \n \n \n GitHub Repo \n \n \n \n tripster-ten.vercel.app \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Binayak Sinha \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n\n \n Chetan Adaki \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Binayak Sinha \n started this project\n \n —\n \n 2 days ago \n \n \n\n
