Manual clicking through 50+ fields takes 5-10 minutes per form. We built an AI agent to do it in seconds. \n\n What it does \n\n Google Form Auto-Filler is an AI-powered agent using WebMCP that: \n\n \n Reads Google Form structure automatically \n Understands field types (text, email, select, checkbox, etc) \n Fills answers intelligently using Gemini AI \n Submits forms with one click \n Stores personal info locally (no server storage) \n \n\n How we built it \n\n \n Backend (Python Flask) - Secure API with Gemini integration, rate limiting, API key auth \n Chrome Extension - Popup UI with local memory storage, DOM inspection \n WebMCP Tools - Form analyzer, field filler, submission tracker \n Security - Per-key rate limiting, JSON schema validation, safe parsing, CORS hardened \n \n\n Tech: Python, Flask, React, Chrome Extension, Gemini API, WebMCP \n\n Challenges we ran into \n\n \n Model output validation (JSON parsing robustness) \n URL validation & SSRF prevention \n Rate limiting per API key vs IP \n Handling different form field types dynamically \n Local storage privacy concerns \n \n\n Accomplishments that we're proud of \n\n 1 . Production-grade security (9.5/10 audit score)\n2.Fully functional Chrome extension with local memory\n3.Safe model output parsing with schema validation \n\n \n Per-key rate limiting for distributed deployments \n Professional README with 20k+ character documentation\n6.Built in 48 hours with zero shortcuts \n \n\n What we learned \n\n \n WebMCP is powerful for browser automation \n Security-first development from day one pays off \n Local storage beats server storage for privacy \n Gemini AI handles unstructured form data better than structured APIs \n Extension development is
