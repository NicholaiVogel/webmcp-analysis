I was inspired by the idea of creating a universal AI lens that can turn visual information into useful, understandable guidance. Drishti was built to make technology and the world around us more accessible through AI-powered vision and narration. \n\n What it does \n\n Drishti is an AI-powered accessibility lens that analyzes visual environments and explains what it sees in a clear, useful way. It can identify objects, describe scenes, extract relevant information, and provide accessibility-focused insights.\nWith WebMCP, Drishti can also expose its accessibility capabilities as tools that AI agents can discover and use, allowing agents to request visual analysis, accessibility summaries, barrier details, recommendations, and reports. \n\n How we built it \n\n Drishti was built with React, TypeScript, Tailwind CSS, and the Google GenAI SDK. Gemini vision models power the visual analysis, while the Web Speech API provides voice narration.\nWe added WebMCP tool registration so supported AI agents can interact with Drishti's accessibility capabilities programmatically. The interface remains usable normally even when WebMCP is unavailable. \n\n Challenges we ran into \n\n One of my biggest challenges was designing AI-powered accessibility features that are genuinely useful rather than simply generating descriptions. We had to consider clarity, uncertainty, and how information should be presented to someone who may depend on the output.\nIntegrating WebMCP also required us to think about how existing application functionality could be exposed as agent-accessible tools without compromising the normal user experience. \n\n Accomplishments that we're proud of \n\n I'm proud of turning an accessibility concept into a working product that combines computer vision, narration, and agent interoperability.\nAdding WebMCP makes Drishti more than an accessibility interface. Its capabilities can become part of larger agent workflows, giving AI agents a structured way to access visual accessibility information. \n\n What we learned \n\n I learned that accessibility is not only about adding assistive features. It is about designing information around the needs of the person using it.\nWe also learned how emerging web standards such as WebMCP can make web applications more useful to AI agents by exposing meaningful capabilities as structured tools rather than relying only on traditional interfaces. \n\n What's next for Drishti \n\n I want to expand Drishti beyond individual visual analysis into a more complete accessibility assistant.\nNext, i plan to improve real-time scene understanding, add more accessibility-specific detection, support richer agent workflows through WebMCP, improve multilingual narration, and explore integrations that allow Drishti to assist users across more environments and devices. \n\n \n\n \n Built With \n\n aiagents computervision googlegemini googlegenaisdk javascript
