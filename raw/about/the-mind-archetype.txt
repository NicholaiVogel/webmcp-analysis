People may first want to understand what they are experiencing, explore possible areas of support, learn how therapy works, or simply figure out where to start. \n\n Traditional websites provide this information through pages, menus, and buttons designed for human navigation. But as AI agents increasingly become an interface for discovering and interacting with services, I saw an opportunity to make that experience more direct. \n\n As a psychologist and the founder of The Mind Archetype, I wanted to explore how WebMCP could bring agent-native interaction into a real psychology service while keeping professional care and human decision-making at the center. \n\n What it does \n\n The Mind Archetype is an agent-native psychology website that allows compatible AI agents to discover and interact with structured capabilities exposed directly by the website. \n\n The application currently provides 12 WebMCP tools covering: \n\n \n Mental health information \n Care-area discovery \n Service information \n Consultation guidance \n Resource discovery \n Organization information \n Contact options \n Consultation preparation \n Appointment booking \n \n\n For example, get_mind_archetype_profile allows an agent to discover structured information about the organization, while book_appointment provides a dedicated capability for starting the appointment process. \n\n This means an agent does not have to rely exclusively on interpreting the visual interface and guessing where to click. \n\n At the same time, the human remains in control. The system is designed to help people navigate information and access professional support, not to replace a psychologist or make clinical diagnoses. \n\n How we built it \n\n The project was built as a real, deployed web experience using: \n\n \n HTML \n CSS \n JavaScript \n WebMCP \n Netlify \n Google Calendar for appointment scheduling \n \n\n Rather than creating a separate prototype, I extended the existing The Mind Archetype website with a WebMCP layer. \n\n The WebMCP implementation exposes tools through document.modelContext , allowing compatible agents to discover the capabilities available on the page. \n\n I tested the deployed implementation directly in Chrome with WebMCP enabled and verified that all 12 tools could be discovered through: \n ( await document . modelContext . getTools ( ) ) . map ( t = > t . name ) \n \n The appointment capability is connected to a real Google Calendar scheduling experience, so the agent-assisted flow can ultimately lead to an actual human-selected appointment. \n\n Challenges we ran into \n\n The biggest challenge was working with a new and evolving web capability while keeping the existing website stable. \n\n I had to understand how WebMCP exposes tools through the browser, how those tools are discovered, and how to define capabilities that are meaningful from an agent's perspective. \n\n Another challenge was balancing the agent experience with the existing human experience. I did not want to rebuild the website around AI or remove the visual interface people already understand. \n\n Instead, I treated WebMCP as an additional interaction layer. \n\n Testing was also an important part of the process. I had to verify the implementation directly in the browser, troubleshoot differences between the WebMCP tool representation and traditional JavaScript APIs, and make sure the appointment flow connected to a real scheduling experience. \n\n Accomplishments that we're proud of \n\n The biggest accomplishment is that this is not just a concept or mockup. The Mind Archetype is a live psychology website with a working WebMCP implementation. \n\n I am particularly proud of: \n\n \n Successfully exposing 12 distinct WebMCP tools. \n Integrating WebMCP into an existing production-style website without replacing its human interface. \n Connecting the appointment capability to a real Google Calendar scheduling flow. \n Creating tools around meaningful psychological-service tasks rather than adding AI functionality for its own sake. \n Keeping human control at the center of the experience. \n Making the complete project publicly available with its source code and documentation. \n \n\n For me, the most important achievement is demonstrating that WebMCP can be applied to a real-world professional service where trust, clarity, and human oversight matter. \n\n What we learned \n\n This project changed how I think about websites. \n\n Previously, I primarily thought of a website as an interface between a person and a service. Building with WebMCP made me think of it as an interface between people, services, and agents . \n\n I learned that making a website agent-friendly is not simply about adding AI. It is about identifying meaningful actions and exposing them as clear, structured capabilities. \n\n I also learned that giving an agent more capabilities does not necessarily mean giving it more control. \n\n In a sensitive field like psychology, the better approach can be to let an agent help someone understand options, find information, prepare an action, or begin a process, while leaving important decisions to the human. \n\n What's next for The Mind Archetype \n\n The current implementation is a foundation for a larger agent-native psychology platform. \n\n Next, I want to expand the capabilities around psychological education, resource discovery, consultation preparation, corporate mental health services, and access to professional support. \n\n I also want to explore richer agent-assisted experiences where a person can describe what they need conversationally and the agent can help them navigate the appropriate information and services exposed by The Mind Archetype. \n\n The long-term vision is not to automate the psychologist. \n\n It is to make the path from a person's first question to appropriate human support simpler, more accessible, and more intelligent. \n\n The Mind Archetype is an exploration of what psychology on an agent-native web could look like. \n\n \n\n \n Built With \n\n agentic agents ai artificial conversational css development google health healthcare html human-ai intelligence interaction javascript mental netlify psychology web webmcp \n \n\n \n Try it out \n\n \n \n \n themindarchetype.netlify.app \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n I developed The Mind Archetype as a solo project, including the concept, UX/UI, website design, content, HTML/CSS/JavaScript implementation, and WebMCP integration.
