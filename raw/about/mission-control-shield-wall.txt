The challenge was to make agent access useful without turning a real operations system into an open door. \n\n What we built \n\n Mission Control: Shield Wall is a public-safe, fictional dashboard where a person and WebMCP agents can observe a synthetic fleet, create an ephemeral task, run six local security checks, preview a simulated scheduled report, prove tool behavior with a five-scenario harness, and walk through a reversible incident drill. \n\n Why WebMCP matters \n\n A person can see the same state an agent is using, while the agent receives explicit schemas instead of guessing through buttons. The tools are bounded to fictional memory: one read, one validated task write, one local scan, and one reversible incident action. Invalid inputs and external-workflow attempts are rejected by the evaluation harness. \n\n Privacy and implementation \n\n The demo has no backend, database, analytics, credentials, cookies, external calls, or production integrations. It uses Next.js, React, TypeScript, Zod, and the experimental document.modelContext.registerTool pattern. Every visible organization, operator, task, check, and incident is fictional. \n\n What we learned \n\n Designing the human and agent surfaces together made least privilege visible as a product feature. Shield Wall and the repeatable harness turn safety claims into something a judge can inspect and run. \n\n \n\n \n Built With \n\n next.js playwright react typescript vercel webmcp \n \n\n \n Try it out \n\n \n \n \n mission-control-webmcp-safe-preview.vercel.app \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Ramon N \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n 1 \n \n \n\n\n \n 1 person likes this:\n \n\n \n \n \n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Ramon N \n started this project\n \n —\n \n 9 days ago \n \n \n\n
