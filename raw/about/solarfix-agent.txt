Helping technicians diagnose issues \n \n 1 2 \n\n\n\n \n Inspiration \n\n Solar technicians often spend valuable time diagnosing faults, checking spare-part availability, creating service tickets, and managing inventory. My experience in solar technical operations, logistics, and inventory management inspired me to build SolarFix Agent —an AI-powered assistant that connects these activities in one simple workflow. \n\n What It Does \n\n SolarFix Agent helps technicians: \n\n \n Diagnose common solar system problems. \n Check spare-part availability in real time. \n Create and manage service tickets. \n Track parts used during repairs. \n Identify low-stock items and create restocking lists. \n \n\n The key idea is that an AI agent should not only provide advice—it should be able to interact with the application and perform useful actions through WebMCP . \n\n How I Built It \n\n I built the project as a lightweight web application with an inventory and service-management interface. I integrated WebMCP tools that allow an AI agent to search inventory, check stock, create service tickets, update stock, and generate restocking lists. \n\n The application uses sample solar equipment and spare-part data to demonstrate the complete technician workflow. \n\n What I Learned \n\n This project helped me understand how WebMCP can make AI agents more useful by allowing them to interact directly with web applications. I also learned how to design tools with clear actions and inputs so that an AI agent can safely work with real application data. \n\n Challenges \n\n The main challenge was keeping the project simple while demonstrating meaningful agent interaction. I focused on a practical solar-maintenance workflow rather than building unnecessary features. \n\n Future Improvements \n\n I would like to add customer management, technician GPS/location support, predictive maintenance, supplier management, mobile support, and AI-powered solar fault diagnosis using real service data. \n\n \n\n \n Built With \n\n ai-agents css html inventory-management javascript logistics openai renewable-energy rest-api solar-energy technical-operations web-development webmcp \n \n\n \n Try it out \n\n \n \n \n GitHub Repo \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Samsonkulwa Kulwa \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Samsonkulwa Kulwa \n started this project\n \n —\n \n 2 days ago \n \n \n\n
