Corealm is a browser based medieval RPG built for an AI agent to sit beside you using WebMCP, whether that means guiding you with suggestions and overlays or playing the game itself. Like Comment Story Updates Corealm Inspiration This game is inspired by Runescape, Runelite, and Knight Online. There both games fight against bots while offering pay to win mechanics. Corealm takes a different stance and builds "botting" as part of the game. You can also choose to only use the agent as a guide in a similar way Runelite works, which uses overlays. What it does Its a browser based RPG where your ai agent can play alongside you. The agent can help you plan what's next, show you the steps for a quest, or grind away at tasks you might just not have the time for. How we built it Vite + TypeScript + Three.js, with Rapier for physics and Recast for navmeshes. The agent API is a thin WebMCP tool layer using the same functions the UI calls. The docs are generated from the same data the game runs on and is exposed two ways: the Astro site for humans, and corealm_search_docs that agents query directly. Challenges we ran into Honestly the WebMCP was the easy part, making a game in less than a week was the hard part. I wanted to make sure the game had enough content to feel worthwhile while not packing too much in and lowering the overall quality. Accomplishments that we're proud of The fact this went form an idea to a working prove of concept within a week. I've never built a full 3D RPG before, this was a huge undertaking for me. What we learned I learned a lot about how WebMCP works and came up with ideas how we can use this in fintech where I work. I also learned a lot about how 3D games are built and all the nuances to having a compelling game with proper animations sequences, sounds, good lighting, textures, ect its a lot. This makes me appreciate all the work that goes in to these types of games. What's next for Corealm Honestly might push this through and polish the content much more! Currently the game only has content for level 1-20, it'd be nice to continue to grow the game and refine the overall look and feel.
