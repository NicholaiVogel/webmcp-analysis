These tasks are often handled across different tools, making it difficult for filmmakers to keep everything connected. \n\n I wanted to build CineOps, a production workspace where humans and AI agents can work together. The idea was to let a filmmaker enter real production information while an AI agent can use structured tools to help with repetitive planning tasks. \n\n What I Built \n\n CineOps is an AI-assisted film production planning application that brings the core production workflow into one place. \n\n A filmmaker can: \n\n Create a film project with its title, genre, duration, and budget.\nAdd scenes with location and time-of-day information.\nGenerate a structured five-shot camera plan.\nEstimate a production budget.\nOptimize the proposed budget.\nReview and approve budget changes.\nCreate a multi-day shooting schedule.\nMonitor actions through an agent activity panel. \n\n The important part is that these capabilities are exposed as WebMCP tools, allowing compatible AI agents to interact with the application through structured tool calls. \n\n Why WebMCP? \n\n WebMCP makes the application more than a traditional web interface. \n\n Instead of an AI agent only giving suggestions as text, CineOps exposes actual application capabilities such as: \n\n create_project\nadd_scene\ngenerate_shot_list\nestimate_budget\noptimize_budget\ncreate_schedule \n\n This allows people and agents to work together on the same production workflow. \n\n For example, a filmmaker can provide the production information, while an agent can help generate a shot list, estimate costs, and organize the shooting schedule. The filmmaker can then review the results and remain in control of important decisions such as budget optimization. \n\n How I Built It \n\n CineOps was built as a modern React and TypeScript web application using Vite. \n\n The main technologies used are: \n\n React\nTypeScript\nVite\nWebMCP / Model Context API\nLucide React\nVercel for deployment\nGitHub for open-source project hosting \n\n The WebMCP integration registers structured tools using document.modelContext.registerTool(). Each tool has a name, description, input schema, and execution function. \n\n The application state is updated when tools execute, allowing agent actions to be reflected directly in the user interface. \n\n What I Learned \n\n Building CineOps taught me how to think about AI applications beyond chat interfaces. \n\n I learned how to: \n\n Design structured tools for AI agents.\nDefine tool input schemas.\nConnect agent actions with React application state.\nBuild human-in-the-loop workflows.\nHandle TypeScript interfaces and browser APIs.\nDebug integration and build errors.\nDeploy a React application to Vercel.\nDesign an application around the idea of agent + human collaboration. \n\n One of the biggest lessons was that an AI agent becomes much more useful when it can interact with real application capabilities instead of only generating text. \n\n Challenges \n\n One of the biggest challenges was integrating WebMCP with a TypeScript React application because the modelContext API is not part of the standard TypeScript DOM definitions used by the project. \n\n I had to create appropriate TypeScript interfaces and handle the availability of document.modelContext safely. \n\n Another challenge was making sure the tools were registered only when they were not already available, while also preventing duplicate registration. \n\n I also had to debug build errors, TypeScript errors, and deployment issues before getting the application running successfully on Vercel. \n\n What Makes CineOps Different \n\n CineOps focuses on a practical human-in-the-loop workflow. \n\n The goal isn't to replace the filmmaker. Instead: \n\n Human provides context → Agent performs structured tasks → Human reviews → Human approves important decisions. \n\n This creates a workflow where AI can reduce repetitive production-planning work while the filmmaker maintains control. \n\n Future Improvements \n\n Future versions of CineOps could include: \n\n AI-generated production breakdowns.\nMore advanced scheduling based on locations and cast availability.\nReal-time collaboration between production team members.\nMore detailed budget categories.\nAI-assisted script-to-shot-list generation.\nIntegration with real production management systems.\nMore sophisticated WebMCP tools for production workflows. \n\n CineOps demonstrates how WebMCP can turn an ordinary web application into an agent-ready workspace where humans and AI can work together on real tasks. \n\n \n\n \n Built With \n\n agent css html5 react webmcp \n \n\n \n Try it out \n\n \n \n \n cineops-webmcp.vercel.app \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n JWALITHA NAGASRI koppavarapu \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n JWALITHA NAGASRI koppavarapu \n started this project\n \n —\n \n 4 days ago \n \n \n\n
