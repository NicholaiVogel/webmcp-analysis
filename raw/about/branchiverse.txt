Real futures are not answers: they are living systems of choices, assumptions, turning points, and consequences. We wanted a shared space where a person could bring their values and lived context while an agent contributed imagination, structure, and overlooked possibilities. \n\n What it does \n\n Branchiverse turns an open-ended scenario into an interactive branching universe. A person manipulates branches and events directly on the canvas while an external AI agent inspects the same state and uses structured WebMCP tools to add branches, edit events, explore what-ifs, duplicate paths, collapse branches, and compare outcomes.\nThe demo follows a personal future: moving to Lisbon or staying in Montréal. After inspecting both paths, the agent discovers a third option—a seasonal, transatlantic life—and adds connected events that make the original decision reversible.\nThe final artifact is not an AI answer. It is a future model that neither participant would have created alone. \n\n How we built it \n\n Branchiverse is a responsive React application built with Vinext, TypeScript, and CSS. Its shared universe is structured branch and event data. The page registers eleven tools through document.modelContext, allowing compatible external agents to act on that state while React immediately reflects changes on the visual canvas.\nThe WebMCP tools are create_universe, add_branch, add_event, edit_event, remove_event, branch_from_event, explore_what_if, compare_branches, duplicate_branch, collapse_branch, and get_universe_state.\nWebMCP is a progressive enhancement: the canvas remains usable when no agent is connected. \n\n Why WebMCP matters \n\n Without WebMCP, the agent could only describe suggested changes in chat and ask the human to reproduce them. With WebMCP, the agent participates in the same creative surface. The canvas—not the chat transcript—becomes the shared artifact. \n\n Challenges \n\n The central design challenge was keeping collaboration legible. Agent actions needed to feel immediate without obscuring human authorship. We addressed this with provenance labels, live activity, distinct branch colors, tool-use summaries, and a focused action surface. \n\n Accomplishments \n\n \n A complete eleven-tool WebMCP surface \n Real-time agent mutations reflected on the canvas \n A polished, responsive scenario that communicates the concept immediately \n Graceful behavior with and without WebMCP support \n A focused demo flow under three minutes \n \n\n What we learned \n\n The most compelling agent experiences are not necessarily autonomous. Branchiverse works because human intention and agent exploration remain visible at the same time. Structured browser tools let the agent become a collaborator inside an existing interface rather than replacing that interface with chat. \n\n What's next \n\n Future versions could add persistent universes, multiplayer sessions, uncertainty ranges, evidence attached to assumptions, replayable history, and templates for business futures, alternate history, fictional worlds, and civic planning. \n\n \n\n \n Built With \n\n css lucide react typescript vinext vite webmcp \n \n\n \n Try it out \n\n \n \n \n branchiverse-futures.starmanfarah.chatgpt.site \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n Bassem Abi-Farah \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n 1 \n \n \n\n\n \n 1 person likes this:\n \n\n \n \n \n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n Bassem Abi-Farah \n started this project\n \n —\n \n 5 days ago \n \n \n\n
