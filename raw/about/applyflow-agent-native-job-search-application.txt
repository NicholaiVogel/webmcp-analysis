ApplyFlow brings job discovery, application drafting, validation, review, and tracking into one connected workspace for both candidates and AI agents. \n\n What it does \n\n ApplyFlow helps candidates: \n\n \n Discover and filter relevant job opportunities \n Compare job requirements against their profile \n Create pre-filled application drafts \n Validate applications before submission \n Track application statuses \n \n\n It also exposes these workflows through WebMCP, allowing AI agents to assist with the same tasks in a structured and reliable way. \n\n How we built it \n\n I built ApplyFlow as a frontend prototype using React, TypeScript, and Vite. Jobs, candidate data, and applications are managed through local services and persisted with browser localStorage . \n\n WebMCP tools connect AI agents to the same workflows used by the web interface, so agents can search jobs, prepare applications, validate details, and track progress without relying on page scraping or simulated clicks. \n\n Challenges we ran into \n\n The main challenges were designing a smooth multi-step application workflow, keeping UI and agent actions synchronized, and clearly separating read-only tools from state-changing actions. I also needed to ensure that applications were validated before they could be submitted. \n\n Accomplishments that we're proud of \n\n I am proud that ApplyFlow supports a complete job application journey in one place. I also built structured WebMCP tools that let AI agents work alongside users by searching jobs, preparing applications, checking details, and tracking status through well-defined actions. \n\n What we learned \n\n I learned how to design agent-accessible web experiences, define structured tool schemas, and connect AI actions to the same services used by a React interface. I also learned how important user approval, validation, and clear action boundaries are when building tools that can change application state. \n\n What's next for ApplyFlow: Agent-Native Job Search & Application \n\n Next, I plan to connect ApplyFlow to real job boards, add stronger AI-powered job matching and application writing, support resume uploads, and improve authentication and backend persistence. I also want to expand WebMCP support to make career workflows more personalized, trustworthy, and collaborative between people and agents. \n\n \n\n \n Built With \n\n ai-agents application-tracking browser chatgpt css eact frontend-development html javascript job-search localstorage typescript vite webmcp \n \n\n \n Try it out \n\n \n \n \n applyflowwebmcp.vercel.app \n \n \n \n GitHub Repo \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n I built ApplyFlow end to end, including the React, TypeScript, and Vite frontend prototype, the local service layer for managing jobs, candidate data, and applications, and the browser localStorage persistence.
