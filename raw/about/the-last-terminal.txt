This approach is fragile, slow, and burns tens of thousands of tokens per action. \n\n When WebMCP (Web Model Context Protocol) emerged as a proposed browser standard ( navigator.modelContext.registerTool ), we realized web applications no longer had to be passive visual interfaces. Websites could directly expose machine-readable capabilities to AI agents. \n\n We wanted to showcase this paradigm shift in a way that was instantly understandable and fun. An escape room was the ultimate sandbox—demanding puzzle reasoning, state prerequisites, data extraction, and tool sequence execution! \n\n \n\n What it does \n\n THE LAST TERMINAL is an interactive, browser-based cyberpunk escape room where human players and AI agents collaborate to escape an abandoned digital research facility before the emergency countdown reaches zero. \n\n \n 5 Interconnected Subsystems : Surveillance Matrix, Security Terminal, Auxiliary Power Control, Archive Database, and Emergency Exit Override. \n 10 WebMCP Capabilities : Exposes structured capabilities ranging from inspect_surveillance("CAM-07") and read_log("LOG-2049") to restore_power(["C","A","D","B"]) and unlock_exit("7319") . \n Dual Execution Engine : Human UI interactions and AI WebMCP tool calls invoke the exact same underlying JavaScript game engine logic. \n Real-Time Agent Feed & Trace : A live terminal logs tool calls in real time, accompanied by a full JSON execution trace inspector for hackathon judges. \n Demo Agent Simulator : Includes a 90-second automated execution mode so anyone can watch an AI agent solve the room step-by-step without needing external API keys. \n \n\n \n\n How we built it \n\n \n Core Tech Stack : Next.js 14 (App Router), React 18, TypeScript, and Tailwind CSS. \n WebMCP Integration ( src/lib/webmcp/ ) : Registered 10 structured tools with strict JSON Schemas using navigator.modelContext.registerTool imperative API, wrapped in a hydration guard to prevent re-registration during React re-renders. \n Unified Game Engine ( src/lib/game/ ) : Built a central state machine ( gameEngine.ts ) powering both human clicks and agent tool calls. \n Web Audio API Synthesizer ( src/lib/audio/sound.ts ) : Built a zero-external-asset audio generator for terminal typing clicks, success chimes, failure buzzers, and power-up sweeps. \n Developer Debug Bar ( ?debug=true ) : Added a secret query parameter mode for instant puzzle completion and state inspection during testing. \n \n\n \n\n Challenges we ran into \n\n \n Enforcing Prerequisites Without Crashing : Ensuring that tools like open_archive() correctly check state prerequisites ( power === 'online' ) and return structured error payloads ( PREREQUISITE_NOT_MET ) rather than throwing unhandled exceptions. \n Graceful Fallback & Polyfilling : WebMCP is an emerging browser feature. We needed to support native navigator.modelContext while building an in-memory tool polyfill and automated simulator for standard browsers. \n Zero-Dependency Architecture : Ensuring the entire application ran client-side with zero backend infrastructure, zero paid APIs, and zero external databases while keeping the build Vercel-ready. \n \n\n \n\n Accomplishments that we're proud of \n\n \n >90% Token Reduction : Demonstrated how structured WebMCP tool calls eliminate the heavy token overhead of DOM parsing and visual screenshot analysis. \n Zero Paid Dependencies : Built the entire experience to run 100% locally in the browser with zero external infrastructure. \n 100% Test & Build Validation : Achieved a clean Next.js static build and 100% pass rate on our standalone engine test suite ( npm run test:engine ). \n \n\n \n\n What we learned \n\n \n WebMCP transforms web applications from passive UIs into agentic APIs . \n Human + Agent co-op design patterns—where humans supply visual intuition and agents perform rapid tool inspection—create a powerful collaboration model. \n \n\n \n\n What's next for The Last Terminal \n\n \n Multi-Agent Co-Op : Expanding to multi-agent escape rooms where specialized WebMCP agents (e.g. Security Agent, Power Agent) solve puzzles in parallel with human teams. \n useWebMCPTool React Hook : Packaging our WebMCP registration layer into an open-source React hook library for Next.js developers. \n Community Puzzle Creator : Allowing developers to construct their own WebMCP escape rooms using custom JSON schemas!
