More importantly, we made these capabilities accessible to AI agents through WebMCP . \n\n An agent can search for a purchase, check its warranty, find the receipt, and prepare a claim without the user having to manually navigate through everything. \n\n For example, a user can ask: \n\n \n “Find my Sony headphones, check if they’re still under warranty, retrieve the receipt, and prepare a claim if eligible.” \n \n\n LifeReceipt can handle the investigation and preparation — but it stops before submitting the claim . \n\n The user has to explicitly approve the action. \n\n That human approval step was an important part of our design because we don't want an agent making consequential decisions completely on its own. \n\n How We Built It \n\n We built LifeReceipt as a React + Vite web application and created a WebMCP layer that exposes the application's capabilities as agent tools. \n\n We implemented 9 tools covering purchase search, warranty checking, receipt retrieval, claim preparation, approval, submission, and claim status. \n\n The UI was designed to make the whole process visible. Users can explore their purchases through the Purchase Vault, see upcoming warranty expirations through Warranty Radar, and follow the agent's actions through the Agent Activity Log. \n\n What We Learned \n\n The biggest thing we learned was that building for agents is different from building a normal website. \n\n We had to think about what an agent should be allowed to do , what information it needs, and where a human should take over. \n\n WebMCP made us think of the website as more than just pages and buttons. Each useful capability can become something an agent can discover and use. \n\n Challenges \n\n Getting the WebMCP integration and the normal website experience to work together reliably was one of our biggest challenges. \n\n We also faced deployment issues with Netlify, including SPA routing and JavaScript MIME types. Fixing those issues taught us that a project isn't finished when it works locally — it also needs to work reliably in the real environment where people and agents will use it. \n\n Why LifeReceipt? \n\n We don't want LifeReceipt to be another place where receipts go to be forgotten. \n\n We want it to be a place where your purchases stay useful long after you buy them — with an agent handling the boring work and a human staying in control of the important decisions. \n\n \n\n \n Built With \n\n agentic-ai ai-agents css e-commerce github html human-in-the-loop javascript netlify personal-finance react rest-apis ux-design vite warranty-management web-automation web-development webmcp \n \n\n \n Try it out \n\n \n \n \n lifereceipt-yourpurchasesremembered.netlify.app \n \n \n \n\n \n\n \n\n \n \n Submitted to\n \n\n \n \n \n \n \n\n \n \n The WebMCP Challenge \n \n\n\n \n\n\n \n\n \n \n\n \n \n Created by\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n 125-LOHITH RAJ R \n \n \n\n \n\n \n \n \n \n\n \n \n \n \n \n \n \n \n \n\n \n \n \n \n \n\n \n\n \n\n\n \n \n \n \n \n\n \n \n \n \n \n \n \n \n \n Like\n \n \n\n\n \n \n \n\n \n \n\n \n\n\n \n \n \n \n Share this project:\n \n\n\n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n \n \n \n \n \n \n\n \n\n \n \n \n \n\n \n \n \n\n \n \n \n \n \n\n\n\n \n \n \n Updates \n\n \n \n \n \n \n\n \n \n \n \n \n \n 125-LOHITH RAJ R \n started this project\n \n —\n \n 2 days ago \n \n \n\n
