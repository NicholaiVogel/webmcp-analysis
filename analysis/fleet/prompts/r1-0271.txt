Like Comment Story Updates Inspiration Automated accessibility scanners are valuable, but they usually evaluate isolated rules—not whether someone can complete an entire task. A page can pass conventional checks while an essential action remains unreachable. That gap inspired Blind Spot : Automated scanners test rules. Blind Spot tests whether a task remains reachable through an accessibility-derived interaction surface. Blind Spot is not a replacement for disabled-user testing, assistive-technology testing, axe, Lighthouse, or Playwright. It provides an earlier, task-level signal that helps developers find critical barriers before shipping. What it does Blind Spot gives an agent a constrained set of semantic actions derived from the application’s currently rendered state. Our demonstration begins with the task: Add the cheapest keyboard to the cart. The agent can read the page and navigate its semantic model, but the cheapest product uses a pointer-only <div> as its Add to Cart control. The agent attempts the task, the developer makes the judgment and repair, and both participate in validating the result. A model must understand how a flat texture wraps around a 3D character, not just produce a convincing front view. With genMC(P), I wanted to turn that benchmark into a shared workspace where humans and agents create and refine skins together. How I built it I built the editor with React, TypeScript, and Three.js. WebMCP gives agents structured tools to inspect skins, edit pixels, and respond to user instructions. Users can paint directly, mark areas, and send messages while the agent works. Each skin has its own session. Gallery skins open as private copies, and publishing requires human confirmation. The backend uses Cloudflare Workers, D1, and R2, deployed through ChatGPT Sites. Challenges The biggest challenges were mapping 2D textures correctly onto 3D body parts and keeping human and agent edits coordinated. Session and revision checks prevent stale edits. Message tracking distinguishes “read” from “completed.” I also learned that a marked area should be guidance by default—not a restriction that prevents the agent from completing the task. What I learned Good agent integration needs more than tools: it needs clear state, visible feedback, and human control. Minecraft skins remain a surprisingly demanding spatial-reasoning test. WebMCP turns that test into an interactive creative process, where users can guide the model and improve the result together.
