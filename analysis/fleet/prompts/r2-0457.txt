Key workflows include: Inspecting system status and runtime metrics. Discovering managed services and viewing their current state. How I built it Agent WebMCP is implemented as a Java application with a lightweight browser frontend and a canonical operation runtime. Each operation defines its identifier, description, access characteristics, input schema, and execution behavior. That feels less like automating a website and more like designing a new kind of interface. What's next MoveToGermany.lol is about relocation, but the experiment is bigger than relocation. I want to explore what happens when more websites stop treating agents as visitors that need to imitate humans, and start exposing meaningful capabilities directly, while keeping the human in the loop. One application. Two operators. One shared state.
